# 0.1.308 召唤武装预览与实际模型对齐（2026-10-31）

原预览直接调用ItemRenderer，而实际武装使用原生ItemDisplayRenderer；后者在物品FIXED变换前会额外绕Y轴旋转180度。预览遗漏该步骤，使剑、发射器等模型方向和视觉位置与实际显示不同。预览现在创建仅客户端缓存的ItemDisplay，并调用与实际武装相同的原生实体渲染器，完整复用模型枢轴、FIXED物品变换和旋转链，不再手动拼接近似变换。预览不加入世界实体列表，不产生服务器实体、碰撞或存档，仍仅操作者可见且3秒后过期。

位置和发射口仍使用原有共享frame/formation计算。目标追踪预览不再直接跳到完整朝向，改用与新生成武装相同的首tick转向步长。预览是点击时的生成姿态快照，已运行武装后续随目标/部件移动的姿态会正常继续变化。

包含上次用户要求的属性排序：生成特效、生成音效、消失特效、消失音效移至武装属性列表末尾。未改变武装伤害、攻击节奏、持续时长和多批激活规则。

验证：隔离实际客户端同时显示10件武装，以发射器与下界合金剑逐项对比预览实体和实际实体的世界坐标、完整XYZ旋转/缩放变换矩阵与FIXED显示上下文，全部通过；两张截图已检查。保留原有阵型、目标追踪、跟随/世界位置、死亡清理检查。召唤武装相关原生测试与JAR构建通过；双语手册141（57章节44模块）通过。本次未重跑全模组282项或GUI组合测试。

# Heart 无线红石时序控制（0.1.23）

Life 管理生命状态和无线信号；Create / Aeronautics / Synaxis 等模组执行关节运动。Heart 不直接改变关节姿态。

## 独立界面

创造模式右键 Heart，点击“无线时序控制”（中继器图标）。这是独立 Screen/Menu，不使用箱子格子作为按钮。铜色外框、深色面板与紫晶分隔线沿用 Life 的形象。

- 左侧：16 个频道，每页 8 个；总开关、当前输出状态。
- 右侧：红／蓝频率样本，启动延迟、通电时长、断电时长、信号强度。
- 数值可以直接输入后按 Enter 或 ✓；加减按钮每次调整 1 秒，Shift 调整 5 秒。
- 下方：单次／循环、频道启用开关、时序波形预览；绿色游标表示运行进度，超过预览窗口后隐藏。
- “选择频率物品”展开玩家物品栏。拿起物品后点击红／蓝样本槽，仅复制样本，不消耗物品。空光标点击清除；关闭界面正常归还光标物品。

仅创造玩家可打开；休眠时编辑，激活后只读。用创造解除工具恢复休眠后可修改；无线频道配置保留，再激活从零计时。

## 时序与网络

各频道共享激活起点：启动延迟 → 通电 → 断电；循环在第一次延迟之后反复执行通断，单次只发射一次。每项时间最大 600 秒；通电最短 1 tick（0.05 秒），断电为零表示持续通电。默认延迟 0 秒、通电 1 秒、断电 1 秒、强度 15；频道默认关闭。

频道使用 Create 原生 `IRedstoneLinkable` / `Frequency`，两件物品的顺序与 Create 接收器一致。至少需要一个频率样本。信号遵守 Create 距离、维度和频率匹配规则；同频道多个发射器按 Create 原生最大强度合并。每 5 tick 刷新移动后的范围。

Sable 自带 Create 无线距离兼容：将 Heart 与接收器的子世界坐标转换到物理世界，再比较距离。因此发射器返回 Heart 原始方块位置，避免重复转换。

生命归零、解除、核心移除或区块卸载会注销该 Heart 的发射器；世界关闭由 Create 清理全部网络。其他同频道发射器不受影响。频道配置与已加载游戏刻进度保存到 NBT，重载继续运行，离线时间不推进。

## 验证与下一步

自动测试覆盖波形边界、单次／循环、零断电、数值夹取、样本复制、频道 16、菜单权限与距离、激活锁定、NBT 保存、原版 Create 接收器与 Sable 结构连接、重载重注册、死亡／解除／卸载清理、同频率其他 Heart 输出。

尚待客户端验证独立界面的布局与点击，以及实际关节接收器在移动、旋转和超出无线距离时的动作。当前实现为固定时间表；按感应、受伤、死亡等事件切换动作组属于后续扩展。

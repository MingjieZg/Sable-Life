# 0.1.95 悬浮追踪弹展开与模型

## 调整

- Preview 增加 Mark 到每个悬浮终点的粒子连线，终点仍显示粒子团。
- 默认使用 Minecraft 原生潜影贝白色立体弹模型及发光层，替代潜影壳物品。
- 弹丸从 Mark point 出发，按「飞向悬浮位置时间」直线移动到展开终点，默认 1 秒、范围 0–10 秒。0 为立即展开。抵达后开始计算原蓄力时间，再追踪目标。展开阶段不造成伤害，开始追踪后使用正常碰撞。
- 工具／武器使用与箭矢模块一致的完整物品模型姿态，飞行朝向不再始终面对镜头。大小与 hitbox 仍共用直径。
- 扇形平面可选水平、正面竖直、侧面竖直；另可旋转 -180°–180°。换平面后中央弹的位置不变，Preview 和实际展开使用同一组位置。
- 默认蓄力音效为烟花 launch，发射音效为烟花 shoot；保留两组音量／播放半径。旧版本原默认潜影音效自动替换，其他自定义声音保留。
- 保存展开终点及移动进度；修改模块不会改变已生成的一批。

- 追踪方式新增「直接追踪（预判移动）」作为默认，保留「潜影贝分段转向」。直接追踪每刻更新目标方向，远距离最多预判 6 刻的移动，近距离对准实际碰撞中心。
- 追踪强度 0.01–1，默认 0.5；高值快速转向，低值保留更多惯性，方便横向闪避。它不是随机命中概率：飞行速度、hitbox、障碍及目标移动仍决定实际命中。
- Single target：一整批弹丸集中锁定最近目标；Multiple target：一批弹丸依次分配给范围内目标。目标数超过弹丸数时，本批最多覆盖弹丸数量的目标。
- 核心新增「受到其他生命体攻击伤害」开关，默认开以保持旧行为。关闭阻挡其他生命体的箭矢、炮弹等可攻击本体的伤害与破坏路径；本身攻击始终无效，玩家攻击不受影响。开关可在存活时更改，并随保存／复制保留。
- Whole-body loot 与 Limb loot 使用相同的 6 行界面：上方 27 格样本，下方概率／权重模式、抽取次数及帮助。Shift 左／右点击样本增减 5；模式及抽取次数操作一致。旧存档默认每格 100% 概率，死亡任务冻结规则后抽取，规则随保存及复制保留。

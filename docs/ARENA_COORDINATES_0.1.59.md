# 0.1.59 场地标记与水平圆柱

- 场地标记独立使用服务端世界视线射线，允许普通世界地面与 Sable 本体。普通部位模块仍维持原同体标记规则。
- 地面 BlockPos 直接保存世界坐标；本体命中用所属刚体 pose 转换一次，保存固定中心。核心也通过 BlockPos 所属刚体转换当前位置。
- 边界依然只按核心与中心的 X/Z 水平距离，忽略 Y。玩家警告范围从原球形改为水平圆柱，同样忽略 Y。
- 标记成功显示固定世界 X/Z；面板显示实际水平距离与半径，便于区分坐标、激活、供电与附近无合格玩家的问题。
- 已有标记建议重新标记一次。场地处罚仍要求生命化 ALIVE、模块启用/供电，且警告范围内有生存/冒险玩家；创造/旁观不处罚。

验证：编译与代码检查；未声称游戏内复现已通过。

待复查：世界地面可标记；移动核心后距离增加且中心不移动；大幅升降但 X/Z 不变不越界；水平越界触发生存玩家完整倒数；高/低位置玩家同样参加；回场取消。

# 0.1.85：落雷随机落点

攻击模式新增「范围内随机落点」，围绕标记点在水平圆形范围内散布，每轮重新选择位置。起始距离大于零时排除中心圆，随机按面积均匀分布。选定位置先预警再落下，不会追踪玩家移动。

- 随机落点范围：决定散布圆的外半径。
- 从自身 X 格以外开始：决定内圈安全区，须不大于外半径。
- 每轮随机落点数：1–128，默认 16，仅随机模式可编辑。
- 随机落雷间隔：沿用 waveDelay，按生成顺序错开预警和落下时间。
- 攻击半径：每一发落雷的命中半径，不是散布范围。命中圆可延伸到散布边缘或中心安全区内，留安全区时应计入此半径。
- 自定义发射物、拖尾、颜色、伤害、预警时长和音效继续沿用原设置。

同一轮不重复同一地面列。没有地面的落点会重新尝试，最多尝试数量的八倍；小范围、悬空或稀疏地形时实际数量可能少于设定值。旧模式编号保持不变，旧配置无需重做。

## 本轮待测

- [ ] 切换随机模式，落点数输入与滚轮；左右键切换模式。
- [ ] 范围 12、起始 4、每轮 16：落点中心是否在圆环内，下一轮是否变化。
- [ ] 预警后走开是否能躲避；每发按随机落雷间隔依次落下。
- [ ] 自定义发射物、粒子、音效与伤害正常；小范围和无地面场景不出现卡顿。
- [ ] 保存重载／数据复制器／Photomancy 后保留随机模式与数量；旧直线、向外射线、追踪模式正常。

# 0.1.287 自带可调色粒子（2026-10-29）

现有粒子选择器新增 Sable 电弧、Sable 烟雾、Sable 能量光点，可搜索 sable；支持独立 Color / Life / Size，名字附带可调色提示。中英文名字随语言设置切换。不增加模块、不增加网络消息，使用既有粒子注册、服务端发送、客户端调色与预算。

- sablelife:arc：随机方向、每次出生固定折线的短促电弧，面向镜头，内外两层线条。默认0.3秒、约1.3格长。不是连接两个标记点的雷电束。
- sablelife:smoke：中性灰度原版烟雾帧，允许RGB染色，缓慢上飘、随寿命淡出；默认1.6–2.4秒。受环境光影响。
- sablelife:energy_mote：小型柔和光点，逐渐消散，默认1秒。

Life 0使用原生默认寿命，正值覆盖；Size沿用0.1–4倍。电弧和光点使用自身全亮渲染，不会照亮世界。没有闪电实体、伤害、点燃或天气改变。粒子模块、攻击、持续范围、波纹等使用现有粒子选择器的入口均可选择；实际分布、数量、运动仍由发射模块控制。烟雾帧按原版从大到小排列，避免最初仅为单像素。

颜色和参数随模块NBT及预设保存；仍由现有蓝图配置保存流程处理。协议保持22，新增粒子注册要求客户端与服务器使用同版。手册123，54章节、41模块。稳定仍243，移动观察/对照仍273/272，上次GitHub仍284。未修改原游戏实例或上传。

验证：17项粒子原生GameTests，包含新粒子注册/参数编辑/NBT及预设往返；隔离客户端世界确认三种provider、默认原版包和自定义样式包、RGB/Life/Size、有效贴图及到期回收；Color/Life/Size界面检查GUI比例2和3。未重复完整战斗、Epic Fight或大型多人压力测试。

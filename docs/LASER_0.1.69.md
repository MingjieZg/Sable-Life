# 激光模块 — 0.1.69-dev

新增虚拟「激光束」模块。标记一个发射出口即可，使用现有 Always、标记处红石、内／外无线触发。

## 属性

- 固定射线：跟随标记面的实时朝向，可由机械部位动作控制；扫射角度 0–180 度，默认 0，非零时从一侧扫到另一侧。扫射绕部位自身的上轴进行。
- 持续自瞄：对指定类别的最近可见目标开始蓄力，并保持追踪；目标死亡或离开长度范围后重新获取目标。没有目标时取消当前蓄力／发射并等待。
- 激光长度 1–128 格，默认 32；直径 0.1–4 格，默认 0.5。
- 每次命中伤害 0.1–1000，默认 6，正常受护甲减免。
- 蓄力 0–60 秒，默认 2；蓄力阶段仅显示预告，不造成伤害。
- 每轮伤害次数 1–100，默认 5；伤害间隔 0.05–10 秒，默认 0.5。每次脉冲可伤害射线内多个符合类别的目标。
- 每轮结束后停顿 0.05–600 秒，默认 3。例：2 秒蓄力 → 5 次伤害，每次间隔 0.5 秒 → 3 秒停顿。
- 7 种颜色，自定义粒子双列表（最多 16 种）、蓄力音效和发射音效。音效支持原版声音与自定义 OGG。

外部碰撞方块截断激光，生命体自身已捕获方块不会挡住射线。不会破坏地形。触发关闭、禁用、删除、解除生命化或部位断开都会终止激光和对应音效。Preview 显示射线和扫射边界，无伤害。

激光参数、粒子和音效采用既有模块存储，可随数据复制器复制数值，以及随 Photomancy 蓝图继承模块和标记。

## 验证状态／待玩家检查

已通过 assemble 编译。用户于 2026-10-03 确认「光束没问题」，激光功能已通过玩家测试。

1. 固定射线随标记部位转动；扫射角度 0 与 90 的差异，旋转部位上的扫射方向。
2. 自瞄选择玩家／生物／全部；无目标等待，目标死亡或离开射程后停止或重新获取。测试玩家目标需使用生存模式；创造／旁观玩家不会成为目标。
3. 蓄力无伤害、伤害次数和间隔、每轮停顿正确；护甲能减伤。
4. 外部墙体阻挡，自身结构不会挡住射线；不同激光直径下命中范围。
5. 颜色、多个粒子、自定义音效，以及预览无伤害。
6. 关闭红石／无线、禁用／删除模块、解除生命化时取消光束和声音。
7. 存档重载、数据复制器、Photomancy 复制后参数与标记继承。

## 后续方向

生命阶段只考虑按血量阈值输出自定义无线信号，不接管玩家设计的机械动作。可编程脉冲序列作为后续独立功能，参考触发后依次执行信号／等待步骤、结束后等待下一次触发的方式。当前未加入 Create Connected 依赖或脉冲序列；不做部位破坏事件模块。

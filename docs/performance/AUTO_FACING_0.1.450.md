# 自动朝向瞄准偏移性能

32 个简化活动核心配合移动目标时，零偏移阶段 0 的平均值为改前 2.850、候选 2.838 MSPT；阶段 3 为 1.403、1.394 MSPT。本样本未见明确持续增加。候选阶段 0 的单次最高值更高，不能据此声称性能提升。

| 阶段／候选偏移 | 改前平均／P95／最高 MSPT | 候选平均／P95／最高 MSPT |
|---|---:|---:|
| 0：零偏移 | 2.850 / 3.689 / 4.465 | 2.838 / 3.601 / 11.881 |
| 1：左 0.375 | 2.372 / 3.264 / 4.013 | 1.973 / 2.520 / 2.810 |
| 2：左 0.375，上 -0.625 | 1.863 / 2.318 / 3.769 | 1.605 / 1.998 / 3.378 |
| 3：零偏移 | 1.403 / 1.808 / 2.981 | 1.394 / 1.904 / 3.478 |

改前使用实际 0.1.449-fix1 catalog-order JAR；候选使用实际 0.1.450 aim-offset JAR（手册251），早于后续文案和近战设置调整。改前不支持偏移，各阶段均为零。本报告测量瞄准偏移，不代表后续近战新增项。

每阶段 240 tick，前 120 tick 预热，后 120 tick 采样服务端完整 tick 计时。每核心有一个自动朝向，关闭碰撞检查、开启垂直追踪；目标是无 AI、无重力牛。固定简化主体的位置及速度并保留朝向，场景维护和目标移动计入 MSPT。

原生结构组装准备耗时改前 380.001 ms、候选 320.720 ms。这是同步测试场景组装耗时，不是完整生成 tick 或蓝图生成耗时。

环境：Minecraft1.21.1、NeoForge21.1.235、Create6.0.10、Sable2.0.5、Java21、2GiB 堆，同一 Windows 机器串行运行，其他测试进程已停止。每个 JAR 一轮，预热、GC 和调度会影响小幅差异。未测大型蓝图、复杂关节、多人及客户端 FPS。

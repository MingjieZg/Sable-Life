32只生命体、256个接触传感器启用时，两个采样段的平均开销为3.532和2.412 MSPT，合计240个采样刻的平均为2.972 MSPT，最高4.843 ms。无传感器场景中，0.1.442和0.1.443的平均分别为1.392与1.450 MSPT。单次对照存在预热和抖动，不能据此推断其他整合包的性能。

## 持续活动

Minecraft 1.21.1、NeoForge 21.1.235、Create 6.0.10、Sable 2.0.5、Java 21，JVM最大堆2 GiB。使用实际JAR，关闭其他测试进程。32个单方块生命体；负载场景每只安装8个传感器，尺寸2×2×2格，勾选五种检测类别。场景初始生成32头无AI／无重力牛和128支无重力箭，箭矢静止，没有持续射击补充。

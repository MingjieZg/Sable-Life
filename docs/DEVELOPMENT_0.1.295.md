# 0.1.295 部件事件漏发修复（2026-10-29）

修复战斗事件“部件脱离／摧毁”在连接器仍引用已移除部件时不输出信号。Sable getConnectedChain 遍历可能包含已移除结构；旧代码把它们的 UUID 仍计为连接中，导致全部部件与 Mark指定部件均漏判。现在连接集合排除 isRemoved 部件，再沿用原有已移除／实际断开检查及每部件去重。未改变事件类型或增加受击事件。

新增两项集成回归：使用真实组装核心与独立部件、Sable真实连接遍历（连接器actor为测试夹具），分别调用原生容器移除结构、断开连接依赖；断言全部与标记规则同时输出，完整部件不触发，移除不会反复输出。原测试版本重现移除后漏发，初次直接markRemoved夹具还造成原生物理访问已移除body的错误，随后夹具改用正常容器移除流程。修复后18项全部信号/战斗事件原生测试通过，打包成功。未做用户Boss结构或完整多人实测。

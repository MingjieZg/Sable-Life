## 原因与结果

| 审计问题 | 改动及结果 |
| --- | --- |
| 命令导入绕过管理员检查 | 复制器拒绝非管理员导入命令；核心方块NBT设为管理员专用；命令编辑/启用/删除和加入动作抽选保持管理员检查。没有玩家身份的蓝图API将命令标为待确认，管理员保存命令行或重新启用后方可运行。 |
| SNBT递归与请求成本 | 解析前限制64层深度、UTF-8字节数，载入限制节点数量；编辑及复制器加入弱引用玩家令牌桶；取消标记不受节流影响。已知预设去除不相关隐藏数据组。 |
| 频道65,535运行成本 | 新建频道默认服务器限额256，旧频道和编号不截断。只轮询配置过的频道，停止时只遍历已注册发送/接收器。任何频道API修改都会使缓存失效。 |
| 全ownership表目标查询 | 使用已加载核心索引、同tick边界和空间候选网格；无需逐方块寻找所有核心，也不会生成实体代理。移动/组装/卸载/维度变更会使相关缓存失效。爆炸桥也使用空间候选。 |
| 重复连接图查询 | 同tick同连接图共享身体与核心结果，标记检查使用成员集合。方块替换、组装和退出使缓存失效。 |
| 碰撞重复扫描及总成本 | 一次检查只抓取一次其他身体边界，使用身份集合排除自身。跨核心共享碰撞工作预算；预算不足的位移等待，不误判为地形阻挡。原接触余量、路径/终点和强制位移语义保留。 |
| 清理全表与历史任务 | owner/part反向索引与有界队列；死亡清理共享256方块/服务器tick并轮转任务。完成任务迁移为精简CompletedDeaths记录，保留防重复奖励及部位历史，不再参与每tick死亡任务扫描。 |
| 视觉/飞行物总量 | 每玩家/tick视觉预算；新弹射物有维度及生命体限额。已有和从存档加载的弹射物不被限额删除，移除归还配额。视觉限额不改变伤害逻辑。 |
| 全量健康更新 | 客户端核心更新只携带材质及身份/名称/健康/死亡阶段；完整作者配置仍保存。大面板超过阈值时保留选中模块详情，其他模块传标题与状态；极端单模块过大时拒绝完整作者载荷。 |
| GUI及字段重复解码 | 不变数据组件不再每帧重新载入全部模块；不可变字段列表及字段查找缓存。 |
| 全局红石发布者扫描 | 按位置/面查询发布者，保留最大强度合并、零强度连线及按核心清除。 |
| 区块续期 | 身体票据只在集合变化时增减；世界票据新增位置立即请求，稳定位置每10tick续期，仍短于40tick超时。 |
| 声音队列 | 批量移除到期项后稳定排序，避免列表成员搜索和逐项移动数组；4096项同刻到期保持顺序、只执行一次。 |
| 生命周期缓存 | 核心卸载/维度切换移除索引、清除相关图缓存；关服清除标记/预览和爆炸余波；退出客户端清除火焰预算引用。 |
| 测试入口 | 默认GameTest使用当前功能namespace；原生伤害、ownership及有效旧测试纳入。旧菜单点击、隐含16频道和默认可破坏的假设改为当前接口，并要求破坏实际成功。 |

## 行为和迁移

招式抽选顺序、损坏导致整个招式不可用、已有伤害/防御、每目标限次、现有字段滚轮步长保持。没有增加实体代理，也没有大规模拆类或更换碰撞算法。

网络协议由4升级为5；客户端和服务器应同时更新到0.1.195。旧存档自动恢复owner/part索引，旧完整已结算死亡任务转换为精简防重复记录。回退版本时使用修改前完整备份，不应依赖旧版本识别新CompletedDeaths数据。

限额位于世界serverconfig/sablelife-server.toml。达到限额时可能减少视觉、暂停新弹射物生成、推迟位移或分批清理；它们是资源边界，不是TPS或承载数量保证。

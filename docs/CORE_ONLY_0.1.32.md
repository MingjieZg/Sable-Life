## 解除生命化

Heart 统一面板右上角增加红色 Release / 解除生命化，旁边 × 为关闭菜单。鼠标悬停显示说明。

仅创造模式可打开此面板和执行解除。按钮不要求核心休眠：Alive、Dying、Dead 状态均可使用，服务端检查当前核心、距离和玩家权限。执行与解除工具相同的 resetForCreative 路径，对同一连接结构上的核心解除绑定，取消死亡/断肢结算，停止无线红石与虚拟模块运行，恢复默认核心生命设置。

保留建筑方块和虚拟模块配置；原解除工具继续可用。操作后菜单关闭并显示已解除提示。之后可编辑结构或重新激活。

本轮沿用用户“无需 test”的要求，仅 assemble 编译打包成功，未运行测试。以前依赖实体模块的回归测试属于退役行为，旧测试数量不代表当前版本已验证。

# 0.1.87：激光 Target 跟踪速度

新增「目标跟踪速度」，范围 0.1–1，默认 1。固定／扫射模式中此项变灰。

- 1：即时锁定，保持旧版本行为。
- 0.1–0.9：每 tick 的转向上限为数值 × 10 度。0.1 为每秒约 20 度，0.5 为每秒约 100 度。1 是即时锁定特例。
- 从标记方向起步，蓄力及发射期间都持续逐渐追向目标。再次发射或切换目标不强行重置朝向。
- 玩家横向移动可以超过转向速度；停下后激光会逐渐追上。能否躲过仍取决于目标距离、光束宽度、蓄力时间与移动速度。
- 显示光束与实际命中使用同一个追踪方向；墙壁截断继续生效。失去目标仍沿用原有取消与重新搜寻行为。
- 静态 Preview 展示最终目标方向；动态追踪速度需实际激活检查。

## 本轮待测

- [ ] Target 速度 1：保持原先锁定。
- [ ] 速度 0.1／0.5：横跑能拉开角度，停下后逐渐追上；上下移动也正常。
- [ ] 蓄力预警线和发射伤害方向一致，射线未扫到时不扣血。
- [ ] 目标死亡／离开范围、重新选目标、连续发射、断电停止后重启，不出现瞬间跳转或无效方向。
- [ ] 固定和扫射不受影响；跟踪速度灰色不可编辑。保存重载及复制保留设置。

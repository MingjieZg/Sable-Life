# 0.1.31-dev：旧模块导入统一核心

## 操作

1. 创造模式下，核心处于 Dormant 状态，打开统一核心面板。
2. 点 + Add module，再点左侧分页位置的 Import。
3. 界面关闭后，右键同一连接结构上的旧 Sable Life 模块方块。
4. 参数和标记复制到一个新的虚拟模块，界面返回并选中它。潜行右键取消导入。

支持近战、喷火、箭矢、脉冲、目标感应、声音、肢体战利品七类。必须实际指向并够到旧方块，其他生命体拥有的方块、未连接结构、已接管来源、满 32 个模块都会拒绝导入。不会批量扫描或自动导入。

## 保留的行为

- 近战伤害、击退、效果、等级、时长和原半径立方体保留，间隔设为 1 tick，与原方块持续伤害一致。预览显示原立方体；可重新标记两点来使用普通虚拟近战选区。
- 喷火、箭矢、脉冲复制数值、声音和朝向。攻击模块默认 anchor power，兼容原方块的红石供电方式（包含核心邻接信号）。可自行切换到内置无线时序或外部 Create RX。
- 感应复制目标类别、全向/前方、半径、内半径、末端宽度、视线和朝向。声音复制靠近音、受伤音、音量、音高、半径、冷却；环境音和接触音默认关闭。
- 战利品复制模板数量、概率、权重、抽取次数、名称、延迟和经验；原先使用 loot table 的来源继续使用该表。修改模板槽位或槽位规则后改用模板配置，打开界面会提示原表模式。
- 内置无线红石频道和其他已有虚拟模块不变。

## 来源与回退

原方块保留，不消耗材料或模板物品；完整来源参数备份保存在核心模块数据里。虚拟模块存在时，来源方块被接管，即使虚拟模块停用或重新标记也不会重新执行。来源位置随 Sable 搬移更新，重新标记的新位置与来源位置分开保存。

删除导入的虚拟模块会解除它对来源的接管，原方块保留的原设置恢复执行。备份不会自动覆盖来源方块，也没有自动恢复已被玩家破坏的来源方块。

本轮按用户要求不运行测试；仅执行 assemble，编译和 JAR 打包成功。尚未进行游戏内导入验收。

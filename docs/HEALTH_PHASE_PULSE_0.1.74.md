# 0.1.74 血量阶段脉冲与频道提示

## 新增行为

血量阶段模块新增「输出方式」和「脉冲时长」。旧版本模块默认保持区间内持续输出，无需重新配置。

- 持续输出：触发条件有效且血量在区间内时保持所设强度，不使用脉冲时长。
- 进入阶段时发一次脉冲：进入有效区间时发出一次，时长可设 0.05–600 秒，默认 1 秒。区间内继续受伤不会重新开始。离开区间或触发断电立即取消；重新进入或重新通电可发下一次。
- 激活时已在区间内也会发一次脉冲。关闭模块／Wireless、解除生命化、死亡或卸载后不保留旧计时；重新激活按当前条件重新开始。
- 一次攻击跨过多个阶段时只触发最终所在区间。

可将进入阶段的脉冲接到 Trigger Sound 做一次咆哮，或接到脉冲序列开始整套动作。连续动作仍可用阶段持续输出配合序列通电循环。多个来源共用频道时依旧取最高强度；若需要接收端识别新脉冲，请使用没有其他持续信号占用的独立频道。

主界面显示当前血量百分比和输出状态。输出频道输入框在不可用时变红并提供具体提示：未绑定、频道不存在、未启用、未设置频率物品、未使用序列模式。血量下限不小于上限时显示无效区间。脉冲完成后显示等待重新进入阶段。

修正频道号和信号强度直接输入小数时的处理，服务端统一取整，不再将小数悄悄截断。

## 本轮待测

1. 旧模块仍为持续输出；切换输出方式时左键下一项、右键上一项。
2. 进入阶段发一次脉冲，区间内反复攻击不会重发；测试 0.05／0.1／1 秒时长。
3. 脉冲未结束时离开区间或触发断电，应立刻停止；重新进入／通电能重新发。
4. 脉冲驱动一次咆哮与一轮招式序列；内／外 Create 无线终端信号正确。
5. 频道无效时红字与原因提示；血量百分比、无效区间和脉冲完成状态。

# 0.1.26 虚拟攻击测试

本版接入近战、喷火、箭矢与范围脉冲。虚拟感应、声音与肢体 Loot 奖励尚未执行；原有实体模块仍工作。测试虚拟模块时先移除同位置的实体攻击模块，避免两者同时攻击。

1. **Loot 区域**：上方三行绿色格可复制模板；下方铜色格只用于设置。空格悬停查看用途说明，确认不会把模板误放到铜色区域。
2. **近战**：休眠核心添加近战，标记同一肢体的两个角点。完整包含区域是攻击范围；伤害、击退、间隔、减益种类／时长／等级可设置。激活后让生物接触不同位置，移动或旋转手臂扫过生物，检查命中粒子与减益。默认间隔一秒；设为 0.05 秒可每 tick 结算。
3. **喷火**：在外露表面标记出口，默认朝标记面。激活后检查火焰宽度、伤害和燃烧时间；放墙挡住出口到目标的路径，应阻止伤害。内部被躯干遮挡的出口也会被挡住。
4. **箭矢**：标记外露出口，调数量、速度和散射半径。半径定义为前方 8 格处的散布宽度。多箭应朝外发射且不能拾取；伤害沿用箭速度与基础伤害计算。已发出的箭在模块停止后继续飞行。
5. **脉冲**：标记发射点，调整半径、伤害、击退、间隔与音效。预览显示球面轮廓；激活后出现音爆／环形粒子。墙后目标不能被命中。
6. **三个触发源**：分别用持续、标记处红石和无线频道测试。无线直接使用 Heart 原有 16 频道时序，关闭信号应停止对应攻击。面板显示“能力运行中”或“等待激活或触发信号”。
7. **停止和独立性**：重复添加两个模块，确认配置独立且可以分别叠加伤害；核心死亡立即停机。拆下攻击肢体后停止攻击，接回仍保持停用，需创造解除并重新标记。拆掉标记块再补回不自动恢复。
8. **保存重载**：参数、减益、标记和断肢停用状态应保留；不应从旧位置扫掠到重载后的新位置。卸载暂停能力，不发奖励。

自动验证：构建成功，94 项 GameTest 通过，包括五项新增虚拟战斗测试。粒子观感、UI 对比度及真实关节运动仍需客户端确认。

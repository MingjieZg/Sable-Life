# 0.1.28-dev：核心内置感应与声音

本轮 build 和全部 104 项 GameTest 通过；以下为客户端体验检查。

## 目标感应

1. 休眠 Heart 添加 Target sensor，标记一个保留的身体方块。选择玩家／生物／全部，先使用 Always 触发和关闭视线检查，方便确认基本范围。
2. 环形侦测包含对角方向，水平外半径、内半径和上下各 2.5 格高度限制共同生效。Preview 展示内外边界；前方侦测使用标记面的方向，可在参数中改方向，末端宽度渐扩。
3. 激活后以生存玩家或普通生物进入范围。创造玩家与旁观玩家不作为侦测目标。面板显示 Target detected / Redstone: 15 或 Scanning / No target。
4. 感应结果在标记方块处向六个方向输出强／弱红石。旁边放红石灯检查；攻击模块的 Anchor power 标记放在该点旁边，可使用同一生命体的对角邻接。
5. 原版红石传播也会经导电方块传递。若想驱动远处模块，可以在感应点旁放 Create 无线发射终端，由 Heart 外部 RX 接收同一红蓝频道，再驱动攻击。
6. 打开视线检查，墙体应阻断；切换环形／前方、内半径、目标类别，检查范围与实际检测一致。关节运动时前方方向跟随所属肢体旋转；环形仍为世界水平范围。
7. 关闭、删除、挖掉标记、断肢、核心死亡或创造解除均应停止感应输出；断肢停用锁存，重新标记才能恢复。卸载只暂停。

## 声音

1. 休眠 Heart 添加 Sound，标记声音发出位置。在原有音频库中分别设置 Approach / Hurt，以及半径、音量、音调和冷却。
2. 激活后第一次靠近播放 Approach；一直站在范围内不循环。离开后重新进入，超过冷却时间才再次播放。创造玩家也可以测试靠近音效。
3. 攻击生命体听 Hurt；短时间连续受伤受冷却限制。两个声音模块有独立配置及冷却。触发条件也支持 Anchor power、内部重复、外部 RX；无触发信号时不监听事件。
4. Preview 显示声音监听半径。声音从当前标记部位发出，随移动更新；断开、标记破坏、死亡、解除后停止后续事件音效。
5. 自定义 .ogg 仍使用测试实例专用音频文件夹与现有音频库，不需要重新创建声音方块。

实体声音／感应方块仍兼容；同类型虚拟模块标记在该实体方块上时，由核心执行，避免两套行为重复运行。本轮没有自动导入旧方块的参数。

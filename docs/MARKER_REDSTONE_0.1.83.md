# 无线红石输出面修正（0.1.83）

## 修正

无线红石之前同时提供弱信号与强信号，强信号可经相邻实心方块继续传到对角位置。本轮将无线标记输出改为弱信号，限制直接供电到指定的相邻格。导航与传感器保留原有强信号行为。

- 六面：右键选中的方块本身作为信号源，向上下左右前后六个相邻格输出，不将信号源移动到表面外那一格。
- 表面：仍以右键选中的方块为信号源，只向实际点击的那个面输出。保存的是右键事件的面，避免射向方块中心的校验射线误选另一个面。
- 预览改为贴在实际输出面上的绿色边框，不再用延伸到方块外数格的通用标记线。
- 已有标记坐标保持；如果旧版曾记错表面方向，需要重新 Mark 一次。
- 同一位置多个无线红石输出仍取最大强度；无线总开关、删除、死亡与解除生命化仍清理输出。

无线红石不再通过普通实心方块中继到第二层，需要较远传输请接红石线。方块自身原有红石行为保持，例如标记红石块不会禁用它原生的供电能力；红石线、其他供电源、导航或传感器也仍可按自己的规则传播。

## 自动验证

构建与单元测试通过，5 项游戏测试通过：

1. 灯阵六个直接相邻格亮、四个水平对角格与源方块不亮。
2. 六面切换表面后，延迟熄灯完成时只保留选中的那个方向。
3. 表面模式六个法线分别验证，源坐标不偏移；总开关关闭后清理。
4. 原有招式调度 → 序列 → 标记点 → 原版灯联动。
5. 共用标记强度合并、单面方向、删除不影响其他输出、死亡清理及调度频道约束。

## 本轮待玩家检查

- 在原灯阵重新 Mark：六面仅六个相邻格，表面只选中的一面，对角不误亮。
- 分别点击顶面、底面和四个侧面，绿色预览框与实际右键面一致，尤其从斜角点击时。
- 旋转后的 Sable 部位、保存重载与 Photomancy 复制后，表面方向仍一致。
- 红石线及 Create 设备正常接收；若之前依赖实心方块中继，需要改接红石线。

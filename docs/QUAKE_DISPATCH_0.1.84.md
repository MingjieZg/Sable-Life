# 0.1.84：地震采光与招式调度界面

地震弹起模型改用地表上方的光照，避免弹起不足一格时采到地下黑暗。保留昼夜与附近灯光，不强制全亮。

招式调度默认显示 7 个常用属性：启动序列频道、目标类型、最远距离、冷却、选中机会、最短招式时长、招后停顿。点击「高级条件」查看血量范围、近距离、方向、遮挡、重复与启动信号参数。切换页面不重置原来的条件；每个属性悬停都有独立说明。

## 最小使用例子

1. 无线频道 1：开启、放入频率物品，模式设为 **Sequence / internal**。
2. 喷火招式的 Pulse sequence：Trigger 设为内部频道 1，单次执行，断电停止关闭。在序列里安排动作和攻击频道。
3. 添加一个 Move dispatch，命名「喷火」，启动序列频道填 1，Trigger 保持 always。
4. 想加另一招，就再建一个序列及独立启动频道，再添加一个调度模块。系统从满足条件、冷却结束的招式中按权重选择，等动作序列结束，再停顿并选下一招。

**调度选招并启动序列，具体生物动作和攻击依然由你配置的序列及红石频道控制。** 最短招式时长不是强制截断；序列还在运行时会继续等待。此招冷却从开始时计时。

## 本轮需要手动检查

- [ ] 地震弹起高度 0.1／0.5／0.9／1.5：草方块和石头是否正常显示，不再整块黑化。
- [ ] 夜晚、洞内和灯旁：弹起模型亮度是否接近地表环境，结束后无残留。
- [ ] 调度常用／高级条件切换，50% 字体下是否易读；输入数值后切换能保存。
- [ ] 已有调度模块的血量／方向等高级条件保持原值；翻页与其他模块正常。
- [ ] 按上面例子连接两招，检查启动、等待序列结束、冷却和招后停顿。

客户端画面尚需上述实机检查；没有自动开启或关闭客户端。

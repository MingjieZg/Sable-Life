# 0.1.98 悬浮弹形状

- Formation shape：弧形 ∩（默认）、直线 —、五角星、圆形 O、斜线 \、斜线 /。
- 删除正面／侧面分选，保留 Fan rotation -180°–180°，绕排列中心旋转形状。0° 弧形向上拱起；90° 变为侧向弧形。
- 顶面／底面标记仍保持形状的上方轴，不影响 Mark 到悬浮终点的展开方向。
- 弧形与直线／斜线的宽度受 Fan angle 和 Hover distance 控制；圆形与星形使用完整轮廓，半径取 Hover distance，Fan angle 不改变闭合轮廓。
- 星形建议 10 发可显示交替内外顶点，5 发只分布在五个外尖角；圆形建议 8 发以上。所有形状保持 1–32 发，单发都在中央。
- Preview 和实际展开共用位置；展开、蓄力、追踪、声音及粒子行为不变。
- 0.1.97 的两种弧形合并为弧形，两种直线合并为直线；更早的三种扇形合并为弧形，旧 Fan rotation 保留。旧正面／侧面区分不再单独保存。

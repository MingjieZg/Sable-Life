# 0.1.67 喷火直接命中

喷火新增“命中伤害无视抗火” On/Off，排列在伤害之后，默认开启；旧模块未保存该字段时也使用开启默认值。

开启：接触火焰前沿时按配置 Damage 造成正常物理伤害，受护甲、保护及抗性提升等普通减伤影响，抗火药水不免疫直接命中。关闭：保留原版 inFire 火焰命中规则，抗火可免疫。

两种模式的后续着火仍由原版燃烧处理，抗火继续免疫燃烧扣血。命中范围、前沿轨迹和伤害间隔不变，不叠加第二份命中伤害。

编译验证：assemble。游戏待检查：喝抗火后命中仍扣血但停止接触后无燃烧伤害；无抗火时正常命中及后续燃烧；关闭开关后抗火免疫；护甲仍对直接伤害减伤。未重启客户端。

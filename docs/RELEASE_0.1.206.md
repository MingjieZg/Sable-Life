# 0.1.206 — 可选 Arena 自动重生与物理法术补完

开发验证版，稳定仍 0.1.200。Minecraft 1.21.1 / NeoForge 最低 21.1.235；协议保持 7。没有自动升级稳定版本。

## Arena 重生

Arena 属性增加自动重生、间隔（1–3600 秒，默认60）、记录当前结构和清除记录。Photomancy 仍 optional；只有精确核对的 sable_schematic_api 1.0.1 开启重生能力。没有该模组时，控件禁用，生命核心/其他模块正常运行。记录和清除要求创造模式管理员、当前菜单/模块/revision 校验；客户端不能上传模板内容、坐标或 UUID。实际模板由服务器读取当前相连结构生成。

ArenaRespawns SavedData 保存独立模板与当前生命体/模块绑定、剩余时间、旧/新身体 UUID、增量建造进度。模板不进入核心或 GUI NBT，普通蓝图/预设复制不会自动继承世界任务。每服务器/世界最多32条记录；单次捕获最多32部件、32768包围体素访问、16384方块、1024方块实体、256实体、1 MiB 模板。

死亡通知来自 LifeLifecycle.schedule。倒数始于死亡，不以核心是否存在推断死亡。真正的模板世界区域未加载就暂停，不主动取世界区块。倒数结束还须 LifeLifecycle 完成旧主体及脱离部位清理，且旧身体不再注册。每服务器每 tick 最多推进一份建造，公平轮转。使用 Photomancy SableBlueprintIncrementalPlacer 和持久 BlueprintBuildProgress；每次块阶段预算128方块、16方块实体、8后处理、2ms（第三方 API 的最终提交不保证所有操作均被这个预算切分）。最终验证模块绑定后才满血激活，沿用正常 activation/ownership/wireless/保护流程。

记录的姿态以 Arena center 为原点。legacy plan.bounds 实际为空，已改用导出的 canonical bounds 加目标原点检查世界区块。分批稳定姿态时，将新存储 plot 的 rotationPoint 相对 blockOrigin 换算到蓝图坐标，避免把存储枢轴当世界位置。世界位置、标记迁移、完整库存和保存恢复有真实测试。

默认增量 API 清洗 NBT 会移除库存。完整 NBT 只对本适配器持有的、管理员在服务器实际记录的那个 blueprint 对象启用 ThreadLocal identity scope，finally 恢复；不修改全局默认策略，不对上传或其他工具开放，仍保留 DENY。原本已批准的命令模块可从可信模板恢复批准；本来待批准的仍待批准，普通蓝图复制的审批行为不变。

场地中心使用不碰撞的 vanilla TextDisplay 展示倒数/20格进度条，每个状态/秒/填充变化才更新同步字段。原生 invoker 更新 text/billboard 等字段，不反复加载整实体 NBT。显示 UUID 与记录持久关联，卸载时不忘记未清理实体；EntityJoinLevel 丢弃已取消/已完成记录的旧显示。没有生命体实体代理。管理员站在中心64格内用 /sablelife_respawn cancel 可取消并清除仅属于该任务的已知部分身体；正常存活重生体不会因为清除记录而删除。异常停止并日志记录，不无限重试生成。

## 剩余四种魔法

用户确认0.1.205多数魔法正常，并要求指定系全部忽略。本轮没有给身体添加 entity target/锁定能力。核对原法术发现这四种均可通过物理路径执行：

- 苦力怕迫击炮 CreeperHeadProjectile：原生平方距离衰减及范围，通过覆盖 onHit 的专用接口转接身体；保留原爆炸特效/消失，不模拟连锁杀死 LivingEntity 回调。
- 神圣打击 DivineSmiteSpell：原生前方区域盒与法术＋武器伤害，并修正局部粒子地面射线的世界命中点。不是必须指定生物的法术。
- 唤魔尖牙 ExtendedEvokerFang：原生延迟至 -8 的一次啃咬攻击盒。FangStrike 地面查找修正世界坐标，并把被攻击的生命身体当作受害者而非其脚下的地面，继续找真实地面；悬空目标不凭空生成地面尖牙。
- 霜降 IceBlockProjectile：悬浮不伤害；下坠实际碰撞盒接触半伤害并消失；原生落地爆发使用3.5半径/三次方衰减。普通生物目标获取不变，原生无目标射线 fallback 可生成冰块，未为身体伪造目标。

不新增指定生物系适配，不模拟非 LivingEntity 身体的冻结/毒/火状态及原实体专用事件。霜降是实际冰块落下，并非此前纯冻结的 FrostField。

## 验证

- 96 项真实铁魔法（51）、重生（6）、Arena、审计与防御组合回归。
- 25 项重生/Arena/生命周期/旧清除回归。
- 真正移除 Photomancy runtime 后40项相关回归，包括生命激活与禁用重生；没有API类加载异常。
- 290 默认完整GameTest；57单元；独立客户端16种GUI缩放/密度可选能力控件检查，截图检查通过。
- 手册 revision58，45章/32模块/中英四分页。

测试危险路径：完整蓝图和库存、满血即时激活、标记及 UUID 迁移、260方块建造中保存/恢复、两代循环不重复、部分任务安全取消、未加载暂停且不强制加载、权限拒绝。FakePlayer 原生禁止命令权限，正向测试使用显式管理员角色；各模板使用唯一名称防止误认前一场生命体。不能把这些自动检查视为原整合包所有关节、绳索或第三方炮体都已验收。

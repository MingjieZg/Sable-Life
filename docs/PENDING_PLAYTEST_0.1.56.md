# 截至 0.1.56 的待游戏内检查清单

2026-10-03 用户反馈：此前清单已测试完毕；场地边界的越界警告单独反馈未触发，保留为待复查项。下面保留原检查内容作为历史记录；0.1.58 新改动见 UI_GROUND_STRIKE_0.1.58.md。

依据版本记录和聊天中的验收反馈整理。编译成功不等于游戏内验收；下列项目未收到明确验收反馈。早期已经确认正常的全方位侦测、断肢 Loot、外部 RX、基础攻击及 BGM 播放不重复列为新功能，但列出与新功能有关的回归项。

## 1. 核心界面与分页（0.1.44–46）
- [ ] 核心设置：名称、最大生命、死亡延迟、经验值输入与保存正确；Boss bar、破坏开关明确显示 On/Off。
- [ ] 数值输入悬停滚轮增减、Enter、应用按钮正常；输入时库存快捷键不抢输入。
- [ ] 100% / 85% / 75% 密度切换、重启记忆正常；不同窗口和 GUI 比例无遮字/重叠。
- [ ] 模块/添加列表每页 8 项，属性紧凑模式每页更多项；翻页后修改的是正确属性/模块。
- [ ] 标记、预览、子界面返回仍停留在之前选中的模块。

## 2. 无线频道（0.1.41–44）
- [ ] 打开无线界面不再断线；从空列表新增、多页新增、删除首/中/末频道正常。
- [ ] 删除频道后其引用解绑，后续引用前移；新频道不会误触发旧引用。
- [ ] 时间滚轮每步 0.1 秒、信号强度每步 1；外部接收模式不能修改不适用的时序。
- [ ] 内部 repeat 只控制核心；外部 RX 接收 Create；外部 TX 按频率、时间和强度输出给外部 Create 接收器。
- [ ] 修改频率/模式、总开关关闭、删除、解除生命化、卸载后没有遗留无线信号。

## 3. 喷火、枪与迫击炮（0.1.41–47）
- [ ] Bullet hitbox 最大 2.0，旧值截断；高速子弹、墙体与边缘命中符合尺寸。
- [ ] 喷火从出口逐步推进；转动机械时旧火焰保留原方向，新火焰随出口转动；墙体截断，关闭停止伤害。
- [ ] 枪/迫击炮自定义发射物样本不消耗物品，清空/恢复默认正常；外观保存、复制并同步。
- [ ] 自定义外观不改变枪直线、迫击炮抛物线、碰撞和爆炸规则。
- [ ] 迫击炮警示圈、爆炸范围/视觉/伤害一致；每轮目标当前位置重新瞄准。

## 4. 声音与 BGM（0.1.42–47、55）
- [ ] 所有音效左键下一项、右键上一项，首尾循环。
- [ ] MC 文件夹导出并打开本体音效浏览副本；OGG 文件夹打开自定义目录。
- [ ] BGM 顺序为音频、开始方式、范围；进范围播放/首次受伤播放两种模式正确。
- [ ] 离开渐弱，重新进入按规则重播；攻击反馈、触发音效与 BGM 重叠且不重置音乐。
- [ ] 禁用、删除、死亡、解除生命化后停止对应音频；旧 approach/hurt/ambient/contact 正常。
- [ ] 触发音效：短红石脉冲播完整咆哮，持续供电 Once 不重复；冷却内快速开关不刷音。
- [ ] Repeat 按间隔/冷却重复，断电停止新播放；Always、内部无线、外部 RX 正常。

## 5. Heart 材质与扳手（0.1.48）

- [ ] 生存材质消耗/返还、Sable 搬移、存档重载正常；不损坏原有核心数据。

## 6. 多重附加效果（0.1.49）

- [ ] 即时效果与模组效果正常；爆炸范围内目标获得效果，直接命中不重复结算同一炮弹的即时效果。
- [ ] 重载/数据复制保留列表；旧近战效果迁移，清空后不再恢复。

## 7. 目标对准 / Navigation（0.1.50–51）

- [ ] 目标选择/锁定、预览、旧配置保持正常；实际接线到机械执行器验证。

- [ ] 整部位预览跟随；断开/卸载、重载/复制、死亡清理正常。

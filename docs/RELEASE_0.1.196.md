# 0.1.196 实测反馈修复

开发验证版。稳定版仍为0.1.193；0.1.194和0.1.195历史及导出保留。

## 修复及原因

- Copycat伪装材料：Create在onRemove中直接调用Block.popResource，绕过战利品过滤。补上归属方块材料掉落过滤（包括popResourceFromFace）。死亡/部位清理保留归属直到移除回调结束；普通非生命体Copycat仍返还材料。未对世界所有掉落实体做全局删除，也不影响自定义死亡战利品。
- CBC炮体残留：炮台remove调用disassemble会把已装配炮体重新放回世界。仅在带ownership的炮台死亡/部位清理期间，移除真实装配炮体实体并跳过放回方块。普通炮台和固定炮台均覆盖；普通拆卸保持。没有给生命体增加实体代理，也没有改炮体伤害判定。适配实际验证CBC5.11.7的接口，不承诺所有未来版本。
- Sphere Blast：没有飞行物实体的地形爆炸现在通过专用ExplosionDamageCalculator携带攻击者UUID。与现有生命体爆炸保护共用自身及目标攻击权限过滤，打开允许爆炸破坏也不允许自己的球爆拆掉自身。地形破坏开关及配置伤害保持，地形爆炸不重复施加实体伤害。
- 最大自适应减伤：服务器、客户端输入上限和提示由95%改为100%。DPS公式及低于阈值行为保留；填100%并不表示始终100%免伤，仍随输入DPS计算。
- 无线频道：主菜单仅有两个频率样本槽，不再注册隐藏玩家物品栏。选择频率物品打开与模块共用的独立选择页，支持复制/清除频率物品且不消耗物品，返回原频道。可避免其他GUI模组画出隐藏物品槽。
- 滚轮：核心每秒回血regen ±5、百分比回血regenPercent ±5个百分点、回血延迟regenDelay ±1秒。其他已指定步长不变。

## 验证

- 最终build成功，57项单元测试无失败/跳过，包含指定滚轮及100%减伤边界。
- 269项默认GameTest全部通过。
- 真实TaCZ/CBC依赖下125项组合GameTest全部通过；与默认存在重复，不能相加当独立覆盖数。
- 新增真实Create Copycat移除回调：归属清理不掉材料，非归属拆除仍返还材料。
- 新增原生爆炸事件/最终移除：携带模块攻击身份后保留自身玻璃，同时破坏普通玻璃。
- 新增真实CBC普通/固定炮台移除：清理不放回装配炮体，正常disassemble仍执行。
- 独立频率页复制到正确频道、不消耗物品、Back保留频道；主页面槽结构无玩家库存。
- 隔离客户端无线主页/频率选择页预览通过，并查看截图确认布局。
- 最后新增的滚轮改动仅改变客户端输入步长，单元测试与最终build重跑；不重复已通过服务器全量回归。

证据：verify196-complete.log、verify196-fixes2.log、verify196-wireless-ui.log、verify196-final-build.log、build/test-results/test。

## 用户实测结果与限制

用户确认各缩放下模块列表/页面正常，以及复制后每个个体Move set正常运行。用户未手测权限、深层/大型异常输入和预算，不能把它们记为用户实测通过；这些已有自动化边界回归。没有真实长期多人TPS压测。Copycats附加模组的完整组合及具体玩家世界仍需用户回测；自动用例使用真实Create Copycat回调与已安装CBC。

0.1.195中Sphere Blast风险已有用户实测确认，本版修复其缺失的攻击者身份；全物理场景仍需实测，不把原本无效的射线测试算作通过。

网络协议由5升到6，因为无线菜单槽布局已变；客户端/服务器同时更新0.1.196。回退请使用之前备份，新版本不自动提升稳定。

# 0.1.75 牵引模块

## 标记与落点

新增虚拟模块「牵引」，标记一个 Sable 身体方块的表面即可。落点为该方块中心沿所点面法线移动 0.55 格，再加「沿标记面向外偏移」；随该部位平移／旋转。默认额外偏移 1 格，因此落点距所标方块中心 1.55 格。

被牵引目标以自身碰撞箱中心靠近落点，在「停靠距离」附近减速，默认 0.8 格。绿色十字显示落点，绿色小圈显示停靠距离。不会直接传送、不删除地形，也不绕过方块碰撞；选择外露面并用预览检查落点是否被其他身体方块遮住。

## 警示和躲避

1. 触发有效且范围内存在符合目标类型的生物时开始警示。默认捕获半径 8 格、警示 1.5 秒。
2. 橙色三圈显示真正的球形范围，向内收拢的粒子提示蓄力。每轮警示范围固定在开始时的世界坐标，避免机械移动时范围暗中追着玩家跑；实际绿色落点继续随部位移动。
3. 警示结束时只捕获仍在球形范围内且符合视线检查的生物；提前跑出可躲避。启动后新进入者不会补抓。
4. 牵引时边界变蓝，默认持续 2 秒。离开原球形范围，或开启视线检查时被外部墙体挡住，则永久退出本轮捕获；重新进入不会再次被抓。
5. 横向速度保留，力度可以调低，让冲刺、横移或其他移动技能挣脱。关闭视线检查允许隔墙施加牵引力，但实际实体移动仍由游戏碰撞处理，不会穿墙传送。
6. 本轮结束后冷却，默认 3 秒；触发断电、关闭模块、断肢、死亡、解除或卸载会取消警示与牵引，并停止本模块的音效。

默认只对生存／冒险玩家生效，可切换为非玩家生物或全部；创造和旁观玩家不受影响。每轮最多捕获 64 个，优先较近目标。警示和捕获都使用目标碰撞箱中心与球形距离，不使用地面圆柱判定。

不直接造成伤害、不施加药水。需要咬击／爆炸等后续招式时，可通过已有红石序列接其他攻击模块。

## 属性

目标类型、捕获半径 1–32 格、警示 0.25–10 秒、牵引持续 0.05–10 秒、结束后间隔 0.05–600 秒、牵引加速度 0.01–1 格/tick²、最大向内速度 0.05–2 格/tick、向外偏移 0–8 格、停靠距离 0.25–4 格、视线检查、警示音效、牵引音效、粒子列表。

音效使用现有左键下一项／右键上一项和 MC／OGG 双文件夹；粒子使用已有左右双列表，支持右键快速添加／移除。额外选择的粒子在牵引落点出现，默认警示与落点颜色保持可辨识。

所有属性和标记使用通用模块存储，可随存档、数据复制器及 Photomancy 复制。捕获名单与警示／牵引进度不保存；重载后重新警示。

## 验证

build 通过，新增 4 项单元测试覆盖警示／牵引／冷却时长、取消后重新警示、速度上限、向外惯性与近点减速。未启动客户端，未验证玩家运动同步、Sable 移动碰撞或躲避手感。

## 本轮待测

1. 标记前／上／下等不同表面；预览绿色落点、偏移和停靠距离。移动／旋转部位后实际落点跟随。
2. 橙色球形警示固定；警示结束前离开可躲避，启动后新进入不补抓。
3. 被拉目标离开范围或躲到墙后能退出；再次进入不被本轮补抓。视线检查开关符合预期。
4. 牵引力度／速度、横移挣脱和近点减速；站立、跳跃及空中状态的同步和手感。
5. 不穿地形／身体方块；多人和玩家／生物目标筛选，创造／旁观免疫。
6. 音效切换、MC／OGG、双列表粒子；断电、停用、断肢、死亡、解除／重载无残留。
7. 属性保存、数据复制器及 Photomancy 后重激活。

# 0.1.285 信号逻辑与战斗事件信号（开发版，2026-10-29）

## 信号逻辑 / Signal logic

新增信号分类核心模块，无需Mark。属性包括全部条件（AND）／任意条件（OR）、条件编辑入口、输出频道、信号强度、持续／条件上升沿脉冲和脉冲时长（仅脉冲模式显示）。默认AND、输出未绑定、强度15、持续模式、脉冲0.5秒。

每模块最多16行输入条件，可各自启停，设置从1开始的内部频道及有信号／无信号。输出必须使用已启用的序列控制／内部频道。空条件、全部停用、启用条件存在无绑定／缺失／未配置频道，或输入使用本模块输出频道时，都不输出；NOT不会把无绑定当作无信号。

所有逻辑模块先采样统一输入，再一次性合并写出结果。逻辑链每服务端刻推进一级（0.05秒），不随列表排序变化，不递归求值。间接反馈同样只逐刻采样，不提供自动锁存。持续模式在条件不成立时关闭；脉冲由不成立变为成立时启动，按设定时长播放，条件持续成立不重播。停用、失去Trigger、删除、总开关关闭、重载或解除清理运行状态。既有Wireless锁存可继续用来记住转阶段完成状态。

## 战斗事件信号 / Combat event signal

新增信号分类核心模块，编辑器沿用现有多行规则方式，最多64条独立规则。每条设置事件、筛选、攻击来源（可搜索选择全部／指定攻击模块）、输出频道、强度、脉冲时长、冷却和启停。默认击杀玩家、全部攻击、输出未绑定、强度15、脉冲0.5秒、冷却1秒。

事件：

- 造成击杀：筛选玩家、普通生物、其他生命体或全部。使用真实伤害来源中的生命体和模块归属；普通实体走原生LivingDeathEvent，机械目标走现有伤害结算入口。取消死亡、创造／旁观目标、无归属的死亡不计入。脱离攻击后无法归属到模块的原版燃烧死亡不追认。
- 部件脱离／摧毁：监听任意独立部件，或事件模块Mark指定的独立部件。Mark仅这个筛选需要，其他事件不需。沿用Sable连接关系及部件移除，不增加部件血量。监听期间建立部件观察基线，既有脱离或整个生命体死亡／解除不补发事件；暂时缺失但未确认移除的部件不当作摧毁。
- 攻击被格挡：筛选原版盾牌、已适配防御／招架或两者。原版盾牌事件及已有近战／Slash的Epic Fight桥接提供结果，成功格挡后输出；破防不发成功格挡事件。Slash默认不可格挡，需开启上一版的可被格挡选项。零直接伤害Slash被盾牌或已适配防御挡下也可产生事件。

多条规则独立冷却，同事件可输出不同频道。没有匹配的归属、已删除的指定攻击模块不自动变为全部来源。击杀和部件按对象去重，同刻相同来源／目标格挡去重；每条只有一个待处理脉冲标志，不维护无界事件队列，短脉冲在下次模块处理时启动而不因事件发生在本刻模块运行之后丢失。重触发刷新剩余脉冲，不叠加信号强度。

## 编辑、持久化与引用

两个模块支持既有Always、内部／外部频道、Move Set及受伤Trigger。规则编辑沿用核心休眠时可编辑、激活时只读的权限，验证容器、距离、模块身份、全局Revision和数值范围。规则面板独立左右分页，数值支持输入、确认、滚轮，保持正在编辑的草稿。攻击来源选择器支持搜索。

配置保存在核心NBT，本地Copy深拷贝规则；预设解除频道及来源绑定。Sable schematic通过同一放置UUID映射转换事件攻击来源，保留频道数字配置；整份核心配置复制同样转换事件、命中计数和持续范围模板引用。运行事件、冷却、脉冲及部件观察状态均不持久化。现有稳定版本与移动行为未更改。

例：血量阶段持续输出4，转阶段动作末尾触发既有锁存5；AND两者输出6，驱动常驻粒子。击杀玩家输出8可连接回血／声音；指定手臂脱离输出9连接暴怒；斩击被挡输出10连接后续招式。

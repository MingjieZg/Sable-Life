# Melee 范围偏移与命中上限（0.1.135）

## 两点范围与偏移

两个Mark仍定义包含边界方块的长方体，保留原标记与尺寸。第一个标记面的方向作为前方。

- Start distance：0–128格，沿经过角度修正的方向平移整个范围；默认0。
- Horizontal offset angle：-180–180度，正值向右；默认0。
- Vertical offset angle：-90–90度，正值沿标记面的相对平面向上；默认0。上下标记面使用固定的结构局部X轴作为右方参考。
- 角度既调整平移方向，也绕范围中心旋转整个区域，随后跟随所属结构运动与旋转。
- Preview直接使用相同的中心、尺寸和旋转，不另外计算一个显示区域。

旋转扫掠现在保存结构姿态和范围局部偏移，按插值结构姿态生成接触盒，避免把范围中心连成直线。瞬移保护基于结构原点位移，不再把远端普通转动误当超过8格跳跃；采样上限512。旧配置角度默认0，范围位置保持兼容。

## 每次连续激活的命中上限

属性名称：Hits per target (0 = unlimited) / 每目标命中上限（0 = 无限次）。

- **0 = 无限次，仍按Interval间隔结算**，不是每tick无限伤害；默认0保留旧行为。
- 正数1–1024：每个目标独立统计本次连续触发期间成功的直接Melee命中次数。
- 只有伤害被接受的接触才计数；未成功伤害的尝试不消耗次数。
- 达到上限后，该目标不再受此模块攻击；其他目标仍有自己的额度。
- 离开攻击范围再进入不会清除次数。
- 断信号、禁用模块、生命体停止/运行重载会清除运行窗口；下一次激活从0开始。
- Move set有明确断开间隔的两个动作窗口分别计数；若同一模块连续供电没有断开，仍视为同一个窗口。
- 上限不保证打满。例如持续0.5秒、Interval1秒、上限3，通常只来得及命中1次。Hurt Once的单tick窗口也不会因上限大于1而自动延长。
- 次数只针对直接命中，附加效果本身造成的持续伤害不算额外Melee命中。

## 示例

一次横扫想让同一目标最多受伤1次：命中上限设1，将模块加入Move set并设置有效攻击窗口。另一招重新触发时，只要中间有断信号，就会获得新的1次额度。

持续伤害区：上限设0，Interval设0.5秒，在整个触发期间每个接触目标最多每0.5秒结算一次。

范围偏到嘴前右侧：选择第一个Mark面为前方，Start distance设3，水平角设30，垂直角设0；Preview检查整个长方体的位置与朝向。

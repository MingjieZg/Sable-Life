# 0.1.247 快速连续波纹修正

开发版，稳定版仍0.1.243，网络协议14，客户端和服务器一起更新。

修正高频释放中心阶段消失：旧客户端保存8道事件，而渲染器和shader只有4个槽。同位置按距离排序使旧波先占槽，新波排队后开始绘制时已经离开中心。现在8道保留事件都有对应渲染槽，并优先处理新事件；超过8事件淘汰最旧，保留最新中心阶段。仍只使用一次颜色复制与一次绘制，没有增加渲染pass数量；每像素最多检查8道波纹，第三方光影仍需实际验收。

缩放正值单项上限与叠加上限都回退到30；负值下限保留-100。这样连续30不会再叠加到100。双语提示及手册同步。

验证：94项控制专项原生GameTests通过；GPU模拟同位置8道并发波，间隔1/2/5/9tick（0.05/0.1/0.25/0.45秒），第8道最新波均在中心产生可见像素变化（104/70/64/64）。单波局部性环内5460、环外0，半径30长短扩散对比、背后/禁用/过期、状态恢复和resize通过。jar与双语手册90校验通过。未重跑全套358、原整合包及JUnit。

# 0.1.214 — 地面重生提示与放置须知

计时器定位与模板重生高度分开。Arena中心X/Z保持，优先在锚点下方找到有碰撞顶面、上方两格空间清空且无液体的地形；上方可站表面为后备，无地形支撑时保留锚点+2.5。提示在表面上方2.5格。不读取Sable移动身体为地面、不创建区块、不自动把模板贴地。只在提示内容刷新时定位/移动，避免每tick地形扫描或重复同步。

提示靠近地面后，即使原锚点高出64格，管理员也可在实际提示或锚点64格内使用取消命令。仅验证同任务TextDisplay标记，取消范围仍64格，不扩大结构删除范围。

核对原生Exporter.coordinateFrame和BlueprintPlacementPlan.legacy：非空模板以所选主体portable basisAnchorPose作为规范化原点，不直接使用请求Arena中心作原点。旧手册「相对Arena中心记录」表述不准确，已纠正。Arena中心放置的是规范化基准锚点，不一定是所有部件的底部；大型模板部分部件可能低于锚点，过低放置与地面/其他结构重叠可能造成推挤、弹射或关节受力。改变Arena中心改变重生位置，记录不会自动贴地。这次不改变原生重生计划。

双语Arena Usage添加分段重生须知，Settings同步计时器与锚点区别、取消位置及虚空后备。手册65。开发0.1.214，稳定0.1.200。

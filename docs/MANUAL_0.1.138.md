## 扩充方式

结构位于`assets/sablelife/manual/catalog.json`，目录带revision。章节id稳定，sections四组是翻译键，module引用现有类型，timeline引用模块并提供start/duration。界面无需针对章节编写Java。

正文位于en_us/zh_cn语言资源。优先复用现有模块名称，英文修改后同步翻译并递增revision。初始内容的维护来源为`scripts/manual-content.py`；修改已有内容时同时修改该来源，避免重新生成覆盖。

运行`scripts/validate-manual.py`检查模块覆盖、章节ID、四页签、双语正文和时间线引用。独立`runManualPreview`不打开世界，验证工厂字段标签、搜索、页签、返回，并生成英文GUI scale 2与中文GUI scale 3截图。

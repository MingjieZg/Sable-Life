# 0.1.305 召唤武装阵型与逐个部署（2026-10-31）

召唤武装新增数量1–32（默认1），复用悬浮追踪的八种部署布局：弧形、横排、水平/垂直星形、水平/垂直圆环、两种斜线。直线/斜线使用相邻间距0–32格；其他阵型使用半径0–32格，弧形另有0–180度展开角度。阵型平面旋转/水平旋转各±180度，只改变武装的生成布局，与物品模型XYZ校正、瞄准角度和发射口偏移独立。数量滚轮±1，阵型半径/间距±1格，相关角度±5度。数量1隐藏阵型属性，并保留0.1.304的中心位置和行为。

生成间隔0–10秒，默认0同时出现；其他值按序出现。每件从自己的出现时间开始计算完整存在时长，整组结束时间为最后一件生成时间加其寿命。每件独立运行Gun/Arrow/Flame/Laser计时、瞄准、发射口和声音，命中仍归属被引用攻击模块。运行面板显示当前运行数/总数、待生成数和整组剩余时间。持续通电时整组只生成一次，重新触发/下次Move set激活重建；关闭触发会移除已生成武装并取消后续队列，寿命不能越过提前关闭的触发。

跟随模式保存阵型在部件本地的偏移，整组随部件平移/旋转。世界模式在触发时锁定全部预定位置，包括稍后才生成的成员。目标与模型朝向仍各自独立。未加载的生成位置不强制加载区块。预览显示所有阵型位置、模型轴和发射方向，大数量降低单件预览采样。

悬浮追踪和召唤武装共用DeploymentFormation；悬浮追踪保留原有中心、半径、展开角度控制的直线宽度及旋转规则。召唤的直线使用独立间距。旧模块缺少新字段时默认1件，预设保存新阵型配置，跨模块引用规则沿用原版本。

# Sable Life 0.1.445

## 功能

- 核心碰撞破坏支持草、花、蕨和蘑菇等无碰撞体装饰物，使用其方块外形检测实际接触；流体不按此方式破坏。脚底保护只保留真正的实体支撑。
- “地表／植物预设”补充常见自然植物与花、树苗、树叶标签。它仍是不破坏清单：点击后合并、保留已有项目并去重。已有世界清单不自动更改。
- 近战新增“破坏方块”，默认关闭。使用当前攻击框及扫过范围，支持原有距离、扩展和角度设置。只处理已加载世界方块，跳过其他Sable结构、保护清单与不可破坏方块。
- 近战沿用核心的方块掉落偏好；无需开启机身碰撞破坏，也不采用其延迟和脚底保护。生存核心每成功破坏一个方块按配置的近战费率扣能量，失败退回本次费用。

## 兼容与限制

- 原模块、预设、蓝图缺少新开关时默认关闭；已有字段、ID和标记含义保持。联机协议50，手册246。
- 地形清理按每核心／每维度工作预算执行；大范围可能分多tick，极快的扫过不保证清空全部方块。停用、解除、卸载或范围变化不保留旧扫过路径。

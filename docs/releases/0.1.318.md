# Sable Life 0.1.318

- Fixed stale Life protection blocking Photomancy blueprint placement when deleted body storage is reused. This could cause incomplete structures or an `empty plot bounds` error, including for blueprints without a Life Core.
- Kept deletion and replacement protection for existing living blocks.

Existing blueprints do not need to be saved again. Previously incomplete placed copies should be deleted and placed again from the original blueprint after updating.

Validation: 67 unit tests and 73 related server integration tests passed, including 13 consecutive placements on reused storage and checks that existing living blocks remain protected. The affected player also confirmed that original blueprints now place correctly in the previously failing world.

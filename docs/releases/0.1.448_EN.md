# Sable Life 0.1.448

## Core Remote default

- New world/server configurations default `allowCoreRemoteWithUnsupportedClaims` to `true`. Unavailable claim integrations no longer require an initial opt-in.
- Existing saved values remain unchanged. A saved `false` still rejects unsupported integrations until the server owner changes it manually. Set `false` when strict rejection is desired.
- Supported claim permission checks, denied/failed checks, editing eligibility, range, dimension, loading and world protection retain their previous behavior. This is a default change, not a new claim-mod integration.
- The setting also covers Core Remote-based inspection. Both manuals and the configuration tooltip reflect the new default. Protocol50, manual249.

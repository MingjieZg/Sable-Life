# Sable Life 0.1.442

Changes since 0.1.440:

- Administrators can use `/sablelife blueprint spawn <name> <true|false> [x y z]` to place server blueprints, with Tab completion. Without coordinates, find ground across the blueprint footprint at the execution X/Z. Optional coordinates place the bottom center directly. true activates its Heart Core after placement; false leaves it dormant.
- `/sablelife help` and bare `/sablelife` list command syntax and concise purposes. Anyone can read help; placement, inspection, damage, cleanup and Arena respawn cancellation still require permission level 2.
- Command jobs use independent saved records, with eight pending jobs and at most one native placement per tick. Unloaded chunks, occupied space and template limits reject placement. Failed or interrupted placement is cleaned up without replaying the spawn.
- Both manuals document commands, revision 242. Existing cores, blueprint modules, Arena records and public extension formats retain their meaning.

Use the same 0.1.442 build on clients and server. This local preview has not been published.

- Command help now shows only syntax and concise purposes. Removed repeated permission labels and the long footer; access checks are unchanged.

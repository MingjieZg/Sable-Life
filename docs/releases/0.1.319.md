# Sable Life 0.1.319

- Added Wireless Redstone signal ramps with configurable start/end strength and duration.
- Ramps stop immediately when activation ends, including shortened Move Set actions. Reverse controls are disabled in Ramp mode; swap the endpoints for a descending ramp.
- New Wireless Redstone modules default to selected-surface output. Existing saved selections are preserved.

The same ramp drives marked-surface, internal-channel and external-frequency outputs. Fixed and Follow input modes retain their previous behavior. Ramp settings are available on both core types when the module is enabled by server configuration.

Validation: 72 unit tests and 32 server integration tests passed. An isolated native client captured the Chinese Ramp properties page and checked endpoint layout/edit focus and disabled controls.

# Sable Life 0.1.404

## 自定义模块

- Java 附属模组可以注册自己的模块类型、属性、标记和服务端行为。[标记点铃声示例](../../examples/module-addon/)会在触发时从标记方块面播放音效。示例 JAR 要求客户端和服务端都安装 Sable Life `0.1.404`。参见 [Java 模块 API 指南](../MODULE_ADDON_API.md)。
- Datapack 可用 JSON 定义模块，初版支持模块触发时播放音效。[警报模块示例](../../examples/datapack-alarm/)可放进世界的 `datapacks` 文件夹。参见 [Datapack 模块指南](../DATAPACK_MODULES.md)。
- `/reload` 会刷新服务端目录，逐条跳过有误的定义。移除模块定义后，核心仍保留模块的属性、标记和触发设置。重新加载同一 ID 的定义即可恢复使用。

## 目标与战斗

- **目标白名单与阵营**新增**生物**页，可把原版和其他模组注册的生物类型排除出自动索敌，目标类型选**全部**时也生效。
- 实体受击框免疫药水效果。武器直接命中和直接魔法伤害照常结算。
- 同一攻击者以同一伤害类型反复接触命中时，同一生命体的多个实体受击框共享受伤间隔。修正了灾变魂戟和冲击波等攻击重复扣血的问题。独立投射物仍按各自的命中结算。

## 兼容性与文本修复

- 修复 qModeling 的 Workspace 编辑器在普通世界方块或未激活结构上临时切换旁观模式时自动关闭的问题。
- 修复英文界面和竞技场重生倒数中的乱码。

Minecraft 1.21.1 · NeoForge · Java 21。联机时客户端和服务端都需使用 Sable Life `0.1.404`。

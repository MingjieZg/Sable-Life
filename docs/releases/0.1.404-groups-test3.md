# Sable Life 0.1.404-groups-test3

相对 **0.1.403-fix1** 的更新。预发布适用于 Minecraft 1.21.1、NeoForge 和 Java 21。联机时服务端和所有客户端使用同一构建。

## 新功能

- **核心遥控器**可以远程打开同一维度中已加载的绑定核心。潜行右键核心可绑定，潜行对空气右键可激活已绑定的生命核心。服务端检查权限，生存生命核心按正常规则扣除能量。合成使用拉杆及十字摆放的四个红石粉。
- **部位破坏**可在收到信号或累计伤害达到阈值时破坏同一 Sable 部位的标记方块，并播放自定义音效。**累计伤害触发**可监听全身或标记部位。
- **生物白名单**可将指定的原版及模组生物从自动索敌中排除，对「全部」同样生效。提供被动与中立预设。实体受击框可选允许对实际造成伤害的白名单生物反击，使其在 15 秒内成为可选目标。
- **模块分组**支持在侧栏直接编辑成员。右键组名后勾选或取消勾选模块，再点击「确认」。
- **自定义模块**支持 Java 附属和 JSON 数据包。每个数据包模块最多支持八个数值属性，可用 `/reload` 重载。附件包含最低要求为 Sable Life `0.1.404` 的 Marker Chime Java 示例，以及 Alarm 数据包。

## 战斗与修复

- 实体受击框免疫药水效果，同一攻击者和伤害类型的重复接触攻击共享受伤间隔，修复灾变幻影戟、波浪等攻击扣血过多的问题。
- 新增 **Create: Gunsmithing 1.4.9** 与 **NTGL 3.2.0** 的伤害兼容。
- 新增可染色的弹道拖尾、可自定义的结构受击粒子，以及持续范围伤害的可选延迟爆破。
- 追踪激光在目标丢失时沿最后瞄准的方向完成本次发射。
- 修复标记受击监听部位时断开连接的问题。
- 新建无线频道默认启用。新放置的普通生命核心默认在三秒后清理断肢。

# Sable Life 0.1.444

## Compatibility fixes

- Fixed Let it Walk! 0.1.5 leg segments remaining after the main creature dies. Cleanup uses the Walker's recorded sublevel IDs in bounded batches, including remnants of broken legs; it does not delete nearby structures by distance.
- Activated independent segment cores are retired with the main body, without awarding another foot-core defeat reward. A foot already defeated independently retains its existing death settlement. Defeating a foot alone leaves the main body alive.
- Normal release preserves legs. A segment reclaimed as a new creature during the death delay is protected from the old job.
- Pending segment cleanup is saved with the death job and resumes after restart. Older death records without the added field retain their previous behavior.

The adapter remains optional and isolated. Native foot-core marking scopes and independent HP are unchanged.

Manual revision 245 removes the in-game Let it Walk relationship notes. Program classes are unchanged from the previous 444 cleanup test build.

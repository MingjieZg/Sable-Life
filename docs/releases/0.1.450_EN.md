# Sable Life · 0.1.440 → 0.1.450

[中文更新说明](0.1.450.md)

Changes after 0.1.440 through 0.1.450, grouped by feature. Repeated adjustments are combined into their current behavior.

## New Module

- **Signal Contact Sensor**: An adjustable box with checkboxes for terrain, other Sable structures, players, mobs and projectiles. Supports Start distance, local XYZ dimensions, horizontal/vertical angles, Hold and a timed first-contact pulse. Move Set can enable a detection window; its channel can drive attacks, effects or another move. Ignores its own structures and projectiles. High-speed bullets, hitscan and custom third-party projectiles are not guaranteed.

## Module Changes

- **Auto Facing**: Added left/right and up/down aim-origin offsets relative to the core center and marked front. Accepts signed decimals from -64 to 64 blocks, defaults to 0 and scrolls by 0.1 block. Positive means left/up; vertical offset requires Vertical tracking. It keeps the existing target and waits when that target is too close for the offset.
- **Auto Facing defaults**: New modules default Collision check to Off. Existing modules, blueprints and presets retain saved values; old data missing the field keeps its historical On behavior.
- **Wireless Redstone output buffer**: Hold the last nonzero strength after output ends; defaults to 0 seconds, Off. Marked faces, internal channels and external frequencies share the buffered output. New nonzero input replaces it immediately. Disable, release, death and unload clear it immediately. Scrolls by 1 second while retaining typed decimals.
- **Chinese pulse label**: The option reads “单次脉冲”, with matching explanations. Trigger behavior is unchanged.
- **Melee block breaking**: An independent switch, Off by default, clears breakable world terrain in the attack volume and sweep. Each module has its own protected list with block IDs, tags, presets and non-consuming inventory samples. An empty list permits all breakable terrain in range. Unbreakable blocks and Sable structures remain excluded.
- **Melee breaking controls**: Break blocks, Protected blocks, Flying debris and Block drops are grouped at the end of properties. Debris and drops have independent switches, both Off for new modules. Existing modules inherit their previous drop preference. Survival cores pay energy per successfully removed block.

## Core & Commands

- **Blueprint spawning**: `/sablelife blueprint spawn <name> <true|false> [x y z]` supports name completion. Omitted coordinates find ground; explicit coordinates place the bottom center directly. The boolean controls core activation after placement.
- **Command help**: `/sablelife help` lists concise syntax and purposes. Operation permissions remain in place.
- **Collision breaking decorations**: Recognizes grass, flowers, ferns, mushrooms and similar decorations. The surface/plant protection preset includes common plants, saplings and leaf tags; loading it merges entries without automatically replacing saved lists.
- **Core Remote defaults**: New configurations allow remote use when a supported claim interface is unavailable. Existing values remain intact; supported claim permissions, distance, dimension and loading checks still apply.

## Interface & Localization

- **Russian localization**: Integrated [Bill-Fasber](https://github.com/Bill-Fasber)'s [PR #5](https://github.com/MingjieZg/Sable-Life/pull/5), with terminology corrections and translations for subsequent additions.
- **Language selection**: Shows native names and the current selection, fits the window height and paginates longer lists. Switching retains parent navigation and unsaved input.
- **Module order**: Groups purple signals, red weapons and yellow functions. Contact Sensor sits beside Target Sensor; personal presets retain custom ordering.

## Fixes & Compatibility

- **Let it Walk! death cleanup**: Main-body death removes recorded leg structures, including legs with independent activated cores. Defeating a leg alone leaves the main body alive. Normal release preserves legs; pending cleanup resumes after restart.
- Existing cores, settings, marks, sensor bindings, blueprints and presets retain their data meaning.

Protocol 50; manual 253. Version 0.1.450 is the current source and local test candidate. The latest published GitHub Release remains 0.1.440.

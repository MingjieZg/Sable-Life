# Sable Life 0.1.404-groups-test3

Changes since **0.1.403-fix1**. This pre-release requires Minecraft 1.21.1, NeoForge and Java 21. Use the same Sable Life build on the server and all clients.

## New features

- **Core Remote** opens a bound core while it is loaded in the same dimension. Sneak-right-click a core to bind it, or sneak-right-click in the air to activate a bound Heart Core. The server checks permissions and the Survival Heart Core’s normal Energy cost. Craft with a lever and four redstone dust in a cross.
- **Part Break** removes marked blocks on one Sable part when triggered by a signal or accumulated damage. It supports a custom sound. **Damage Accumulation Trigger** can watch the whole creature or a marked part.
- **Mob Whitelist** excludes selected vanilla and modded mob types from automatic targeting, including **All**. Passive and Neutral presets are available. An optional Entity Hitbox setting makes an individual whitelisted mob eligible as a target for 15 seconds after it damages the hitbox.
- **Module Groups** can be edited directly in the sidebar. Right-click a group, check or uncheck modules, then click **Confirm**.
- **Custom Modules** support Java addons and JSON datapacks. Datapack modules accept up to eight numeric settings and support `/reload`. The Marker Chime Java example requires Sable Life `0.1.404` or later. The Alarm datapack is also attached.

## Combat and fixes

- Entity Hitboxes ignore potion effects. Repeated contact hits from the same attacker and damage type share a hurt window, fixing excessive damage from attacks such as Cataclysm’s Phantom Halberd and Wave.
- Added damage compatibility for **Create: Gunsmithing 1.4.9** with **NTGL 3.2.0**.
- Added tintable projectile tracers, customizable structure hit particles and an optional delayed explosion for Persistent Area Damage.
- Tracking lasers finish their burst in the last aimed direction if they lose their target.
- Fixed a disconnect when marking the part to watch for damage.
- New Wireless Channels start enabled. Newly placed Heart Cores clean up detached limbs after three seconds.

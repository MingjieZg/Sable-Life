# Sable Life 0.1.447

## Wireless redstone output buffer

- Output buffer defaults to 0 seconds (Off). After final output falls to zero, hold its last nonzero strength for the configured duration, then clear it. A new nonzero value replaces it immediately.
- Supports Hold, Pulse and Ramp; inversion is applied before buffering. Marked faces, internal channels and external frequencies use the same buffered output. Short gaps can become continuous power.
- Range 0–600 seconds, mouse wheel ±0.05 seconds. Changing buffer duration clears a pending timer. Disable, invalid marks, Master Off, death, release and unload clear the buffer immediately. Running timers are not saved.
- Existing enum values, defaults and data fields remain compatible. Old modules default to no buffer; presets and blueprints retain the new setting. Protocol50, manual248.

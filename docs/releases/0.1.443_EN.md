# Sable Life 0.1.443

Changes since 0.1.442:

- Added the independent Signal Contact Sensor. Combine checkboxes for terrain, other Sable structures, players, mobs and projectiles. Structure checks use actual block collision shapes and include ordinary builds without a Life Core.
- Mark one face; set Start distance, full local XYZ dimensions (0.05–16 blocks each) and horizontal/vertical angles. Angles rotate the box in place; offset follows the original marked face. Preview and the Inspection Tool show the same box.
- Output to an existing internal channel using Hold or a timed contact Pulse. Duration defaults to 0.2 seconds and accepts 0.05–60 seconds; cooldown defaults to 0.2 seconds. Contacts do not extend an active pulse and cooldown events are not queued. A newly entering projectile can trigger independently.
- Move Set can enable a detection window; the output channel can drive attacks, effects or another Move Set. Action end, disable, unload and other shutdown paths clear output. Runtime clocks are not saved.
- Ignore own connected parts, known Walker attachments, proxy hitboxes and own projectiles. Optional eligible-target filtering applies to known targets/shooters. Unknown projectile owners remain detectable.
- Detection only: no damage, blocking or reflection. Initially supports Projectile entities and Sable Life shots. Hitscan and other custom bullet families are outside guaranteed coverage. Ordinary projectile crossings up to four blocks per sample are checked; faster crossings and a sensor moving fully across a target between samples may be missed.
- Independent query limits: 32,768 operations per dimension/tick, 256 nearby entities and 64 candidate structures per sample. Incomplete queries do not create new contact edges; Hold is suppressed for that sample and existing pulses expire normally. Cores without this module perform no contact queries.
- Bilingual UI and manual revision 243. Existing module IDs, fields, registries and protocol 50 retain their meaning. Independent module config switches are added.

Use 0.1.443 on both clients and server. This local test build has not been uploaded.

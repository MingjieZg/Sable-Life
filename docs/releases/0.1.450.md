# Sable Life · 0.1.440 → 0.1.450

[English changelog](0.1.450_EN.md)

按功能整理 0.1.440 之后至 0.1.450 的更新，同一功能的调整合并为当前行为。

## 新模块

- **信号接触传感器**：检测框可勾选地形、其他 Sable 结构、玩家、生物和弹射物。支持起始距离、局部 XYZ 尺寸、水平／垂直角度，以及持续输出或指定时长的首次接触脉冲。Move Set 可开启检测窗口，输出频道可驱动攻击、效果或另一组动作。忽略自身结构及弹射物；不保证支持高速子弹、即时命中及第三方自定义飞行物。

## 模块调整

- **自动朝向**：加入左右、上下瞄准位置偏移，以核心中心和标记前方为参考。支持 -64～64 格的小数，默认 0，滚轮每次 0.1 格；正值为左／上，上下偏移需要开启垂直追踪。仍瞄准原本的目标，目标过近而无法满足偏移时暂停转向。
- **自动朝向默认值**：新模块默认关闭碰撞检查；已有模块、蓝图和预设保留设置，缺少旧字段的数据沿用原来的开启行为。
- **无线红石输出缓冲**：信号结束后保留最后的非零强度一段时间，默认 0 秒关闭。标记面、内部频道和外部频率使用相同缓冲输出；新非零信号立即替换旧值。停用、解除、死亡及卸载立即清空。滚轮每次 ±1 秒，手输仍支持小数。
- **无线红石中文名称**：脉冲选项统一显示为“单次脉冲”，同步相关说明，触发行为不变。
- **近战破坏方块**：独立开关默认关闭，按攻击范围和扫掠路径破坏可破坏的世界地形。每个模块有自己的保护名单，支持方块 ID、标签、预设，以及从背包选取样本添加，不消耗物品。空名单允许破坏范围内的可破坏地形；不可破坏方块和 Sable 结构保留。
- **近战破坏设置**：破坏方块、保护方块、飞散碎块、方块掉落统一放到属性末尾。碎块与掉落有独立开关，新模块默认关闭；旧模块继承原来的掉落设置。生存核心按成功破坏的方块结算能源。

## 核心与指令

- **蓝图生成**：`/sablelife blueprint spawn <name> <true|false> [x y z]` 支持名字补全。省略坐标时寻找地表，指定坐标时按底部中心放置。布尔值决定生成后是否激活核心。
- **指令帮助**：`/sablelife help` 简要列出格式与用途，操作权限校验保留。
- **碰撞破坏装饰物**：核心可识别草、花、蕨类、蘑菇等装饰物。表面／植物保护预设加入常见植物、树苗和树叶标签；加载时合并去重，不自动覆盖旧存档名单。
- **核心遥控默认设置**：新配置默认允许在缺少受支持领地接口时使用遥控。已有配置值保留；已支持的领地权限、距离、维度和加载检查继续生效。

## 界面与翻译

- **俄语翻译**：纳入 [Bill-Fasber](https://github.com/Bill-Fasber) 在 [PR #5](https://github.com/MingjieZg/Sable-Life/pull/5) 提交的翻译，调整术语并补齐后续内容。
- **语言选择**：显示语言原名和当前选择，按窗口高度适配并分页，切换后保留上级页面和未保存输入。
- **模块排序**：按紫色信号、红色攻击、黄色功能分组；接触传感器排在目标传感器旁。玩家预设保留自定义排序。

## 修复与兼容

- **Let it Walk! 死亡清理**：主体死亡时清理已记录的脚部结构，包括仍有独立激活核心的脚部；脚部单独死亡不影响主体。正常解除保留脚部，待清理记录可在重启后继续处理。
- 保留已有核心、模块设置、标记、传感器绑定、蓝图及预设的数据含义。

# Sable Life 0.1.404

## Custom modules

- Java addons can register module types with their own settings, markers and server-side behavior. The [Marker Chime example](../../examples/module-addon/) plays a sound at a marked block face when triggered. Its example JAR requires Sable Life `0.1.404` on both client and server. See the [Java module API guide](../MODULE_ADDON_API.md).
- Datapacks can define modules in JSON. The first format supports playing a sound when a module starts. The [Alarm example](../../examples/datapack-alarm/) can be installed in a world's `datapacks` folder. See the [datapack module guide](../DATAPACK_MODULES.md).
- `/reload` updates the server catalog and skips invalid definitions individually. A core retains the settings, marker and trigger of a removed module so it can resume when the same definition ID returns.

## Targeting and combat

- The new **Mobs** tab in **Target Whitelist & Factions** lets you exclude registered vanilla and modded mob types from automatic targeting, including when the target type is **All**.
- Entity Hitbox receivers ignore potion effects. Direct weapon hits and direct magic damage still use their usual damage rules.
- Repeated contact hits from the same attacker and damage type share a hurt window across a creature's hitboxes. This fixes excessive damage from attacks such as Cataclysm's Phantom Halberd and Wave. Independent projectile hits keep their own handling.

## Compatibility and text fixes

- Fixed qModeling's Workspace editor closing when it temporarily switches the player to Spectator mode outside an active living structure.
- Fixed broken characters in the English interface and in the Arena respawn countdown.

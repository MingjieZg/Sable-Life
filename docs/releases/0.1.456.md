# Sable Life 0.1.456

这是 Minecraft 1.21.1、NeoForge 的发布候选版，包含四项新功能，以及 `0.1.452-review.3` 的修复。游戏内手册修订为 259。[English release notes](0.1.456_EN.md)

## 新功能

- **结构蓝图阵营迁移**。Photomancy 保存结构蓝图时可带上生命核心的阵营设置和直接盟友引用。跨地图放置后，在核心的「阵营」页按目标地图权限绑定当地阵营、按原设置另建或跳过。确认过的个人映射随目标地图保存，盟友关系由当地阵营确认。
- **实体穿透**。触发期间允许玩家和生物穿过标记的子结构，或整个相连结构。支持持续、信号和招式触发。攻击判定、弹射物与 Sable 刚体物理沿用原有规则。此功能在 Sable 的碰撞接口通过兼容检查时启用。
- **近战破盾**。玩家成功格挡启用「破盾」的近战攻击后，盾牌进入原版 5 秒冷却。触发冷却的一击仍可正常格挡并结算盾牌耐久。破盾默认关闭。可选音效从被破盾玩家所在位置播放给附近其他玩家，被破盾者听到原版提示。
- **近战击退控制**。「额外击退」为 0 时，可以关闭默认开启的「原版受伤击退」。「额外击退」大于 0 时两种击退都生效，调回 0 后恢复保存的开关状态。

## 修复与兼容

- **LittleTiles 网格恢复**。已有重建任务时继续使用该任务。恢复顶点缓冲时复用模型几何缓存，减少重复重建。
- **Let it Walk! 死亡清理**。腿段卸载或服务器重启后保留待办，重新加载时继续清理。确认永久移除后才解除归属。
- **索敌与生存核心**。开启视线检查时，可设置失去视线后保留目标 0–60 秒，默认 0 秒。目标对齐与招式可绑定目标传感器，继承目标时沿用来源的到期时间。服务端可用 `allowSurvivalHeartCoreTerrainBreaking` 关闭生存生命核心近战、激光和爆破的地形破坏，攻击仍对目标生效。
- **大型结构蓝图与物品显示**。通过官方 Photomancy 放置现有 `.nbt` 时，生命核心恢复模块、重新绑定标记，再恢复物品显示模型。支持分包的客户端可接收大型模型快照。结构蓝图超出工具传输上限时，可将文件放到服务端蓝图目录，通过官方 `/sablebp load` 读取。
- **数据复制器**。物品提示显示已用字节与 2,000,000 字节的压缩上限。配置通过读取检查后保存在世界存档，已有磁盘引用仍可使用。管理员可检查用量、归档和恢复条目。详细配额和指令见上一版说明。[0.1.452-review.3 更新说明](0.1.452.md)

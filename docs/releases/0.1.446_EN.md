# Sable Life 0.1.446

## Melee terrain breaking

- Each Melee module has its own protected block list, supporting block IDs, tags, preset merging and individual removal. Listed blocks stay intact; an empty list permits all breakable terrain in the attack volume.
- The list is independent of core collision protection and other Melee modules. Drops still follow the core preference. Existing work budgets, energy settlement, unbreakable-block handling and Sable-structure exclusions remain.
- Enabled 445 modules without an independent list copy the current core list once when core context is available, then save it independently. Saved valid block IDs survive a temporarily absent decoration mod.
- Updated both interfaces and manuals. Protocol 50, manual revision 247.

## Feedback investigation

- Tested real Move Set five-second face switching with redstone lamps and 16 consecutive one-tick face-output actions. This does not establish reproduction of the player's machine; the receiving block and wandering/target-lock setup still need confirmation.
- This update does not change Move Set preemption, redstone publication or Arena center rules.

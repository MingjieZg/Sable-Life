# Sable Life 0.1.403

[English changelog](0.1.403_EN.md)

本次更新整合 0.1.320 以来的新功能与修复，加入生存生命核心、阵营与联盟、野外蓝图自然生成、实体受击框、世界血条，以及更多自动化和视觉效果。

## 生存生命核心与能量

- 新增可合成的生存生命核心，可在生存模式下编辑，通过补充材料获取能量。服务器可自定义材料价值、模块开关、伤害限制与计费倍率。
- 激活补足生命值、实际回血、攻击与强力控制能力按各自规则消耗能量。面板显示预计消耗和计算公式；已付费的剩余生命与核心余额会保留。
- 蓝图及配置复制不会复制能量和已购买生命。核心生命清空后自动解除生命化。
- 新增生存解除工具，只解除生存生命核心。数据复制器支持三类核心，并遵守对应核心的编辑权限。
- 普通生命核心可通过管理员配置开放生存编辑；与生存生命核心的能量系统分别管理。

## 目标、阵营与自动化

- 新增玩家白名单，All 目标类型也会排除名单中的玩家；加入 Owner 目标和生命核心目标优先级。
- 阵营支持公开／私人、玩家邀请、成员管理和多个相互确认的联盟。生命体只加入一个阵营；联盟主要影响选敌与本模组友伤规则，不自动赋予核心编辑权限。
- 管理员可限制普通玩家创建的阵营数量；默认每人一个，管理员豁免。
- Move Set 可忽略选敌与生命条件，同时保留优先级、权重、冷却、时长、招后停顿和重复规则。
- 红石核心加入 Move Set 和安全的直线移动；支持的模块默认开放，管理员仍可配置关闭。

## 实体受击框与交互

- 新增可调整尺寸与偏移的实体受击框，默认 Hybrid，可与结构伤害入口共存，共享生命值与部位伤害规则。
- 可选择吸引敌对生物和具有反击 AI 的生物；生物按照附近受击框边缘接近与攻击，减少集中挤向标记中心的问题。
- 修复大型受击框跨区段漏检。每只默认最多 8 个同时激活，服务器可调整。
- 新增方块交互模块，支持世界／结构内右键、单次／持续、起始距离和偏移；范围内只操作最近的支持方块，并跳过箱子、工作台等界面交互。
- 解除工具可穿过适用的实体受击框执行解除操作。

## 蓝图生成与野外自然生成

- 蓝图生成模块支持固定世界点、跟随标记部件、生成基准、起始距离、偏移和旋转。蓝图选择在解除后保留，并提供实际方块投影预览。
- 新增野外蓝图生成工具，可管理多个蓝图规则，选择是否激活核心，也支持无核心的普通结构。
- 每条规则可设置阵营、群系、离地间距、露天要求、障碍清除、数量上限、寿命和附近无人后的清理。
- 密度面板可调整刷新冷却、失败重试、候选位置数量与刷新距离。创造玩家也可触发自然刷新，旁观者除外。
- 默认全服所有规则合计最多追踪 64 个对象，附近 128 格内最多 4 个；可由服务器配置调整。列表显示当前数量，并支持清除当前对象。
- “生成后放生”让新对象脱离规则计数与自动清理；寿命 0 仅表示不按寿命清理，两者独立。
- 默认避开固定世界原版工作台周围水平半径 64 格，按整个蓝图占地判断。服务器可调整或关闭保护；Sable 结构中的工作台不算保护点。
- 出生全服公告支持颜色、粗体、斜体与可选坐标。自然生成可通过服务器总开关停用。

## 攻击、血条与视觉效果

- 激光加入跟随部件的连续光束、染色、水平／垂直扫射及独立速度，并允许调整额外粒子间距。
- 喷火加入扇形样式；牵引加入方向范围与稳定吸入。箭矢、枪、迫击炮支持自定义物品旋转，箭矢另有始终面向镜头选项。
- 世界血条支持长方形／圆角、大小、偏移、显示距离、受伤后显示／始终显示和隐藏延迟；可显示带格式的生命体名字，名字大小与间距独立调整。
- 视觉特效新增聚能、机械刻度环、护盾碎裂、喷口焰流、平面能量裂纹、回声光环，以及 `!`、`?`、`!!`、`?!`、`+`、`...`。
- 新图案可设置颜色、大小、时长、动画速度及跟随／固定位置。修复 Photon 下线条图案缺失。
- 标记与范围预览改为连续实线；无线红石面采用斜条纹；直线移动显示实际方块轮廓与红／绿阻挡状态；目标对齐与陀螺仪使用粗实线箭头。

## 修复与易用性

- 补充普通 Artifice 子弹的结构伤害读取，支持其动态伤害入口；这不代表所有外部武器及附加效果都已适配。
- 修复远处结构空包围框误挡旋转、部分光影下血条名字缺失、水边血条合成及多处输入、对齐、翻页问题。
- 结构被永久删除时清理关联状态，改进无核心自然生成对象、断肢和残留清理。新增管理员残留检查／清理指令。
- 普通生命核心的玩家挖掘采用禁止／全时段允许／仅死亡后三种模式，并分开控制挖掘掉落与爆炸破坏。
- 重整中英文手册，保留 Usage、Example、Troubleshooting；入门加入分步图示，重点介绍 Move Set、Wireless Channel 和 Wireless Redstone。
- 更新野外蓝图生成工具、复制器和解除工具的自绘材质。

Minecraft 1.21.1 / NeoForge / Java 21。客户端与服务器请使用同一版本。蓝图放置、竞技场自动重生和野外蓝图生成需要兼容的 Sable Photomancy；不使用这些功能时仍可运行其他模块。

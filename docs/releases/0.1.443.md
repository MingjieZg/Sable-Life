# Sable Life 0.1.443

相对0.1.442新增：

- 独立信号模块「信号接触传感器」。五个检测对象可多选：地形、其他Sable结构、玩家、生物、弹射物。其他Sable结构按实际方块碰撞形状检测，也适用于未生命化的普通结构。
- 标记一个面，设置起始距离、局部XYZ完整尺寸（各0.05–16格）及水平／垂直角度。角度绕框中心旋转；起始距离沿原标记面朝向偏移。普通预览和观察工具显示相同范围。
- 输出到已有内部频道，支持持续接触输出和首次接触脉冲。脉冲默认0.2秒，可设0.05–60秒；触发冷却默认0.2秒。再次接触不延长正在输出的脉冲，冷却期间的事件不排队。新进入的弹体可独立触发。
- 可由Move Set启用一个检测窗口，也可用其输出频道触发攻击、特效或后续Move Set。动作结束、停用、卸载等立即清除输出，不保存运行计时。
- 默认排除自身连接部件、已识别的Walker附属部件、代理受击框和自身弹体；有效目标过滤适用于能识别的目标及发射者。未知来源弹体仍可检测。
- 检测器只输出信号，不产生伤害、不拦截或反弹弹体。首版支持Projectile实体和Sable Life射击弹体；纯射线和其他自定义弹体不保证识别。普通箭矢每次采样不超过4格的穿越会补查，更高速穿越及检测框在两刻间完全越过目标仍可能漏检。
- 查询独立限额，不占用移动避障预算：每维度每刻32,768次操作，单次最多256个实体、64个候选结构。未完成查询不制造接触边沿；该次持续输出暂停，已有脉冲正常到期。未安装对应模块的核心不会进行接触查询。
- 中英文界面和手册更新至修订243。保留旧模块ID、字段、注册项及协议50；配置新增独立模块开关，旧设置含义保持。

客户端和服务端请同时使用0.1.443。这是本地测试包，尚未上传平台。

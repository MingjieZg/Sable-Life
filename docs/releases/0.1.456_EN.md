# Sable Life 0.1.456

This release candidate for Minecraft 1.21.1 on NeoForge includes four new features and the fixes from `0.1.452-review.3`. The in-game manual is at revision 259. [中文更新说明](0.1.456.md)

## New features

- **Faction mapping for structure blueprints.** Photomancy structure blueprints can carry Heart Core faction settings and direct ally references. After placement in another world, use the core’s Faction tab to bind a local faction, create one from the saved settings, or skip. The destination world checks permissions and saves confirmed mappings for each player. Local factions confirm alliances.
- **Entity Pass-Through.** While triggered, players and mobs can move through one marked substructure or the whole connected body. Supports always-on, signal and Move Set triggers. Attack hitboxes, projectiles and Sable rigid-body physics retain their usual behavior. Sable’s collision hooks must pass the compatibility check.
- **Melee shield disabling.** When a player blocks a Melee attack with Disable shield enabled, their shield enters the vanilla five-second cooldown. The shield still blocks the hit and wears as usual. Disable shield defaults to Off. An optional sound plays at the defender’s location for other nearby players. The defender hears the vanilla cue.
- **Melee knockback control.** With Extra knockback at zero, you can turn off Vanilla hurt knockback, which defaults to On. A positive Extra knockback applies both kinds of knockback. Returning to zero restores the saved choice.

## Fixes and compatibility

- **LittleTiles mesh recovery.** Pending rebuilds can finish. Buffer recovery reuses cached model geometry, reducing duplicate rebuilds.
- **Let it Walk! death cleanup.** Pending leg cleanup survives chunk unloads and server restarts. Cleanup resumes when the legs load again. Ownership is cleared after permanent removal is confirmed.
- **Targeting and Survival Heart Cores.** With Line of Sight enabled, targets can be remembered for 0–60 seconds after they move behind cover. The default is zero. Target Alignment and Move Set can link to a Target Sensor, and inherited targets keep the source expiry. Server owners can use `allowSurvivalHeartCoreTerrainBreaking` to turn off terrain damage from Survival Heart Core melee, lasers and blasts while keeping those attacks active against targets.
- **Large structure blueprints and Item Display.** When official Photomancy places an existing `.nbt`, the Heart Core restores modules, remaps marks and recovers Item Display models. Compatible clients receive large model snapshots in parts. If a structure blueprint exceeds the tool’s transfer limit, put the file in the server’s blueprint directory and load it with Photomancy’s `/sablebp load`.
- **Data Copier.** The tooltip shows the stored size and the 2,000,000-byte compressed limit. Configurations are checked for readability before being stored in the world save. Existing disk references remain usable. Operators can check usage, archive entries and restore them. See the previous notes for quotas and commands. [0.1.452-review.3 release notes](0.1.452_EN.md)

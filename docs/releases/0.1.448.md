# Sable Life 0.1.448

## 核心遥控器默认值

- 新世界／服务端配置的 `allowCoreRemoteWithUnsupportedClaims` 默认改为 `true`，遇到未适配领地接口时，无需先修改配置即可使用遥控器。
- 旧配置已有值保持不变。原来为 `false` 时仍会拒绝未适配接口，由服主需要时手动修改；希望严格拒绝的服主可设为 `false`。
- 已适配的领地权限、权限检查失败、编辑资格、距离、维度、加载状态和世界保护均保持原逻辑。这里只调整默认值，没有新增领地模组适配。
- 远程检查工具也使用此设置，中英文手册和配置提示同步。协议50，手册249。

# Sable Life 0.1.317

- Added horizontal and vertical firing angles to Flamethrower, Arrow, Gun and fixed-mode Laser. Start distance first positions the muzzle along the original selected direction, then the attack turns at that point. This positioning also applies to Slash; fan and laser sweeps no longer move the muzzle. Previews distinguish the positioning line and launch point.
- Added Visual Effects, Distortion trail, Particle effects, Item display and Trigger sound as optional survival Redstone Core modules. All five default to `false` in `[modules.redstoneCore]`; administrators can enable them individually.
- Enabled the corresponding survival editors when allowed by the server. Existing control modules retain their defaults.

Validation: 67 unit tests and 79 attack/summoned-weapon server integration tests passed. The optional Redstone Core settings also passed the 16-test control/policy suite. Firing positions and angles were confirmed in game before publication.

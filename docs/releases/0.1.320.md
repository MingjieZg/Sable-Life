# Sable Life 0.1.320 — Module management

- Added Module Manager next to module search: References, Groups and Channels.
- Highlighted Uses/Used by labels, aligned the manager button with search, and enabled Channel Inspect wheel adjustment by one.
- Added Particle density (0-128, default24) to Ongoing area damage. Zero hides particles while damage, burning and effects remain active; the existing shared particle budget still applies.
- View module references and jump to the relevant module or Move Set move. Deleting a referenced module now warns about unresolved references.
- Assign modules to collapsible groups. Search reveals matching modules inside collapsed groups; grouping preserves execution order, IDs and settings.
- Inspect actual internal channel contributions, configured sources and consumers. See each contributing module's published strength, external RX strength, channel pulse sequences and latched output.
- Available on both core types, subject to existing server module restrictions. Group metadata is preserved in saves, copies and presets.

Validation: 72 unit tests, 40 management/redstone native tests and 38 surface-area native tests passed. Surface-area coverage includes actual default-density Flame particle packets. Native client checks cover 16 GUI scale/density combinations, all three manager tabs, editing focus and direct Move Set page selection. These checks do not constitute a full multiplayer regression test.

The dashboard bottom frame now leaves spacing beneath the bottom buttons.

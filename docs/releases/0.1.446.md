# Sable Life 0.1.446

## 近战破坏

- 每个近战模块有自己的“保护方块白名单”，支持方块ID、标签、预设合并和逐项移除；清单内方块保留，空清单允许破坏攻击范围内所有可破坏地形。
- 不再共用核心碰撞破坏的清单；其他近战模块也各自独立。掉落仍沿用核心设置，原有工作预算、能量结算、不可破坏方块和Sable结构排除规则保持。
- 445中已开启破坏、但没有独立清单的模块，首次读取核心上下文时复制当时的核心清单，随后独立保存。缺少装饰物模组时，已保存的有效方块ID保留，便于重新安装后恢复保护。
- 中英文界面与手册同步。协议50，手册247。

## 反馈排查

- 测试实际Move Set时间线的5秒动作换面，以及连续16个单tick动作的选面输出。此场景不代表已复现玩家原机械的漏执行；尚需确认接收方块和流浪／锁敌配置。
- 本轮没有修改Move Set抢占规则、红石输出算法或场地中心规则。

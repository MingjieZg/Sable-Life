# Sable Life 0.1.442

相对0.1.440新增：

- 管理员可用 `/sablelife blueprint spawn <name> <true|false> [x y z]` 生成服务器蓝图，名字支持Tab补全。省略坐标时自动在执行位置X/Z的蓝图占地范围内寻找地表；提供坐标时按蓝图底部中心放置。true生成后激活生命核心，false保持未激活。
- `/sablelife help` 和直接输入 `/sablelife` 显示每条指令的语法与简短用途，普通玩家可查看帮助。生成、检查、伤害、清理及取消场地重生仍需权限等级2。
- 指令生成任务单独保存，最多8项待处理任务，每游戏刻最多一次原生放置；区块未加载、空间占用和模板超限会拒绝。失败后清理未完成结构，放置中断不会自动重复生成。
- 中英文手册补充指令用法，手册修订242。已有核心、蓝图模块、场地记录和公开扩展格式保持原有含义。

客户端与服务端使用同一份0.1.442。本地测试包尚未上传发布平台。

- 指令帮助缩短为语法与简短用途，移除逐项权限提示和末尾长说明；实际权限规则不变。

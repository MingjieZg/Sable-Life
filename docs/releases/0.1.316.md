# Sable Life 0.1.316

Changes since **0.1.313**.

## Server-controlled module availability

- Added individual `true` / `false` module switches in `sablelife-server.toml`:
  - `[modules.lifeCore]`: all 44 Life Core module types.
  - `[modules.redstoneCore]`: the nine supported survival control modules.
- Multiplayer clients follow the server's availability list.
- Disabled modules are hidden from the Add and preset catalogs. Existing modules retain their settings, display **Disabled by server**, and cannot trigger, be copied or bypass restrictions through an open editor.
- Re-enabling a module restores normal trigger behavior using its saved settings.

## Survival Redstone Core

- Added **Signal logic**.
- The available modules are now Signal logic, Pulse sequence, Wireless redstone, Target sensor, Target alignment, Auto facing, Signal turning, Gyroscope and Hover anchor.
- Removed Move Set, sound, BGM, item display and visual-effect modules from the survival core's available catalog. Existing unsupported module configurations are retained but cannot run on that core.
- Removed Move Set and Hurt triggers from the survival core. Always, anchor power, internal wireless and external RX remain available.
- Configuration cannot grant Life Core-only modules to a Redstone Core.

## Dependency compatibility

- **Create:** requires **6.0.10 or later**, with no upper version cap.
- **Sable:** requires **2.0.5 or later**, with no upper version cap.
- Minecraft remains **1.21.1**, using NeoForge and Java 21.
- **Sable Photomancy remains optional.** Arena automatic respawn now checks the required blueprint interfaces instead of accepting only version 1.0.1. Compatible newer versions can enable respawning; missing or incompatible APIs disable that integration with a server-log explanation. Other features remain available without Photomancy.
- Higher dependency versions are allowed to load but are not all verified. Please include exact mod versions when reporting compatibility issues.

## Update notes

- Changing module switches while the server is running resets loaded cores' temporary module runtimes, including counters and in-progress Move Sets, so persistent outputs and active module effects stop under the new policy. Saved configuration is preserved.
- Already-launched independent projectiles and already-applied vanilla effects are not rolled back. Arena respawn countdowns pause while the Arena module is disabled.
- Updated the in-game manual and administrator documentation.
- Release filenames now follow `sablelife-neoforge-1.21.1-v0.1.316.jar`.

Validation: **67 unit tests** and **32 server integration tests** passed for the module availability changes and signal/control regressions.

# 0.1.283 斩击可选正面格挡（开发版，2026-10-28）

Slash 属性的伤害数值后新增“可被格挡 / Can be blocked”勾选，默认关闭。关闭时保留原斩击无法被盾牌或已适配 Epic Fight 防御格挡的行为。开启后按斩击来袭方向判断正面，允许原版盾牌与 Epic Fight 原生防御、招架及冲击防御；背面命中照常造成伤害。不更改其他攻击模块。

来袭位置由目标中心反推飞行方向，避免高速或宽斩击越过目标中心后错误判断前后。盾牌开启时间、耐久、格挡动画沿用原生伤害流程。Epic Fight 沿用既有近战位置伤害兼容入口和原生体力/招架判定。零直接伤害的附带效果斩击同样可挡，不制造虚假伤害；原版零伤害格挡不扣盾牌耐久。

格挡成功不造成直接伤害，不给予命中计数，不触发点燃、药水或命中后持续范围伤害。当前目标对同一道斩击仍只判定一次；格挡保护当前目标，不删除整个斩击，后方其他目标和地形碰撞沿用原行为。已发射斩击保存设置快照，后续编辑不改变在途斩击。

## 验证

78项持续范围伤害与攻击原生 GameTests、9项 Epic Fight 原生 GameTests 通过。新增实际 Slash 飞行命中测试覆盖默认关闭、开启、正反面、主副手盾牌、未举盾、零/非零伤害、盾牌耐久、附带效果/区域抑制及设置保存；Epic Fight 覆盖三种防御各自的开关、正反面与零/非零伤害组合，以及体力消耗和同一斩击不重复扣体力。兼容验证版本 Epic Fight 21.17.3.1。

16组GUI缩放/密度检查通过，包括斩击勾选项的显示和可用性。双语手册更新至120。未跑完整套件/JUnit或原整合包人工战斗测试。

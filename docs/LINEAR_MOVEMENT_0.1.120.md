# Linear movement — 0.1.120

新增黄色功能模块，使用 Mark area/origin 标记出发点。移动的是核心所在的整条相连结构，保留各肢体当前朝向和相对位置；标记点随机器一起移到预览终点。

## 设置

- Movement mode：Teleport 蓄力后瞬移；Travel 沿线移动。
- Movement distance：0.1–128 格，默认 8 格。
- Horizontal angle / Vertical angle：各 -180°–180°，默认 0°，在标记方向基础上偏转。水平正值向右；水平发射方向下，垂直正值向上。上下标记面的右侧基准使用机器自身 X 轴。
- Direction：默认 Marked face，也可选择机器自身六个方向。
- Charge time：0–60 秒，默认 1 秒。蓄力结束时重新检查地形。
- Travel speed：只在 Travel 显示，0.1–40 格/秒。
- Check path obstruction：只在 Teleport 显示，默认 On。Off 可瞬移越过中间障碍，但终点仍须安全；Travel 不提供关闭选项。
- Interval：两次尝试的最短间隔，默认 5 秒，从蓄力开始计算。持续信号会在间隔到期后再次尝试。
- Charging / Departure / Arrival 各有独立双栏粒子选择与音效、音量、播放范围设置。粒子可设置时长和大小。

Preview 显示标记点到终点的线，以及整台机器的终点外包框；绿色畅通，红色阻挡。检查包括所有相连肢体、其他机器、地形、世界边界和未加载区域。使用保守外包框，因此斜向移动、带空洞或狭窄空间的机器可能在肉眼可通行时仍被阻挡。不会为移动强制加载远处区块。

## Move set 多角度实例

1. 添加三个 Linear movement，分别改名为“前进”“右移”“斜上移”，各自标记相同机器的正面。
2. 前进：Horizontal 0°、Vertical 0°；右移：Horizontal 90°、Vertical 0°；斜上移：Horizontal 0°、Vertical 30°。
3. 设置距离、蓄力和各阶段特效，分别 Preview 确认方向与落点。
4. 把各模块 Trigger 切换为 Move set，在三个招式中分别 Choose module 引用对应模块。
5. 动作持续时间须覆盖蓄力和移动：例如距离 8 格、速度 4 格/秒、蓄力 1 秒的 Travel，应给予至少 3.1 秒，避免信号提前结束而取消。
6. 使用权重或 Priority 安排招式。一次只允许一个移动模块控制机器；重叠动作请错开时间。

停止信号、关闭总开关、停用、清除 Mark 或死亡会取消移动；Travel 已经走过的距离会保留。连接链变更会取消 Travel，移动中新增方块的体积会在下一步重新检查。运行中的移动不会随存档恢复。

# 0.1.41-dev

## 枪模块

增加 Bullet hitbox（碰撞直径），范围 0.05–4 格，默认 0.2 格。该尺寸影响高速子弹扫过路径中的生物命中范围，也用于墙体碰撞采样；并非子弹模型大小。保存、重载、数据复制器及客户端碰撞框同步均携带尺寸。迫击炮维持原先尺寸。

## 无线序列器

新核心从空频道列表开始，点击 + Add wireless signal 才新增一行并选中它，每页七行。频道不再固定为 16 个；当前菜单编码支持最多 65535 个，并非真正无上限。界面只同步当前页摘要和所选频道参数，避免每次打开都传输全部频道。

旧存档保留配置过的频道，以及攻击模块引用的频道号码；只收起末尾既无配置又无引用的空白频道。中间空行保留以避免编号变化。RX / TX、频率物品、开关、时间轴和数据复制仍可使用。改变频道频率或 RX / TX 模式时注销旧网络连接，避免遗留信号。

模块的内部 repeat / 外部 RX 频道输入范围也扩展到 65535。没有添加的频道输出为零，不会借用最后一个已有频道的信号。

## 喷火

增加 Flame speed（火焰流速），单位为格/tick，范围 0.1–4，默认 0.8。火焰连续从出口生成并逐步推进，宽度沿途扩大至原先的尾端半径。机械转动时，已喷出的火焰保持喷出时的方向，新火焰使用当前出口方向，形成弯曲的连续轨迹。

伤害跟随推进中的火焰段，以 interval 控制每个目标的伤害间隔，继续忽略无敌帧；墙体截断火焰路径。模块停用或失去触发后停止推进与伤害，已生成的客户端粒子会自行消散。发射音效继续按 interval 播放。

验证：assemble 编译打包通过。未运行自动测试；视觉效果、转动轨迹及新增频道的实际接线仍需游戏内验证。

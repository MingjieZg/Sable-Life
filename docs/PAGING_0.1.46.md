# 0.1.46 Dense module and property pages

Module sidebar pages contain exactly eight entries; Previous/Next select the next eight. The add-module chooser follows the same paging rule. Row height is compressed to fit the smallest supported panel without covering pagination.

Standard (85%, default) and Compact (75%) property pages show at least six properties, using shorter rows when available height is limited. Larger panels show up to nine (standard) or eleven (compact). Comfortable (100%) retains larger readable rows and fewer properties. Property overflow still uses Previous/Next; numeric edits, wheel actions and choice actions use the same calculated page size.

Validation: assemble passed; geometry checked at every panel height from 234 to 330 and all density presets. No client launch or game tests.

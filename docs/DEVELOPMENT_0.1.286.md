# 0.1.286 核心碰撞破坏地形（开发版，2026-10-29）

## 第六页：碰撞破坏地形

Core settings新增第6页，保留原来五页的位置。支持页面记忆及重新打开定位。总开关默认关闭，保护脚下支撑默认开，碰撞破坏延迟默认0秒，碎块飞散默认开，方块掉落默认关。延迟可设0–10秒，滚轮每次0.05秒。创造模式可在休眠或激活期间编辑；其他玩家不能修改。

保护列表独立编辑，最多128项，每项为已注册方块ID或#方块标签，例如minecraft:stone或#minecraft:planks。未知方块ID、非法标识、重复及超限输入拒绝。移除时同时校验索引及原文本，避免并发编辑删除错项。列表分页、完整ID提示和正在编辑的输入保留。标签按世界当前标签内容匹配，允许尚未定义但格式有效的标签ID。

## 运行规则

仅激活且正常运行的生命体生效，控制核心不启用。按当前连接部件实际方块碰撞形状检测，支持旋转后的分离轴判断；包围盒只用于筛选，不把内部空隙当成方块。检测目前姿态及有限前方运动路径，在服务端线程清除接触到的世界地形。其他Sable结构的存储方块、未加载区块、世界边界之外和不可破坏方块不清除。空碰撞形状（如液体）不是撞击障碍。

脚底保护按世界上下方向判断真实当前接触，保留从下方承托身体的方块，不随身体朝向旋转。侧面或未来运动位置的上方边角不会被误判为地板；连接部件间的当前支撑也参与保护。关闭脚底保护后可以破坏脚下方块，可能失去支撑。

延迟0时接触直接移除。正延迟保留接触计时，只有再次确认仍在接触时才破坏，不会在远处补删旧墙面。计时不保存在NBT，停用、解除、重载和卸载后清空。

破坏优先于Linear movement Travel的辅助爬升，包括重力驱动和保持高度的路线移动。先清除可破坏障碍，再检查剩余受保护障碍是否需要爬升；当已知可破坏障碍仍在等待延迟或破坏数量预算时，不把它当成需要跨越的台阶。破坏发生后清除旧爬升接触状态，避免继续执行之前排队的抬升。其他移动/爬升设置保持原规则。

服务端每生命体每刻最多128个破坏、32768次工作预算，每世界每刻131072工作预算，单次部件区域按游标最多扫描4096个候选。待处理接触最多512项，旧接触会过期，部件游标跟随当前连接集合清理。沿用现有连接几何捕获上限64部件；超过或几何探测无法完成时不按整包围盒强行删除。预算是上限，不保证任何体量、速度都能在一刻清空整面墙。

## 飞散与掉落

碎块使用被破坏方块的原版材质粒子，速度沿部件推进方向叠加接触点的旋转运动，加入少量向上和侧向散射。没有可用运动时沿接触外侧飞散。每次8个碎片，附近玩家才收到消息，并受既有VisualBudget限制。原版粒子自带重力与短生命周期，不生成FallingBlockEntity，不重新放置方块，不提供攻击或碰撞判定。原版破坏音效/普通破坏粒子仍沿用原生移除流程。

方块掉落开关调用原版destroyBlock的掉落参数；并非抹除所有方块实体的内容物回调。容器等方块可能按照原版或其他模组的移除逻辑释放内容物，需要保留的建筑应加入保护列表。

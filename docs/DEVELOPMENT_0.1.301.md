# 0.1.301 Ground strike下落物品XYZ与独立显示尺寸（2026-10-30）

Ground strike新增下落物品朝向：默认朝向镜头保留原行为，固定朝向使用世界XYZ欧拉角（rotationXYZ），每轴−180°至180°。新增独立显示大小0.1–32格，按物品模型最长边归一化；只旋转/缩放下落视觉，不改变垂直轨迹、物理判定大小或落点伤害半径。原版剑可先用X=0、Y=0、Z=−135°让剑尖朝下，再按其他模型微调。

每次攻击释放时锁定物品、旋转模式/角度及显示大小，预警结束生成视觉时使用该快照。新增SynchedEntityData布尔、向量和显示大小以同步实际客户端物品姿态，实体NBT保存并限幅。默认0角度/朝向镜头不改变既有视觉；旧模块缺少显示大小时读取原projectileHitbox并限幅到新范围。巨物视觉扩大剔除边界，物理包围盒不跟着放大。其他发射物保留原渲染分支。

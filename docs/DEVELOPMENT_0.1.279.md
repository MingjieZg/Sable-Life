# 0.1.279 命中后火焰与持续区域（开发版，2026-10-28）

Mortar 和 Flamethrower 增加两个独立设置，默认均关闭：

- **命中后留下火焰**：独立设置半径、持续时间、每秒伤害和接触后燃烧时间。只有粒子与燃烧判定，不放置真实火方块、不蔓延、不修改地形。
- **命中后持续区域**：选择已有的“持续表面区域 / Lingering surface area”模块。选择器可搜索，保存稳定 UUID 引用；复制保留本地引用，排序不会改指向，删除后显示失效；跨世界预设清除引用，需要重新选择。

## 使用

1. 添加持续表面区域模块，命名为“毒雾”。释放位置保持“仅由攻击命中释放”，无需 Mark 或额外信号。
2. 选择圆形（半径）或长方形（长度、宽度、角度、居中/向前）。角度相对攻击在表面上的行进方向，90度为横向；垂直命中使用稳定的表面基准方向。
3. 设置持续时间、伤害、命中间隔、接触燃烧及所选药水效果。伤害0仍可使用药水效果。粒子沿用自选及 Color/Life/Size。
4. 在 Mortar 或喷火的“命中后持续区域”中选择“毒雾”。也可单独打开“命中后留下火焰”，两者互不替换。

区域也支持 Mark 或目标位置独立释放，目标模式支持多个目标，Move Set 可以调用。命中释放时只使用模板配置和启用状态，不要求模板自身触发信号同时开启。Mortar 使用实际撞击位置；击中生物时向其附近地面投射。喷火前沿撞到静态地形时留下效果。

## 生命周期与边界

生成后固定在世界位置，攻击触发结束和炮弹销毁不会取消。附近重复接触刷新原区域时间，同一攻击来源/模板重叠区域共享每目标伤害时钟；火焰与自选区域是独立效果，可叠加。不同攻击来源分别计时。停用或删除来源/模板、生命体死亡、总无线开关关闭、卸载或重置时清理。区域不保存运行状态。

圆形半径0.25–16格，长宽0.25–32格，时长0.05–600秒。每个生命体最多64个存活区域，表面采样和粒子发送有预算；轮流分配粒子预算，避免早期区域永久遮掉新区域。地面在两格内贴合台阶起伏，墙面沿命中面铺设；没有支撑的空气、移动 Sable 结构表面不生成区域。大范围地形的高度差超过两格时不继续铺设。区域显示为所选粒子，不是实体火墙模型。

普通目标按真实接触面检查，忽略创造/旁观玩家并遵循目标类别。机械生命体沿用现有真实结构表面查询、攻击许可和伤害修正；药水与燃烧状态仍仅适用于普通实体。持续伤害归属原攻击模块，沿用命中计数接口。

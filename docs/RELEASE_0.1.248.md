# 0.1.248 空间冲击波方块接触触发

开发版，稳定版仍0.1.243；协议14，客户端与服务器一起更新，手册91。

新增“方块接触触发 / Block contact trigger”开关，默认关闭。开启后，原有Always、内部信号、Move Set等条件作为总开关；Mark部位沿选定局部方向探测外部可碰撞方块，接触上升沿从实际碰撞位置发出空间波。持续贴地不重复，离开再接触且冷却结束后才能再次释放；冷却内接触不会延迟补发。关掉总开关后停止检测，重新开启时若已接触则触发一次。

接触方向六向、距离0.05–4方块（默认0.25）、冷却0.05–10秒（默认0.3），跟随标记部位姿态，排除同一生命体。复用Trigger Sound探测方法；原接触音行为不变。接触模式灰显单次/重复与重复间隔，关闭接触模式时灰显接触方向、距离、冷却。Preview继续给作者播放一次示例，不要求实际碰撞。

机械脚步可将扭曲、模糊、缩放设0，仅保留震屏；声音通过独立Trigger Sound标记同一脚底。设置随模块保存，运行时接触状态与冷却不写入模板。

验证：359项默认原生GameTests通过，新增真实组装/悬停结构接触测试，覆盖碰撞位置、贴地不重复、离地重入、冷却、信号开关、重新启用及保存；现有接触音六方向等回归同时通过。jar构建、双语手册91通过。此次未重跑GPU波纹算法、JUnit或原整合包。

16种界面缩放/密度检查通过，检查接触开启/关闭与参数分页；人工查看开启模式截图，开关、方向、距离、冷却、Mark contact布局正常。

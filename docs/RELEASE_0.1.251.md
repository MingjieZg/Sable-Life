# 0.1.251 击杀玩家回满血与模块扩容

开发版，稳定版仍0.1.243。网络协议16，客户端和服务器一起更新，避免旧客户端截断扩容模块。手册93。

核心设置首页新增“击杀玩家后回满血 / Full heal on player kill”，默认Off，不占模块名额。开启后生命体攻击确认击杀生存/冒险玩家时立即恢复至最大生命值。开关允许作者在运行期间修改，并保留于存档、核心配置复制和重生蓝图。已死亡/解除生命化核心不复活；普通命中、击杀生物、创造/旁观玩家、图腾保命、取消死亡和其他来源死亡不触发。

直接模块DamageSource携带真实核心UUID；保留BodyMeleeSource类型以兼容Epic Fight格挡。模块原生箭、枪弹和爆炸等带归属弹射物通过UUID索引找核心，不按名称或附近结构猜测，也不遍历世界。只认本次伤害的直接归属；后续环境死亡/持续伤害及没有本模组归属的第三方武器不追溯。Arena主动判死等显式归属本核心的伤害也沿用该归属。

模块新建容量默认64→128；服务器配置maximumModulesPerCreature允许16–256。服务端新增/预设入口和客户端按钮使用同一限额；保存读取支持256，降低配置不删除已有模块。命中计数来源选择上限同步扩大，UUID绑定不变。配置复制仍受已有1MiB边界限制，容量不等于可无上限增加粒子/实体负载。

验证：370项默认原生GameTests通过，新增真实ServerPlayer近战死亡回血、非致命命中、默认关闭、图腾实际消耗、非玩家/无关死亡、取消事件、原生箭归属、仅名称不授予归属、死后弹射物不复活、权限及保存复制、128新增上限/256读取及来源编号。最初真实玩家用例仍处于原版60tick出生保护，修正测试保护后完整回归通过。原有近战/弹射物、频道锁存、模块大快照等回归同时通过。jar、双语手册93通过；JUnit未重跑，原整合包待验收。

界面验收：核心首页新开关与原回血设置、翻页按钮无重叠；128模块面板在16种缩放/密度下完整加载，正确定位第128项及最后一页，达到服务器上限时新增按钮停用。人工查看对应截图。最终jar协议16。

# 0.1.281 更多攻击接入命中后持续区域（开发版，2026-10-28）

在0.1.280的 Mortar / Flamethrower 基础上，新增 **Gun、Arrow、Slash、Laser Beam、Ground Strike** 的“命中后持续区域”选择器。七种攻击共用 surface_field 模板：圆形/长方形、长宽角度、持续时间、独立伤害间隔、自选粒子/药水，以及接触后燃烧和离开后的燃烧时间。

## 命中时机

- Gun：子弹发生实际地形或实体碰撞时生成；达到射程、自然消失不生成。
- Arrow：普通插地、实体命中和爆炸箭的已接受碰撞都能生成；爆炸箭在取消原插地流程前生成一次。插地箭保存恢复后不会重复生成，实体穿透按不同受害者去重，最多记录64个受害者。
- Slash：每道飞行斩击命中实体时生成，碰到阻挡地形时也生成；沿用原本每目标一次的命中记录，不在普通飞行经过处持续铺设。
- Laser Beam：蓄力阶段不生成。发射期间真实地形接触每刻刷新或留下新区域，实体接触则沿用光束的伤害刻；达到最大射程的空气端点不会生成区域。
- Ground Strike：预警和下落阶段不生成，落击实际发生时才在落点生成；冻结该次释放时选择的区域引用。

地形碰撞沿真实表面法线铺设；普通实体接触从接触点向下寻找地面，不从头顶上方开始寻找，以免把效果投到低矮屋顶。命中其他移动 Sable 生命体表面时同样投向地面，不在移动结构上绘制世界固定的区域。没有可用静态支撑时不生成。

## 保留行为

未选择区域模板时，原攻击伤害、音效、轨迹、爆炸与消失行为保持。子弹和箭仅在配置了引用时额外保存命中设置；飞行保存恢复保留来源/引用。停用或删除来源/模板后，已飞出的攻击不会生成新区域。默认选择“无”，跨世界预设清除引用，需重新绑定。

同一来源/模板的附近接触刷新原区域时间，重叠区域共享每目标伤害间隔；统一保留64个区域/核心上限、粒子/采样预算及生命周期清理。区域伤害和离开后燃烧继续使用0.1.280逻辑，没有新增独立残留火焰设置。Melee、Sphere Blast、Area Pulse、Earthquake Wave 暂未接入。

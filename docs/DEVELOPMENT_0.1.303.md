# 0.1.303 Mortar／Ground strike自选落地粒子（2026-10-30）

两种攻击新增落地特效：默认爆炸／自选粒子。默认爆炸保留原表现；自选粒子使用独立的粒子选择器，可在其中设置Color、Life、Size（仍为0.1–4倍），不与飞行/下落拖尾共用选择。铺开范围默认跟随伤害半径，可改独立0–32格。总粒子数量1–128，默认24，多种选择交替分配；中心保留一颗，余下均匀铺开。数量1始终在中心，半径0全部在中心，空选择不显示落地粒子。单个大光环可用数量1、Size4。

这些设置仅控制落地视觉，伤害/附加效果/地形破坏和预警圈继续使用原伤害半径。Mortar自选模式通过原生服务器爆炸处理地形及保护事件，但不发送默认客户端爆炸表现，保留爆炸声音，并关闭原固定云浪与额外爆炸粒子。Ground strike保留圈和声音，只替换落地爆炸粒子。释放时保存特效快照，之后编辑不会改变已经飞行或排队的攻击。预设、复制、存档保留独立选择，旧模块默认原爆炸。

50项相关原生测试通过，覆盖实际Mortar伤害半径不受20格视觉范围影响、自选模式无默认爆炸包、默认模式保留原爆炸、粒子类型/大小/寿命、快照、预设、空选择、两个选择器的真实菜单与启用后编辑锁，以及其他爆炸和斩击回归。16组比例/密度客户端面板显隐、翻译及布局通过，截图已检查。双语手册136验证通过（56章节43模块）。未做多人场景大量重叠特效性能测试。

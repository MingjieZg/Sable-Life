# 0.1.306 召唤武装共享目标搜索（2026-10-31）

同组召唤武装共享候选目标池，正常每5 tick（0.25秒）刷新空间搜索。重叠搜索范围合并，分离很远的阵型分区搜索，避免扫描过大空白范围。移动超出已有覆盖范围、目标类别变更或新增位置超出覆盖时立即刷新。没有目标时仍保持刷新间隔，不逐武装重试。

每件武装仍独立选目标；池内目标的位置和有效性每tick更新，转向与攻击计时继续每tick运行。死亡、移除或超出该件武装范围的目标失效，可以改选池内其他目标；新增或更近目标正常在下次搜索时识别。相同tick内前一个武装击杀目标，后一个也会排除它。固定瞄准和整组结束会释放候选引用。预览同样共用搜索。

验证：206项相关原生GameTests全部通过。新增覆盖32件重叠范围共用一次搜索、独立目标选择、实时位置、死亡/移除/超距、延迟识别新目标、快速移动立即搜索、稀疏分区、机械生命体死亡及实际32件武装运行。重叠范围测试中每5 tick只进行一次空间查询；这是目标查询次数验证，不是整游戏帧率基准。实际客户端八武装的圆环/横排、移动目标追踪、跟随/世界位置和死亡清理验证通过，两张截图已检查。双语手册139（57章节44模块）和JAR打包通过。本版没有布局变更，未重跑GUI组合检查。

优化不改变发射频率、伤害频率、命中归属或数量上限；发射物、激光及命中计算仍随武装数量增加。未做多人或大批阵型长时性能测试。

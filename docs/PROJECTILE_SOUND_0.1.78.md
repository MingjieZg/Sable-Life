# 音效、轨迹和爆炸 0.1.78

- 所有模块音效选择左侧添加 None 勾选：勾选关闭并淡化选择按钮，取消恢复上一次音效；没有历史选择时用第一个有效音效。音效循环不再经过 None，MC／OGG入口继续保留。
- 普通外部输出、序列外部输出、序列内部输出分别注明 wireless to out、pulse sequence to out、pulse sequence to in。序列模式也供血量阶段输出使用。
- 牵引警告、光束蓄力、落雷下落音效追加独立音量 0–4、播放半径 1–256（默认 1／32）；音量按监听者距离衰减，半径外不播放，仍遵循游戏敌对生物音量。
- 箭矢／飞剑、枪、迫击炮可打开轨迹特效双列表。药水与粒子编辑彼此独立，支持右键快速转移；轨迹按每颗发射物保存，飞行中修改模块不会改变已有子弹。空列表无轨迹；落雷保留原有双列表和默认轨迹。
- 迫击炮移除直接 Damage，仅依赖爆炸开关和 Blast damage；关闭爆炸则不造成伤害。旧存档炮弹同样不再额外直接伤害。
- 爆炸按球形半径与目标碰撞箱相交判定，圈边仍有完整设定伤害；移除地面／机械方块射线遮挡，因此范围内墙后目标也会受伤。护甲、爆炸保护仍生效。方块破坏开关独立。

## 本轮待测

1. 任意音效勾选 None：按钮变灰、停止后续触发；取消恢复原音效，保存重载仍能恢复；左右键不再选到 None。
2. 频道三类注释在 Wireless 与 Sequence 同屏都显示，长名称仍可读。
3. 警告音量 0／1／4、播放半径 8／32／64：近处、圈边、圈外距离与游戏音量设置；停止模块后清理声音。
4. 箭矢、枪、迫击炮：加入多种轨迹、右键移入移出；药水列表不被影响；飞行、命中、残留和重载。
5. 迫击炮爆炸半径 4／8／16：中心、接近圈边、圈外、墙后；关闭爆炸无伤害，开启后只结算一份 Blast damage；护甲减伤和破坏开关。
6. 原有序列联动仍待测，见 PLAYTEST_CURRENT.md。

牵引、光束与血量阶段已由用户确认正常，本轮新增警告音效控制仍需检查。

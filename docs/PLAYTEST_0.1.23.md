# 0.1.23 无线时序控制测试

本轮未启动客户端。创造模式右键 Heart → 中继器“无线时序控制”。

1. 未生命化时打开；确认铜色／紫晶独立界面、频道分页和右侧输入框正常。切换到第 2 页，配置频道 16。
2. 点击“选择频率物品”，拿起钻石点击红槽、绿宝石点击蓝槽；确认物品数不变。空光标点击可清除样本。关闭界面不遗失光标物品。
3. 频道 1 开启，延迟 0、通电 1 秒、断电 3 秒、强度 15、循环；频道 2 使用另一对物品，延迟 1 秒、通电 1 秒、断电 3 秒、循环。给两个 Create 接收器设置对应有顺序的频率，连接关节控制。
4. 激活 Heart；接收器应错开 1 秒发射，每 4 秒循环。独立 UI 可查看当前状态，配置锁定。生存模式不能打开。
5. 测试单次模式、断电 0（持续通电）、强度 1–15、直接输入 Enter/✓、加减与 Shift 大步调整。
6. 移动／旋转结构并超出 Create 无线距离；确认接收器随位置变化。暂未加入超距独立提示。
7. 保存退出后重进，确认频道保存且时序继续；死亡、创造解除、卸载结构后信号归零。相同频率还有另一个 Heart 时，其信号应保留。

重点反馈：GUI 缩放后有无文字遮挡、频率槽点击是否准确、两个关节的时序是否符合设定。

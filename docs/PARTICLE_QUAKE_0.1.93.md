# 0.1.93 地震多目标与粒子显示属性

## 变化

- 地震 Target 下增加 Single target／Multiple target，只有 Wave origin 为目标脚下时可操作。单目标选择最近目标；多目标最多 64 个，分别冻结各自位置。三种波形均支持；同一波在重叠区域最多对同一个目标命中一次。临时地面模型仍共用数量上限。
- 所有双栏粒子选择页的 Remove selected 下方显示时长及大小字段。先左键选中右侧粒子，再输入并按勾或 Enter；滚轮每次 ±0.1。右键快速移入／移出维持原操作。
- 时长 0 为原粒子默认时长；正值为 0.05–60 秒。大小是 0.1–4 倍，默认 1。每种粒子分别保存。时长控制生成后单个粒子的寿命，不改变招式或发射持续时间；某些原版粒子仍会因碰撞、液体条件等提前消失。
- 装饰粒子、箭矢／gun／mortar 拖尾、落雷拖尾、激光、地震、牵引均使用这些属性。普通警告圈原本颜色不受改变。仍强制可见。
- 旧配置保留原默认效果；发射物冻结发射时的粒子设置并随实体保存。蓝图复制使用模块数据，可携带显示设置。

## 自动验证

构建及现有单元测试通过；30 项相关 GameTest 通过，含新增多目标地震重叠伤害、全部粒子模块属性独立保存、箭矢／gun／mortar 发射快照与实体重载检查。实际客户端视觉仍须人工检查。

# 统一声音时间线（0.1.134）

## 页面

Modules所有声音选择、Core死亡瞬间与消失阶段主音/尾音、BGM和旧声音设置后端统一使用声音组合编辑器。外部左右循环选择和MC/OGG快捷入口由编辑页面替代。旧声音方块本身仍作为旧存档兼容对象，不恢复已下架的方块能力。

左侧声音库包含原版/已安装模组声音事件和本地OGG；搜索支持ID或文件名。左键选择，右键快速加入右侧，可以重复加入同一声音。右侧支持启用、复制、删除和排序。排序影响列表，不改变每条声音的开始时间。

MC打开具体原版音频浏览/导入；OGG打开自定义音频文件夹；放入有效OGG后用Reload重新加载。联网环境各端仍需要对应的自定义资源，与之前相同。原版声音事件可能有随机变体，若需要固定某个变体可以使用MC浏览器导入具体文件。

## 每条声音的设置

| 属性 | 范围与含义 |
|---|---|
| Start (s) | 0–600秒，以本次事件发生时为0；按游戏tick精度记录 |
| Pitch | 0.5–2，改变音高，也改变播放速度 |
| Volume | 0–4，单层音量 |
| Range | 1–256格；普通效果在范围内按距离衰减，BGM保留范围进入/离开控制 |
| Limit (s) | 可选播放上限0–600秒；0自然播完，正数只截断当前这一层，不影响其他层；BGM的0保留原先原曲循环 |

默认不要求填写Duration。时间线实线代表已设置的播放上限，虚线尾部是自然长度未知的示意，不假装测出了OGG/原版事件实际时长。试听单条从0秒开始；试听整组按Start执行，停止试听与离开页面都清理预览和未开始的声音。

## 触发与兼容

每次对应事件触发都会从0秒开始新的组合，可以重叠。开始时间相对于蓄力/开火/命中/受伤/移动阶段/死亡等事件，不是全局世界时间。已编排的组合允许尾音在招式阶段结束后自然播完；禁用/删除模块、生命体停用及退出世界会取消对应普通模块的待播与播放音效。死亡/消失声音使用独立标识，允许生命体结束后播完。

旧保存的单个声音迁移为一条0秒开始、无截断的声音，保留原来的音量、音调与范围；默认声音不改变。没有声音则为空列表。修改组合后独立保存每条属性。Core主音/尾音保留为两个事件槽，各自能编排多层。BGM保留单个生命体组合的优先选择、范围控制与离场淡出，支持延迟开始的分层循环。

声音网络协议升级为2，客户端和服务器需使用匹配版本。

## 组合示例

1. 在Laser的Charge sound点编辑声音组合。
2. 左侧搜索respawn_anchor.charge，右键加入。
3. 第一层设Start=0、Pitch=0.8、Volume=0.8、Range=32，Limit=0。
4. 再加入note_block.bass，Start=0.3、Pitch=1.2、Volume=0.5。
5. 加入firework_rocket.blast，Start=0.7、Volume=0.8。
6. 试听整组，通过时间线检查三个开始点；按需调整各层，不需填写自然时长。

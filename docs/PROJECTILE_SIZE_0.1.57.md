# 0.1.57 发射物大小与碰撞同步

- 枪的 Bullet size / hitbox diameter 与迫击炮新增 Shell size / hitbox diameter 都控制显示大小与扫掠碰撞直径，范围 0.05–2.0 格。
- 默认枪 0.2、迫击炮 0.15，保留原碰撞尺寸；迫击炮不再使用独立的固定 0.65 显示缩放。
- 普通物品模型按最长几何轴归一化后缩放，保留比例并居中。扁平物品仍是扁平外观，碰撞范围仍按直径；自定义动态渲染物品没有通用几何边界，使用标准尺寸缩放。
- 两者共用实体/墙体扫掠逻辑；尺寸同步客户端并保存于每颗发射物。已经发射的子弹保持发射时配置。
- 原爆炸范围独立，不随弹体尺寸改变。

待游戏内检查：普通物品/方块/模组物品外观，0.05/0.2/1/2 尺寸，F3+B 居中，高速墙边/实体擦边碰撞，多人同步，保存重载和数据复制。新尺寸可能让迫击炮提前碰墙，最终警示落点需核对。

# 0.1.307 召唤武装生命周期与攻击扩展（2026-10-31）

召唤武装改为单次激活后独立持续：信号断开、模块停用或Move set结束均不取消已部署成员或待生成队列。新的信号上升沿/Move set激活追加一组，不替换旧组；持续通电不无限生成。世界固定模式每组记住各自触发时的位置，可在不同地点逐批留下武装。每件从自己的出现时间计算寿命，独立到期；生命体死亡或解除清理全部武装、待生成队列、各自声音与控制。部件标记失效时已生成的跟随武装停留在最后位置，到期再消失。每组仍为1–32件，每核心最多256件运行/待生成武装；超出时不接受新批次。

默认显示物品为发射器。新增生成特效/声音及消失特效/声音四个独立编辑入口，复用粒子Color/Life/Size及声音组合编辑器，保存/预设保留配置。默认生成特效为粒子库的“Sable life 星芒”（random_starburst），生成声音为minecraft:entity.firework_rocket.launch；默认消失媒体为空。媒体每件仅播放一次，取消未生成队列不产生消失效果，消失声音不会被武装自己的音频清理立即截断。修正召唤武装可移植预设未保留显示物品的问题。

新增生成后攻击前摇，默认0，范围0–600秒；每件出现时开始计时，前摇包含在武装存在时长内，等待时物品可见并照常转向。前摇结束才启动引用引擎，模板自身的预警/蓄力仍会继续生效。前摇不小于寿命则该件不会攻击。

引用支持由Gun/Arrow/Flame/Laser扩展到Slash、Ground strike、Quake、Attraction、Freeze、Shockwave、Grab，共11种。复用已有判定、伤害、附加效果、命中归属和计时，每件有独立引擎。引用模板可停用、无需标记；释放起点、朝向、Start distance由武装发射口和瞄准框架接管。范围、数量、攻击形状、抓取偏移及预警时间保留。冻结/地震等已发布预警锁定当时的世界位置，抓取目标随武装发射口移动。控制/音频来源使用每件每次激活的独立ID，命中记分仍归属于原攻击模块；一件到期不解除其他件的冻结或抓取。

预览向操作者发送真实物品、大小和与原生ItemDisplay一致的FIXED模型旋转，约3秒后自动清理，不生成服务器实体或碰撞。绿色表示模型轴，橙色能量光点表示实际发射口，蓝色表示发射方向。物品XYZ校正不改变发射口和攻击朝向。保留0.1.306共享目标池，每5tick刷新空间搜索，逐tick转向与攻击。

验证：282项相关原生GameTests通过，涵盖11种引用入口、七种新增攻击实际命中/控制、前摇显示与延迟开火、断电后队列继续、重复激活追加世界组及独立到期、冻结来源隔离、断电后的抓取跟随、媒体保存/预设及两个粒子编辑按钮实际打开，并回归原武装/四种远程攻击/目标缓存/地震波/玩家与生物冻结抓取。默认星芒选择调整后复验召唤测试。16组界面比例/密度检查通过；实际客户端八武装及真实发射器预览、跟随/世界位置和死亡清理通过，相关截图已检查。双语手册140（57章节44模块）通过。

测试夹具修正：冻结重叠范围测试单独批次，避免捕获邻近测试的生物；旧双目标斩击夹具移至独立高度并固定发射结构，先确认两目标可见，再在原有超时内等待单次齐射实际命中，避免低处场地遮挡和固定3tick等待造成误报。正常斩击的目标过滤、视线和伤害规则未改变。

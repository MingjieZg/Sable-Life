# 0.1.250 Wireless频道锁存

开发版，稳定版仍为0.1.243；网络协议15，客户端和服务器必须一起更新。手册92。

每个输出频道新增Latch / 锁存（默认Off）及重置频道（0无）。支持内部波形、外部TX、Sequence内部和Sequence外部TX；外部RX保持原行为并灰显锁存编辑。首次通电捕获强度，原脉冲结束仍保持；持续高信号不反复更新捕获值。原输入断开再通电可捕获新的强度。重置频道读取同核心的有效内部输出，或该频道处于RX时的外部输入；重置优先，输入持续高时清除后不立即重新锁存。禁止自身或不存在的重置频道。

阶段用法：将频道2启用为Sequence/internal并开启Latch；转换动作最后向频道2发一次脉冲；粒子Trigger=内部无线、频道2。粒子跨后续招式间隔保持。可另用频道3作为频道2的重置输入。无需新增虚拟模块。

锁存运行态不写入存档：重进世界需要重新触发；停用频道、关闭总开关、配置修改、死亡、解除生命化、卸载/重载均清空。重命名及界面布局切换不重置。删除频道会清除对应重置引用并调整后续编号；保存、核心配置复制与蓝图保留锁存设置。超出原有运行期的永久进度保存不在本次范围。

运行只遍历已配置且启用锁存的输出频道，不扫描世界；读输出无副作用。重置信号先拍快照，再统一更新，避免递归频道调用。Create发送器及时同步锁存和清除状态。

验证：365项默认原生GameTests通过，新增5项覆盖短脉冲保持粒子触发、多个来源、重置优先/重新上升沿、保存兼容、主开关/停用/死亡/解除/重载、菜单校验和编号删除、真实Pulse Sequence结束后保持、真实Create外部接收器锁存与清除。首次专项测试中的粒子样本少了第二个区域Mark，修正测试设置后完整回归通过。jar、手册92通过。JUnit未重跑，原整合包待实机验收。

界面：16种Wireless缩放/密度组合通过。人工查看高缩放布局后提高数字框最小高度，小界面隐藏波形预览以腾出空间；修正后16组合再验通过，最终jar重新生成。

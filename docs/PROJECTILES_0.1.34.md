# 0.1.34：爆炸范围与目标迫击炮

- 枪使用 Bullet speed 和 Bullets / shot，迫击炮使用 Shell speed。
- 鼠标悬停模块数值框后，滚轮立即提交增减值：小数属性每格 0.1，弹数、燃烧秒数、抽取次数、整数半径和效果等级每格 1。超过上下限时截断；只读属性不处理滚轮。
- 爆炸伤害改为半径内完整设定值，按目标碰撞箱是否接触爆炸球体判断。无遮挡地面的红圈内不再因距离衰减变得几乎无伤；地面撞击点略微外移，视线检查使用身体多个位置，墙体仍能格挡。创造玩家仍不受伤害。
- 增加按半径分布的爆炸颗粒和持续 8 tick 的扩张冲击波，覆盖警示半径。方块破坏仍是独立开关，并遵循原有生命保护规则。地形破坏的实际形状受方块抗爆性影响。
- 迫击炮增加 Aiming mode：默认 Fixed direction 保持旧行为；Target position 在每次发射时选取搜索范围内最近的可达目标，记录当时的位置并自动解算高弧线。可筛选玩家、生物或全部；排除创造和旁观玩家。
- 目标模式以 Shell speed 为速度上限，使用与炮弹实际运动一致的离散重力解算；Launch angle 和 Direction 在此模式禁用。若没有可达目标则不发射，也不播放发射音效。目标移动后不追踪，下一发重新取位置。
- Preview 与真实发射使用同一个瞄准和轨迹计算。墙体、生物或移动结构可能提前截住炮弹，实际落点预警会随飞行更新。

验证：assemble 编译打包。按此前要求未运行单元或游戏功能测试，客户端验收重点为圈边伤害、墙体格挡、滚轮、移动目标位置快照。

# 0.1.253 地震Ring圆周显示修正

开发版，稳定版仍0.1.243，协议16。

修正地震Ring按圆周顺序生成临时地块、192个显示实体名额在半圈中耗尽导致一侧缺失的问题。先收集整圈有效地表并去重，再将剩余名额均匀分配给整个圆周。视觉实体总上限仍192；粒子继续覆盖全部已采样新地表，其他地震模式和伤害扫掠不变。

圆周采样改为四向对称，按半径增加密度，最多256点（原64）；先过滤不可抬升的表面，再分配抬升名额。保持已有按波次/地表列去重、显示14tick寿命、停止清理和不修改真实地形。

验证：32项地震专项原生GameTests通过，新增实际地表/QuakeGroundBlock检查，在剩余13、17、31个显示名额时均覆盖四个象限，无整象限空缺，未超过192上限，真实石块未变化。既有Ring命中/跳跃规避、多波伤害、Line、Area、目标脚下、临时实体清理等回归同时通过。jar构建通过。本次未重跑全套、GPU/客户端截图或JUnit，整合包观感待实机验收。

# 0.1.97 悬浮弹排列

- Fan plane 共四种：Front vertical fan（正面 ∩）、Side vertical fan（侧面 ∩）、Horizontal line（正面 —）、Side line（侧面 —）。默认正面弧形。
- 顶面／底面标记控制从 Mark 展开的方向，不再把竖直扇形的上方轴变成水平方向。扇形跟随生命体姿态；顶面标记使用生命体北向作为正面参考。
- Fan rotation 保留 -180°–180°；0° 是基础排列，可旋转出斜向或其他朝向。
- 直线均匀分布，Fan angle 控制展开宽度；中央弹位置保持不变，Preview 与实际生成使用相同坐标。
- 旧水平弧形和正面竖直扇形迁移到正面弧形，旧侧面竖直扇形迁移到侧面弧形；保存、复制使用新排列编号，旧旋转角度保持。

## 人工检查

1. 顶面和侧面标记，5／9 个弹，正面／侧面弧形均为 ∩；两种直线从对应方向看为 —。
2. Fan rotation 0／90／-90／180；单发中央点不移动。
3. Preview、展开终点一致；保存重载与 Photomancy 复制保留排列及旋转。

# 0.1.35：数据复制器

创造物品栏新增 Data Copier（数据复制器）。

1. 空载复制器右键 Heart：提取配置，可从已激活或死亡核心读取。
2. 装有数据的复制器右键另一颗未生命化的 Heart：替换目标配置。可重复粘贴，数据不会消耗。
3. Shift＋右键 Heart：重新提取，覆盖复制器中的旧数据。

复制范围：生命上限、死亡延迟、结构破坏开关、Boss 血条、名称、死亡战利品和经验、全体虚拟模块属性及其战利品模板、16 个无线频道的物品频率/时间/模式。

粘贴不激活目标，也不复制当前血量、死亡状态、结构身份、所有权、无线运行进度或已发放奖励。模块生成独立的新 ID，清除来源结构标记、剥离与损坏状态，需要在目标结构重新标记后激活。粘贴替换目标原有模块配置，不执行死亡或掉落逻辑。

配置储存在物品 Custom Data，随物品存档；装有数据时有附魔光泽，提示来源和模块数量。创造模式才可使用；已生命化目标需先通过 Heart Release 或解除工具还原。

验证：assemble 编译与打包通过；按此前要求未运行单元/游戏功能测试。

## 战斗 BGM 方案（本轮尚未实现）

建议在核心或声音模块添加 Combat BGM 选曲、循环、范围和离战延迟。首次成功受到伤害时进入战斗，通知范围内客户端播放无距离衰减的音乐；后续受伤不重复起播。死亡、解除生命化、离开范围/维度或卸载后停止；离战延迟避免音乐频繁切换。多只生命体同时战斗时，客户端优先播放最近战斗核心的一首，并暂时避让原版背景音乐。可复用 sounds 文件夹的 .ogg 选择，但需专用客户端音乐会话，不能直接复用受伤单次音效。

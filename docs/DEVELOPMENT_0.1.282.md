# 0.1.282 持续范围伤害仅命中调用、悬浮追踪与斩击点燃（开发版，2026-10-28）

## 持续范围伤害

显示名从“持续表面区域”改为 **持续范围伤害 / Persistent area damage**。内部类型ID仍为 surface_field，保留既有引用及配置身份。

模板的生效方式固定为只读 **命中时 / On impact**。删除 Mark、Preview、独立 Trigger/频道、直接 Move Set 调用及所有自主释放逻辑；不再提供 Mark point、On target、目标搜索距离、多目标释放或自主释放间隔。旧目标/标记释放值载入后归为命中时，旧Mark的失效/脱离状态不影响模板有效性。旧直接Move Set动作应改为触发实际攻击，再在攻击中引用此模板。

目标筛选仍保留，改称“伤害对象”：它只选择区域可以伤害哪些实体，不决定释放位置。只有被引用攻击发生实际命中，才会在命中处生成区域，投射物还没到时不会提前在目标脚下出现范围。

**区域半径、区域长度、区域宽度** 滚轮每次加减1格，**区域持续时间** 滚轮每次加减1秒；仍可手动输入小数，验证范围不变。

## 悬浮追踪

Homing / 悬浮追踪新增“命中后持续范围伤害”模板选择，共八种攻击支持。沿用既有投射物真实碰撞入口，展开、蓄力及普通飞行不生成；保存恢复保留选择引用。

同一悬浮追踪模块引用同一模板，在同一表面附近反复命中只刷新原区域到期时间，不新增区域、不叠加区域伤害、不重置每目标伤害时钟。不同落点仍可各自留下区域；原有数量上限和清理规则保留。归并沿用同来源/模板、相同表面法线、中心相距小于1格的规则，不改变第一次落点的形状/朝向。

## 斩击本体点燃

Slash 新增 **命中后点燃目标** 勾选，默认关闭；开启后显示 **灼烧时长（秒）**，0–30秒，默认3秒。只在普通实体有效命中时点燃，支持直接伤害为0的命中；不依赖持续范围伤害引用，与区域内的接触后燃烧独立。沿用普通防御/免伤的命中接受结果，不点燃被挡下的伤害；机械生命体不应用原版火焰状态。设置随保存、复制和飞行时的斩击快照保留，已飞出的斩击不随后续编辑改变。

## 验证

206项原生持续范围、攻击和控制 GameTests通过。新增覆盖旧On target配置不再自主释放、旧失效Mark不影响模板、拒绝直接Move Set动作、悬浮追踪真实碰撞/保存恢复、多发同点刷新且不重复扣血、刷新到期、模板不依赖自身信号，以及斩击点燃保存/默认关闭/零直接伤害时独立生效。

32组GUI缩放/密度检查通过（16组模板、16组八类攻击），验证模板Mark/Preview/Trigger/频道隐藏、命中条件不可切换、四项滚轮步长、斩击点燃勾选与时长显隐，以及引用选择器。双语手册119和Jar内容校验通过。

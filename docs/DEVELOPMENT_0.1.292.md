# 0.1.292 编辑界面与粒子入口修复（2026-10-29）

攻击模块pulse的显示名称从“范围脉冲 / Area pulse”改为“冲击波 / Shockwave”，双语手册中的对应名称同步。内部类型、保存ID和运行行为不变。

抓取对象组合选项显示“玩家和生物 / Players and mobs”。补齐主面板真正查找的choice_grab_players_mobs、choice_signal_all/any，以及冻结铺设choice_freeze_centered/ahead翻译。信号逻辑显示全部条件满足（AND）/任意条件满足（OR），冻结铺设显示以释放点为中心/从释放点向前铺设。原先已有不带choice_的文字给其他面板使用，主面板因此仍会显示原始键；这次两个入口都保留且补齐。

冻结/抓取的“选择粒子”之前被HeartDashboardMenu的旧类型白名单拒绝，虽然VirtualModule已经允许编辑粒子。新增VirtualModule.supportsParticles作为共同判断，菜单打开和实际粒子编辑共用它。药水效果模式继续限定ModuleEffects支持类型，未知模式不打开；原有阶段粒子入口保持。原生菜单测试实际打开冻结和抓取的EffectSelectionMenu、确认ParticleMode、添加电弧和RGB、返回主面板，并验证激活后不能修改视觉配置。

SignalRuleScreen把标签与选择按钮/数值输入框排在同一行，战斗事件七项设置（事件类型、筛选、来源、输出频道、强度、脉冲和冷却）在支持的常用GUI尺寸同一页显示。右侧不需要分页时隐藏翻页按钮和页码；更小空间保留自适应分页。左侧规则列表仍独立分页，避免64条规则挤在一页。信号条件编辑也用同行布局。长说明保留在工具提示，频道/时间标签缩短以免截断。规则存储、权限、来源筛选、时序和数值验证不变。

验证：89项相关原生测试（核心编辑/粒子/冻结抓取/信号）通过。8组信号规则界面在GUI比例1–4的实际有效尺寸均不需参数翻页；输入焦点保留、控件在屏幕内。14组冻结/抓取主面板和16组信号主面板比例/密度检查通过。新增选择文字检查按正式ModuleFields逐项验证freeze/grab/signal_logic/pulse的choice_名称，包括未选中的冻结向前铺设，在实际客户端和中英文资源中均能解析。最终规则/冻结抓取22组再次通过并打包，实际截图已检查。

# 0.1.304 召唤武装（2026-10-30）

新增攻击模块“召唤武装 / Summoned weapon”。Mark部件方块、选择非消耗显示物品、选择已有Gun/Arrow/Flamethrower/Laser模块。支持显示缩放0.05–32、模型XYZ校正、Start distance0–64和部件本地XYZ偏移、跟随部件/固定生成时世界位置、固定方向/持续追踪、目标分类与范围、转向速度、瞄准水平/俯仰偏移、发射口本地XYZ、存在时长0.05–600秒（默认5秒）。模型校正不改变发射方向；发射口基于瞄准框架，+Z为前方，偏移不随显示缩放放大。预览显示物品轴线及发射方向。

一个模块每次触发生成一个武装、引用一个攻击模板；持续通电到期不会自动重生，关闭再开启或下一次Move set激活重新生成。到期/失去触发/死亡/卸载/删除引用清理显示和持续攻击，已射出的箭和子弹保留原行为。失去目标保持最后朝向继续攻击。固定世界模式锁定生成位置，跟随模式随Mark部件运动。

复用原Gun、Arrow、Flamethrower和Laser运行逻辑，通过仅存在于内存的Emitter框架接管原点/方向。每个武装有独立攻击状态和声音归属，原攻击仍可独立运行；忽略模板Mark、Start distance、触发和瞄准，保留伤害、射速/蓄力、射程、散射、粒子、声音、附加效果等配置。攻击配置在生成时快照。命中和击杀归属原攻击模块，多个武装引用同一模板会汇总到该来源的计数。

模板可以禁用或不Mark，以避免本体额外开火。禁用模板被武装执行时，其引用的命中持续范围伤害仍有效；武装结束后按来源停用规则清理区域。使用原版ItemDisplay实体同步，显示本身无碰撞/伤害，不持久保存，不产生物品掉落；武装清理同时移除显示。仅添加Display变换Invoker，不新增网络包。预设清除跨模块引用，普通模块复制保留引用，整生命体复制和Photomancy蓝图重映射UUID。

验证：192项control/blast相关原生测试通过（含8项召唤实际Gun/Arrow/Flame/Laser伤害与来源计数、几何、到期重触发、原Gun与两个武装独立发射、世界/跟随），另外38项配置/持续区域测试通过（含3项来源选择与显示物品菜单、实际目标分类/角度/发射口、禁用模板命中区域及清理），共230项不重复测试。16组客户端比例/密度面板检查通过，截图已检查。独立客户端世界两件召唤武装的原版显示同步、模型旋转、世界/跟随和死亡清理通过，截图已检查。手册137：57章节44模块双语验证通过。未做大规模多人长时压力测试或所有第三方物品模型校准。

# 0.1.88：迫击炮与落雷多目标

在迫击炮与落雷的目标类型下方新增「Target multiple / single」小勾选框。未勾选是单目标（默认），勾选是多目标；左右键均可切换。仅迫击炮的 Target position／落雷的目标追踪模式可编辑，其他模式置灰并忽略此值。

迫击炮每轮对范围内各符合类型、可解出弹道的目标独立发射一枚，单目标保留最近可达目标。Preview 会展示各条弹道。发射音效每轮播放一次，不按人数叠加。伤害和冷却保持原值。

落雷每轮在各目标脚下独立冻结预警点，仍排除中心安全区和范围外目标。玩家可以离开预警圈，已定落点不会继续追踪。每轮最多选择最近 64 个目标，避免怪物过多导致无限发射。

这里控制的是「选择几个目标释放招式」，不是每发攻击最多伤害几人；爆炸和落雷圈内命中仍保留范围伤害。已经按范围影响全体目标的牵引／力场不需要用这个开关。当前激光仍保持一条射线。

## 本轮待测

- [ ] 两名生存玩家在范围内：勾选后每人一枚炮弹／一个落雷预警点；不勾选只选择一人。
- [ ] 目标类型、范围、起始安全区正常，创造和旁观玩家不被选择。
- [ ] 迫击炮弹道各自正确，预览、直接伤害和爆炸伤害正常。
- [ ] 落雷预警固定，多人离开各自圈后可以躲避；原先其他模式正常。
- [ ] 勾选框紧接目标类型，固定模式变灰；保存重载、数据复制器及 Photomancy 保留。

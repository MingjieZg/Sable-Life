# 0.1.291 抓取普通生物：仅约束位置（2026-10-29）

抓取/束缚新增“抓取对象”：玩家、普通生物、玩家和普通生物。默认仍为玩家，旧存档缺少grabTarget时保持玩家模式。每次捕获最近的一名有效对象，已经被其他抓取占用者跳过。普通生物使用世界实际Mob实体，动物/怪物等可用；不从ModuleTargets的机械生命体适配查询获取对象，Sable LifeTarget、盔甲架/装饰实体始终排除。玩家继续排除创造、旁观和死亡。

按用户最终要求，普通生物不暂停AI，不取消travel，不设置NoAI。原索敌、攻击、转头和移动尝试照常运作，只在实体tick前后约束位置并清除位移/摔落积累。受伤、效果及实体生命更新继续。NoAI、NoGravity和移动属性均不修改；原本禁用AI的生物也不会被打开AI。临时AI和travel拦截方案已移除，安装包不包含对应Mixin。

MobGrab为普通生物保存运行绑定及来源/到期时间，与玩家PlayerFreeze分开但由同一抓取模块清理。跟随同一Mark局部点，按实际身体高度换算脚底。RestraintPath复用双方的实际体积路径/已加载区块/世界边界校验，单刻8格上限不变。地形阻挡、失效、断信号、停用、死亡/移除/卸载、换维度和到期会释放。每服务端最多256个普通生物绑定，不写入实体NBT。普通生物位置沿用原版追踪及插值，不混入独立相对移动包。

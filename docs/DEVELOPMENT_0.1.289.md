# 0.1.289 范围冻结模块（2026-10-29）

新增freeze模块（范围冻结 / Movement freeze），在攻击分类中，可被Move set及现有触发方式调用。支持Mark point和On target；目标模式寻找最近的存活生存/冒险玩家，不需要Mark。释放时采样中心，预警期间不会追着目标移动。预警结束才捕获包围盒触及球形范围的玩家，提前跑出去可躲避，也会捕获预警期间进入范围的玩家。

设置：搜索距离1–256格、半径0.5–32格、预警0–60秒、冻结0.05–60秒、重复间隔0.05–600秒。默认半径8格、预警1.5秒、冻结2秒、间隔5秒。间隔从预警+冻结结束后开始，避免默认连续无限刷新。Move set动作持续时间须覆盖预警和冻结时长，否则关闭触发会立即释放。

预警默认minecraft:snowflake雪花冰晶，可在原粒子列表替换，支持现有Color/Life/Size；Color取决于粒子本身支持情况。预览只绘制范围粒子，不冻结玩家。附带可选预警音效和冻结音效，沿用声音组合。移除默认粒子后保存/预设不再重新添加，反复加载也不重复默认项。

冻结世界位置（XYZ），限制走路、跳跃、击退位移，暂停下落并清空摔落距离。保留转动视角、攻击、举盾。没有伤害、减速药水、原版冰冻条或免伤。创造/旁观、死亡玩家及生物不受影响；骑乘玩家捕获时下坐骑，滑翔停止。捕获后不会因走出范围解除。允许同维度传送被约束，换维度会解除。

客户端接收有界时长/位置消息，禁用移动输入并固定位置；服务端以主线程Mixin把移动包的位置固定、保留朝向，玩家tick清除运动和摔落。仅冻结期间清除原版clientIsFloating/aboveGroundTickCount计数，避免有意悬空被判飞行；不改变未冻结玩家的检查。

多个来源共享首次捕获位置，各自独立计时，移除其中一个不解除其他来源。每服务端最多256名冻结玩家、每玩家最多64个来源；单次模块最多捕获64名。运行租约不写NBT。触发关闭、模块停用/删除、核心卸载/死亡、玩家死亡/换维度/退出及服务器关闭会释放；到期恢复移动。配置随模块NBT、预设、复制及既有schematic流程保留。协议升至23，客户端服务端须同版。

188项相关原生GameTests通过（8项冻结+粒子/控制/核心UI回归）：默认与编辑、Move set兼容、标记/目标、范围及模式过滤、无伤害、预警逃离与晚进入、中心不追踪、停用释放、来源重叠与到期、位置包约束与保留视角、击退清除、死亡/创造解除、包编解码、粒子保存。

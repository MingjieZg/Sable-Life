# 0.1.312 无线红石跟随输入强度（2026-10-31）

Wireless redstone新增输出强度模式：固定强度（默认）/跟随输入。固定模式保留既有0–15设定及二值反转。跟随模式支持Internal wireless、External RX、Anchor power；持续输出实时保留输入强度，统一用于方块面、内部输出频道及外部Create频率。模拟输入取0–15并遵循既有有效状态、总开关和Trigger检测；Anchor power取邻接红石最大强度，普通控制检测继续排除邻接核心的心跳供电，旧LegacyPower路径保留完整邻接检测。

Follow只对上述三种有模拟强度的Trigger生效。Always、Move Set与Hurt继续使用固定输出强度。界面的固定强度输入框只在前三种Follow模式中禁用，其他场景继续可编辑。原Redstone strength标签改为Fixed output strength/固定输出强度，避免把配置值误认为实时读数。

输出行为仍可选Hold/Pulse。Hold逐刻跟随；Pulse在输入上升沿记录强度，完整保持到原脉冲截止时间，输入断电不会截断，持续高电平不会反复延长。Follow模拟反转为15减有效强度，因此输入0、脉冲外为15；停用、死亡、解除或关闭总开关仍关闭所有输出。Fixed及非模拟Trigger的反转保持旧行为，不改为模拟补数。内部同频道仍取最大值，各来源分别清理。

原生测试：13项跟随/方向/预览测试通过，其中覆盖三个模拟输入来源、方块面/内部/外部三类去向、7/2/15/0/11动态强度、反转、脉冲采样及超时、旧默认/保存/预设、停用死亡清理，以及真实Move Set动作窗口和Hurt触发回退设定强度；另148项原有控制测试通过。首次Anchor测试采用的红石粉在放置时自行重算为0，已换为保持模拟POWER值的压力板模拟源进行复核，不改生产供电规则。16种缩放/密度的强度模式界面测试通过，覆盖Internal、External、Anchor与Move Set下的编辑框禁用/启用。手册144（57章44模块）通过。随后仅将强度标签明确为固定输出强度。assemble打包成功。

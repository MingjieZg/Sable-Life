# 0.1.293 范围冻结支持普通生物（2026-10-29）

范围冻结新增“冻结对象”：玩家、生物、玩家和生物，默认仍玩家，旧配置保持原样。Mark point和On target都按相同筛选工作；On target寻找最近有效对象，不会把其他Sable生命体作为目标。普通生物使用实际Mob实体，Sable LifeTarget、盔甲架和装饰实体排除；玩家仍排除创造/旁观/死亡。

圆柱/旋转长方形、高度、方向与起始距离、预警粒子和独立预览沿用上一版。预警结束时重新检查当前包围盒，只有仍在范围内者被捕获；生物可在预警结束前离开，也可在期间进入。实际Mob查询使用ControlVolume.bounds作为粗筛，再用同一份圆柱/OBB几何精确判定，不把旋转包围盒当作实际范围。单次最多64名对象。

生物在捕获时的世界位置固定，AI、索敌、攻击、转头和移动尝试继续执行，仅在实体tick前后约束位置/速度并清空摔落距离。不设置NoAI、NoGravity、移动属性，不取消AI/travel，不提供伤害或免伤。正常实体生命、受伤和状态效果继续。沿用原版客户端实体同步。

MobGrab运行控制扩展为固定冻结租约+可选抓取跟随，普通生物的多个冻结来源分别计时，最多64个固定冻结来源、全服务端最多256个受控生物。删除或关闭一个来源不解除其他冻结。冻结对象可继续被抓取搬运；抓取到期或中断后，尚有效的冻结让它停在释放位置，不弹回原位置。抓取遇墙释放时同样保留其他冻结。玩家原有租约保持。

到期、触发关闭、模块停用/删除、核心卸载/死亡、目标死亡/移除/卸载及换维度会清理相关控制。运行租约不保存，实体原AI/重力标志不改；freezeTarget设置随模块NBT、预设及原配置保存流程保留。

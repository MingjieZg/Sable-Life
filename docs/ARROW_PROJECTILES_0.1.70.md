# 箭矢自定义发射物 — 0.1.70-dev

箭矢模块加入发射物物品样本选择、大小、hitbox 直径、发射音效。空物品样本仍显示原版箭矢；放入剑、工具或其他物品会显示整件物品的模型，朝向随弹道变化，可用于飞剑。样本不消耗，不产生物品掉落。

- 发射物大小：0.1–8，默认 1。自定义物品按模型最长边换算为格；原版箭矢按默认模型倍率缩放。
- hitbox 直径：0.05–2 格，默认 0.25。独立于外观大小，实际参与实体命中和方块的扫掠碰撞。
- 发射音效默认原版箭矢发射声，支持原版声音和自定义 OGG，每次齐射播放一次。
- 保持箭矢重力、速度、散射、药水效果、落地爆炸等既有属性。物品只决定外观，不附加样本武器的伤害或附魔。
- 移除样本恢复默认箭矢；大小、hitbox 和音效会随存档及模块复制保存。枪、迫击炮原先的大小／hitbox 同步行为保持。

待游戏内检查：默认箭矢、飞剑／工具的完整外观和朝向；大小与 hitbox 独立；宽 hitbox 擦边命中实体／墙体；音效、药水、落地爆炸；存档重载与蓝图复制。

# 0.1.311 目标对准内部方向频道（2026-10-31）

Target alignment 新增左、右、上、下、前、后六个内部输出频道，默认0不绑定；输入取整数、滚轮每次1。沿用原来的角度计算和实体输出面，内部信号保留实时0–15强度。左右/上下是修正量，对准后归零；前/后仍是方向对准强度，正前方前输出15。反转同时交换内部方向与实体输出方向。

用户原先通过External RX触发Wireless redstone中转，后者按设定强度15输出，不会保留输入的模拟强度。新频道可直接给Signal turning的对应内部输入，不再需要这段中转。两个模块应使用一致的Mark正面。Wireless页先添加并启用频道，选择序列控制/内部；也支持序列控制/外部TX把动态值发到Create频率。锁存需关闭以跟随当前强度。原有周期/外部RX频道不接受模块程序输出，遵循现有频道模式规则。

同一频道多个方向、模块或其他程序来源取最大值；导航独立发布，不覆盖其他来源。失去目标、结束触发、停用/删除导航模块、死亡/解除及清理会撤回该来源；总开关关闭后输出0。删除无线频道将对应引用设为0，后续序号随频道移动；配置复制和预设保存频道设定，Mark仍需重新指定。控制处理在导航采样之前，转向反应最多延后一游戏刻，未调整移动/转向优先级。

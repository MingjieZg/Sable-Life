# 目标导航：0.1.40-dev

Data Copier 使用原版纸张材质；复制和粘贴行为不变。

在 Heart → Add module 第二页添加 Target navigation。它是虚拟模块，不新增实体方块，也不会直接旋转机械；方向信号交给实际转向装置执行。

1. 选择目标：玩家、生物（不含玩家）、全部。创造模式玩家和旁观者不被选中。
2. 配置搜索半径（1–128 格），默认 32 格。视线检查默认开启，会忽略自身生命化结构，外部墙体会阻挡。
3. 点击 Mark front / output，标记机械正面的水平面。该方块成为输出点。标记上下表面时默认以本地北方为正面，也可在 Construct front 中修改。
4. 把输出点的左右侧分别接到对应转向控制。默认左转／右转模式：目标偏向哪边，哪侧输出 1–15；偏差越大越强。目标正好在后方时保持已选转向，避免反复换边。进入默认 3° 死区后左右归零。前后侧仍输出对应方向的对准强度。
5. 若要导航桌式输出，切换为 Directional strength：前后左右强度均按目标方向对准程度计算，正对为 15，反向为 0。不要把四侧合并成同一根红石线，否则会丢失方向信息。
6. Keep target 保持当前目标，死亡、离开范围或被外墙遮挡后重新选最近目标；Nearest target 每五 tick 重新选择最近的合法目标。

Preview 显示搜索范围和输出方位：金色正面、红色左侧、蓝色右侧、灰色背面。运行时界面显示目标名称及左右信号值。每 tick 按标记刚体当前姿态重新计算方向；结构旋转后本地接线含义不变。

支持既有 always、anchor power、内部 repeat、外部无线 RX 触发。输出是标记方块各侧的模拟红石信号；可接 Create 无线红石发射端，把转向信号传到其他关节。未直接占用或改写核心内置无线序列器的频道。

模块停用、死亡、解除生命化、卸载、目标消失或标记断开后输出归零。导航信号不进入旧传感器的对角广播路径，避免左右信号互相混合。多个模块在同一输出侧取最大值。

验证：assemble 编译打包通过。未运行自动测试，机械实际转向与接线需要在游戏中验证。

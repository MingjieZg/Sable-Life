# 0.1.27 测试清单

1. **选择记忆**：选择第 4 个或下一页的模块，出去标记、预览，再打开 Heart，应返回该模块。打开 Wireless／模板页再返回也应保留选择。当前为游戏会话内记忆。
2. **Limb Loot 布局**：无 Trigger 和 Channel。原 Trigger 行是 Loot templates，右下原模板位置是 Preview。
3. **Limb 标记与奖励**：未激活时在准备切下的肢体上选择一个会保留下来的方块，填写模板。Preview 显示锚点方框和当前刚体金色轮廓。如果和躯干还是同一个刚体，轮廓会包含躯干；实际切断后按锚点所在的新碎片识别。激活、切断后等待 3 秒，该断开的连接组消失并掉模板，主体保留。同一个碎片只登记一次奖励。
4. **锚点注意**：不要把锚点放在要挖掉的连接块上。唯一锚点直接被拆除后无法定位新断肢，需要创造解除并重新标记。本版不会猜测附近碎片；仅修改模板不会为已经结算的旧断肢再次发奖励。
5. **箭矢和喷火触发**：允许在实体箭矢／喷火模块表面标记虚拟出口；同类型实体模块会被该虚拟标记接管。切 anchor power：无控制红石应停止，直接相邻核心心跳不应自行触发；给信号只执行虚拟的一份输出。切 internal repeat：按所选内置时序运行，不额外执行实体方块。
6. **外部 Create 接收**：在 Heart 顶部 Wireless 页选一个频道，复制红／蓝频率物品组合，启用频道并切“Channel: external receive / RX”。时序数值灰化，显示 External signal 强度。在攻击模块中切“Trigger: external RX”，选择此频道。世界里的 Create Redstone Link 使用同组合并设为发送端；通电开始攻击，断电停止。RX 频道不运行自己的循环，也不会同时发送。不同用途的频道建议使用不同物品组合，Create 原生网络会合并相同频率的信号。
7. **原内部时序**：频道选 internal repeat / TX，攻击选 internal repeat；继续发送 Create 信号驱动关节。外部 RX 和内部 TX 分别占用各自频道，原有配置保留。
8. **保存与停止**：保存重进仍保留 RX 模式、频率和 Loot 设置。断肢任务重载后只掉一次；核心死亡、卸载、创造解除后关闭无线监听和攻击。

自动验证：构建成功，99 项 GameTest 全部通过，包含真实 Create 外部发射端、箭矢和喷火不重复执行、选择记忆及断肢奖励重载去重。

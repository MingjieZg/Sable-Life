# 0.1.116 受伤触发测试清单

状态：自动测试通过；以下项目待回家后人工验证。

## 设置入口

先让生命体处于可编辑状态。在任意支持 Trigger 的模块（包括 Move set）中切换到 **Trigger when hurt**。原 Channel 输入框的位置改为 **Hurt settings**，点击进入设置：

- Response：Once / Timed / Stay active。左键下一个，右键上一个。
- Cooldown：每个模块独立的受伤触发 CD，默认 0 秒。
- Duration：仅 Timed 可编辑，默认 5 秒。
- Reset activation / cooldown：Stay active 中可以手动清除激活状态和 CD。

受伤触发不需要创建无线频道或放红蓝频率物品。实际扣除核心生命值才触发，完全被防御抵消的伤害不触发；致死伤害进入死亡流程。

## 人工检查

- [ ] 箭矢模块设 Hurt / Once：激活生命体后不自动攻击；受到伤害发射一次。再次受伤可以再次触发，但仍受模块原有发射间隔限制。
- [ ] Laser / Homing / Ground strike 设 Once：完整完成蓄力和一轮攻击；攻击途中再次受伤不会重启或追加同一轮。
- [ ] Move set 设 Hurt / Once，动作模块设 Trigger: move set。加入延迟开始的动作，受到伤害后完整执行一个招式，结束后停止。途中再次受伤不重启招式。
- [ ] Move set 应有符合目标、距离、HP 等条件的招式；不符合条件时不会执行，也不会把这次受伤排队等候以后执行。
- [ ] 两个独立 Hurt 模块分别设 1 秒、5 秒 CD，连续攻击生命体，确认分别响应；CD 从接受伤害触发时开始计算。
- [ ] Wireless redstone 设 Hurt / Timed / Duration 3 秒 / CD 1 秒：受伤后输出 3 秒，CD 内受伤不刷新，CD 后受伤重新延长 3 秒。确认 Mark 输出与外部红蓝频率输出正常。
- [ ] Stay active：第一次受伤后持续运行，停止受到伤害仍运行；手动 Reset 后停止，再次受伤可重新启动。
- [ ] 普通 Move set 保持原 Trigger，另外添加独立 Hurt 攻击模块，确认正常招式与额外受伤反击都能运作。每个模块只有一个 Trigger，额外反击请用独立模块实例。
- [ ] 总开关关闭再开启、模块禁用、Release、死亡、重新载入后，受伤激活状态应清除，不应自行恢复。
- [ ] 保存世界、重新载入、蓝图复制后，响应模式、CD、Duration 保留；运行中的激活状态和剩余 CD 不复制。
- [ ] 原 Always / 激活 / 内部无线 / 外部无线 / Move set 等触发方式仍正常；切换回无线触发时 Channel 输入框恢复。

# 0.1.61 MC 音效双击导入

- MC 按钮打开游戏内原版 OGG 文件列表，支持文件路径搜索和分页/滚轮。双击同一项（350ms 内）导入具体 OGG 变体并选中当前模块的音效字段。
- 自动复制至 config/sablelife/sounds，刷新自定义声音资源包，不用重启游戏；重载结束返回原模块。重复导入同一资源复用稳定文件名/音效 ID。
- 浏览器的“打开文件夹”仍可导出并打开 Windows 音效目录。Windows 资源管理器双击 OGG 仍使用系统默认播放器，本功能不修改系统文件关联。
- 本体原始资源不修改。只允许原版资源、OGG 头、单文件最多 16MB，沿用自定义音效 128 文件上限。
- 休眠可编辑核心可自动选中；只读核心只能浏览/导入本地库，不修改配置。资源重载期间关闭界面不会修改另一模块。
- 自动导入/注册适用于当前单人开发客户端；独立服务器需要同样的自定义音效文件并刷新服务器库，未实现文件自动上传。

验证：编译检查；游戏内双击、重载后播放、重新进入与重复导入待验收。

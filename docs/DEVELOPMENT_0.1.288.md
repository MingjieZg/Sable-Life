# 0.1.288 自带粒子形状扩展（2026-10-29）

新增六种形状，其中光环拆为扩散/收缩两个选项。现有列表搜索sable，所有选项共用Color / Life / Size和可调色标识；不增加模块或伤害行为。

| ID | 样式 | 默认寿命 |
|---|---|---|
| sablelife:branching_arc | 动态主电弧和两条细分支 | 0.6秒 |
| sablelife:spark | 细长火花，带少量重力；没有给定速度时自行轻微飞散 | 0.5秒 |
| sablelife:light_ring | 中心向外扩散光环 | 1秒 |
| sablelife:inward_ring | 外侧向中心收缩光环 | 1秒 |
| sablelife:crescent | 弯曲月牙光片 | 0.7秒 |
| sablelife:soft_fog | 渐变边缘雾团，膨胀、上飘、淡出 | 2.4秒 |
| sablelife:starburst | 四角星芒和柔和中心 | 0.6秒 |

原有sablelife:arc也改为动画：每2刻重新生成内部折线，主端点不变。不是每帧随机变化，不受帧率影响。普通电弧默认0.3秒，延长Life会继续变换直到结束。旧烟雾和能量点保留。

形状均为面向镜头的粒子，不是世界固定平面上的攻击边界、双标记连接闪电或真实光源。Color仅影响自身RGB，Life为0使用默认，Size为0.1–4倍。发射位置/数量/速度仍由现有粒子模块或攻击模块决定。零速度的火花有轻微默认随机速度；给定速度时保留发射器速度。

新形状使用独立粒子着色器，沿用原版粒子顶点、雾和光照，透明度裁切降至0.001并关闭写深度以保留柔和外缘。不改原版粒子或全屏渲染。纯几何形状复用中性原版粒子图集 texel，无图片资产、实体、伤害或额外网络包。每粒子几何固定上限，沿用既有粒子发送预算。雾团受环境光影响，其余新形状自身明亮。资源重新加载使用NeoForge着色器注册回调。

验证：17项原生粒子GameTests通过，十种自带粒子均可注册、参数编辑、NBT和预设往返。隔离世界通过默认原版包及自定义样式包生成20个粒子，验证RGB/Life/Size、贴图及到期回收；普通/分叉雷电在真实引擎tick后折线变化且主端点不漂移。检查实际前后帧截图，光环扩散/收缩和柔和雾团可见。粒子编辑界面GUI比例2、3通过。手册124、54章节、41模块校验。未重复完整战斗/多人压力或外部光影模组兼容测试。

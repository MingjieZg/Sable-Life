# 0.1.24 统一核心与标记基础测试

本轮未启动客户端。虚拟能力目前是配置原型，不会攻击／喷火／发奖励；现有实体模块仍照常执行。下一阶段才接入虚拟近战。

1. 创造模式空手右键 Heart：应打开铜色／紫晶统一面板，顶部可进入核心设置、原有 16 频道无线时序和整体战利品。无线返回按钮回到统一面板。
2. 点击 + 添加模块，可添加近战、喷火、箭矢、脉冲、感应、声音、肢体 Loot 的配置记录。重复添加两次近战，分别命名、修改伤害与击退，确认互不串设置；最多 32 个，分页显示。
3. 直接输入参数后按 Enter 或 ✓。伤害上限 1000、击退上限 100，间隔显示秒；删除需在 3 秒内再次确认。保存退出再进入，检查模块 UUID、名称和参数保留。
4. 近战点击标记：界面关闭。右键同一段结构的两个方块作为角点，选区包含两个端点方块，边长最多 32 格。地形和跨关节两点应拒绝。完成自动返回统一面板。
5. 喷火或箭矢点击标记：右键结构方块表面，记录面朝向作为出口；方向预览应朝外。点击预览后关闭界面，显示约 5 秒；期间移动／旋转结构，轮廓和出口应跟随。
6. 标记到一半按 Esc 或 Shift 右键取消，确认原有标记没有被替换。两人编辑同一核心时，旧版本提交应被拒绝，标记会话不串人。超时、换维度、切生存或激活取消标记。
7. 拆掉出口方块再原位补回：模块标记仍失效，需重新标记。将有标记的方块拆分成新的 Sable 结构：标记应迁移到实际新结构并显示已脱离主体，而不是留在原躯干。
8. 模块触发可选持续、标记处红石、内置无线；无线频道填 1–16。当前只是保存和解析触发条件，虚拟攻击尚未执行。原来的 Create 接收器驱动关节仍应正常。
9. 激活后虚拟配置只读，生存不能打开统一面板。创造解除后可编辑，虚拟配置与无线配置保留；核心已有其他选项仍沿用既有解除规则。

优先反馈：各 GUI 缩放下文字是否遮挡、实际表面朝向是否准确、标记时是否误放置方块、关节上的出口是否跟随肢体。

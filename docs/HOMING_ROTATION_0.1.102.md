# 0.1.102 悬浮弹双轴旋转

- 原 Fan rotation 保留：在排列平面内旋转，∩ 旋转 90° 会变成侧向弧。
- 新 Fan rotation vertical：绕生命体竖直轴转动整个排列平面，范围 -180°–180°，默认 0。
- 原旋转设 0，新旋转设 90°，即可从侧面看见保持向上拱起的 ∩。
- 两个角度可以组合：先原平面内旋转，再绕竖直轴旋转；不改变排列中心及尺寸。
- Preview 与实际展开共用双轴计算；保存、复制和 Photomancy 保留新属性，旧配置新角度默认 0。

# 0.1.96 统一目标分类

- Player／玩家：可受攻击的生存／冒险玩家，继续排除创造及旁观者。
- Other mob／其他普通生物：Minecraft 及其他模组的普通生物；不混入本模组机械生命体。
- All／全部：包含以上两类及本模组其他已激活的生命体。使用注册类型查询，不把其他模组生物写成白名单。
- Other Sable Life／本模组其他生命体：已激活且尚未进入死亡阶段的其他核心结构，排除自身、休眠、解除生命化及死亡的结构。

统一应用于追踪弹、激光、迫击炮、落雷、地震、牵引、脉冲、传感器、转向和招式调度。固定方向攻击的命中范围也可以识别其他生命体。对方关闭“受到其他生命体攻击伤害”时仍会被侦测或瞄准，但不会受伤；玩家攻击规则不变。

结构目标不生成任何世界实体，使用实际结构的坐标、边界和核心 UUID。伤害转入真实核心；追踪目标解除生命化／死亡后不再有效。牵引／击退速度转入 Sable 物理系统。Minecraft 药水不施加到方块生命体。

旧类别编号 Player=0、Other mob=1、All=2 不变，新类别追加为 3，因此旧保存和复制设置保持原类别。

后续含 target 的模块使用 ModuleTargets.CHOICES、ModuleTargets.matches/query/resolve/visible。目标身份与判定集中在 ModuleTargets；避免重新写 players/mobs/all 三类判断或只扫描 LivingEntity。

# 0.1.103 核心翻页／回血／排列朝向

- Life Core Settings 缩短为 210 高，三页分别为基础数值、保护与伤害开关、回血属性；保留顶部 Modules／Wireless／Whole-body loot 导航。
- 每秒回复生命值：0–1,000,000，默认 0（关闭）；受击后等待：0–600 秒，默认 5 秒。
- 等待期结束后，每 20 刻回复一次设定生命值；每次实际伤害重置等待和回血周期，不超过最大生命值，休眠／濒死／死亡不会回血。
- 回血属性可在存活时调整；数值和剩余等待／回血周期保存重载，配置复制和 Photomancy 保留回血属性，解除生命化也保留作者设置。
- 排列顺序：Arc、Line、Star、Star (vertical)、Circle、Circle (vertical)、两种斜线。
- Star／Circle 默认处于水平面；vertical 版本处于竖直面。两个 Fan rotation 继续组合，Preview 和生成保持一致。
- 旧版 Star／Circle 自动迁移到 vertical 版本，以保留原竖直外观。

# 0.1.92 本轮检查清单

## 改动

- 停止 Heart 激活后的自动红石脉冲。无线红石、感应器、招式／序列等明确配置的信号功能继续保留；血量比较器输出保留。
- Wave count 滚轮每次增加／减少 1，边界仍为 1–8。
- 地震追加 Target detection radius（目标侦测半径），默认 32 格，范围 1–128；用于 Wave origin = Nearest target feet 时寻找最近有效目标，不受攻击大小限制。
- 原 Travel distance 改为直线模式 Wave length（波浪长度）／环形与全范围模式 Effect radius（作用半径）。这两项是同一份旧攻击范围值，既有配置保持；侦测半径是新增独立值。
- 全范围模式不使用 Wave width / Wave speed，对应输入框淡化。
- 激光 Target 模式追加 Single target / Multiple target 勾选，默认单目标；多目标最多选 64 个符合目标类型、射程和可视条件的目标，一轮开始时选定，各光束独立预警／追踪，声音和冷却按一轮执行。
- 激光交叉光束每个伤害间隔对同一受害者最多扣血一次；目标死亡或离开射程，该光束停止追踪，下一轮重新选择。固定模式保持单条光束。

## 本轮待你检查

1. 只放 Heart、激活后周围红石灯不再周期闪烁；另行配置无线红石／感应器／序列时仍能输出。
2. Wave count 滚轮 1→2→3，反向 3→2→1，最大 8，保存重载保留。
3. 地震目标侦测半径 32、作用半径 2：距离标记点约 10 格的生物能被选为脚下中心，攻击只覆盖该中心周围 2 格；超出侦测半径不启动脚下招式。
4. 地震直线显示 Wave length，环形／全范围显示 Effect radius；旧数值、预警、伤害、击飞、连续波及复制保持正常。
5. 激光 Single target 只有一条预警／激光；Multiple target 对多人／多生物分别预警、独立追踪；预警更新和发射追踪速度沿用上一轮已确认的行为。
6. 激光多目标交叉时伤害不叠加，死去／跑出射程的目标不继续追踪；固定模式勾选变灰，保存重载与 Photomancy 复制保留设置。

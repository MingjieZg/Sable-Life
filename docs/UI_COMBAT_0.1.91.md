## 招式接线例子

1. 建立两个 Sequence/internal 频道，例如 1、2，用来启动两套 Pulse sequence。
2. 每套序列使用 Internal wireless 触发，分别绑定频道 1、2。序列输出技能所需的内部频道，或通过 Sequence/external TX 驱动 Create 外部终端。
3. 选择任一招式调度模块，点击“编辑招式列表”，在列表添加两招。两行分别填启动频道 1、2，权重 10、30。
4. 两招都满足血量／目标／冷却条件时，抽选概率为 25%／75%。若开启避免连用，会优先排除刚用的那招（有其他可用招时）。
5. 同一核心一次只运行一招，等待它的序列结束及休息时间后再抽下一招。每行单独设置冷却。

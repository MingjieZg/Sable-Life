# 0.1.33：虚拟发射模块

- 所有模块数值框右侧显示浅色上限；时间字段按界面秒数显示上限。
- 喷火、枪武器、迫击炮各自提供发射音效选择，包含 None、内置音效与专用 sounds 文件夹的自定义音效。喷火每个攻击间隔播放一次；枪每轮齐射播放一次；迫击炮每发播放一次。
- 箭矢增加碰撞方块后爆炸开关，默认关闭。可设置爆炸伤害（0–1000）、半径（0.5–16）、破坏方块（默认关闭）。普通箭矢伤害算法保留。
- 枪武器发射小型铁粒外观子弹，不受重力影响。可设置伤害、间隔、速度、弹数、散射、方向、射程、音效以及独立爆炸属性。子弹直接伤害不随飞行速度变化。
- 迫击炮发射火焰弹外观炮弹，支持速度、45–85 度仰角、直接伤害、间隔、方向、音效与爆炸属性。仰角相对于水平面；标记朝上或朝下时水平朝向回退到北方。
- 迫击炮 Preview 显示高弧线和预计落点红圈；飞行中的炮弹带烟迹，并持续更新地形落点预警。预警不预测生物拦截；移动障碍或生物可能提前截住炮弹。未加载地形不显示虚假的落点。
- 枪武器与迫击炮位于 Add module 类型列表第二页。所有新能力仍由 Heart 统一管理，可使用持续、标记点红石、内部无线时序、外部无线接收触发。
- 枪与迫击炮碰撞生物或方块均可引爆。箭矢只在碰到方块时引爆。爆炸伤害按距离与遮挡衰减，并无视受伤无敌帧；创造玩家不受伤害。开启方块破坏时仍遵循生命结构已有的保护规则。
- 飞行中的发射物保存自己的参数快照；修改模块参数只影响后续发射。子弹与炮弹可存档，箭矢爆炸设置也保存在实体数据中。

验证：仅执行 assemble 编译与打包；按用户要求未运行单元测试或游戏功能测试。实际弹道、音效、爆炸与 UI 需用户在客户端验收。

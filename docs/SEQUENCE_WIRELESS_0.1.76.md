# 0.1.76 序列／无线同屏与反向扫射

## 序列编辑

Edit sequence 采用紧凑布局：左侧步骤列表、中间步骤属性、右侧无线配置，下方显示完整背包及快捷栏。

右侧可用箭头、数字框或滚轮选择频道，新增／删除频道，切换启用／总开关及频道模式。模式按钮左键下一项、右键上一项。序列输出使用 Sequence / internal 或 Sequence / external TX；普通频道波形的完整时序参数仍在原 Wireless 界面调整。

拿起背包物品，点击右侧 R／B 样本格即可指定频率，不消耗手上物品。空手点击样本格清空。样本格不能取出、拖入或通过双击批量取物。背包普通点击保持正常，Shift 快速搬运不启用。

选择一个输出步骤时，右侧自动显示其频道；右侧手动选择其他频道只调整正在查看的频道，不会偷偷改写步骤输出。编辑步骤输出频道仍需在中间输入并确认。新增频道默认沿用原 Wireless 的关闭状态，请启用、放入频率物品并选择合适模式。

活跃核心仍只读配置，可以查看频道和自己的背包。频道删除仍保持引用解绑及后续编号前移。窗口重排只改变客户端格子位置，不改变服务端物品容器或点击编号。

## 光束扫射

Sweep angle 范围改为 −180 至 180 度，支持输入负号及滚轮跨越 0。正数保持原扫射顺序，负数反转方向；0 为固定射线。角度符号也作用于预览，自瞄模式仍不使用该属性。

同时包含上一轮 Output channel 右侧的 Sequence / internal、Sequence / external TX 浅色注释。

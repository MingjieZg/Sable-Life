# 0.1.309 视觉特效：范围颜色滤镜（2026-10-31）

Visual shockwave 显示名改为 Visual Effects / 视觉特效，存档类型ID仍为 visual_shockwave。新增颜色滤镜：独立开关、预设颜色/自定义RGB、强度0–1、淡入/淡出0–10秒。默认关闭；默认紫色、强度0.25、淡入0.2秒、淡出0.4秒。空间波、震屏、视角缩放也各有独立开关，默认开启以保持原配置行为。

滤镜共用标记发射点及效果范围。服务器按每名玩家的世界坐标判断范围，信号有效时保持；离开范围、信号结束、停用/删除模块、死亡、解除生命化或无线总开关关闭后淡出。重复空间波不重启滤镜淡入淡出。滤镜不依赖单次/重复模式，也不由方块接触事件触发；接触事件仍控制波纹/震屏/瞬时缩放。多个滤镜混合颜色，各自独立释放。客户端断开/换世界立即清理，来源中断最多3秒后自动淡出。预览仅操作者可见，约3秒后淡出。

颜色混合与现有空间波共用一次场景复制和后处理，不新增每个滤镜一次全屏绘制。画面保持原始对比度乘以1-强度，强度1会成为纯色。HUD不染色，不改变玩家控制、伤害或判定。客户端“扭曲效果”设置也会缩放滤镜强度，0关闭。第三方Shader/HDR/非标准帧缓冲仍需实际整合包验证。

使用紫色大招滤镜：开启颜色滤镜，关闭空间波、震屏、视角缩放，选紫色0.25；由Move Set动作时长或内部频道维持信号。范围内持续显示，结束渐退。切换开关隐藏对应属性，关闭功能不会删除已填参数。

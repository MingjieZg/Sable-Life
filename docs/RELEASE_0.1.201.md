# 0.1.201 Arena 范围效果组（开发版）

稳定记录仍为 0.1.200，未自动提升。修改前源码检查点：backups/source-before-0.1.201.zip。

## 功能

Arena 新增“范围 Buff”开关，默认关闭；“效果组”打开独立编辑页，可添加、删除、上下排序，满页分页。最多 16 组，每组最多 16 种持续效果，等级 1–5。每组可启停并选择跟随模块、内部频道或外部频道，频道 0 表示未绑定；内部读取无线输出，外部读取接收输入，沿用核心无线页的红蓝频率。

所有效果组共享原 Player range（warningRange），以核心当前位置为中心按水平距离判断，只处理同一世界内存活的生存玩家。Boss 在场地内时也会施加效果，不依赖越界警告；越界惩罚、返回和回血行为不改。Arena 本身必须启用、场地标记有效且触发成立，范围 Buff 总开关开启。

每个核心的 Buff 运行器最多每 20 tick 刷新一次，持续时间固定 40 tick；重复 tick 调用不会重复刷新。先合并同一个 Arena 中已启用效果组的效果，同类取最高等级，再逐个玩家施加。已有较强/较长药水效果按原版合并规则保留，没有 blanket remove。瞬间治疗/瞬间伤害等即时效果不可选，避免把刷新变成重复即时伤害或治疗。

生命阶段模块负责阶段判定及输出信号，效果组仅绑定频道。断信号、离开范围、停用、死亡或解除后停止刷新，效果约 2 秒内自然结束；新旧阶段可能短暂重叠，阶段区间重叠也可能同时输出。频道删除会重映射后续索引并使被删引用解绑；保存/加载和核心复制保留配置，预设保留效果与控制模式，但频道重新绑定。

## 编辑和安全

复用效果选择器，Buff 页显示“持续效果”、固定 2 秒，只允许等级修改；瞬间效果从列表隐藏且服务器再次拒绝。分组菜单验证当前容器、核心/模块对象、距离、权限和修订号；伪造组 UUID、旧修订、删除后的子编辑器、异常数值均拒绝。组及效果列表加载有固定上限，未知或即时效果丢弃。没有保存玩家 UUID/计时列表，也不会主动加载目标区块。

新增菜单与编辑路由使用协议 7，两端应同时使用 0.1.201。旧 Arena 默认不受影响；0.1.200 稳定包、备份和版本记录保留。

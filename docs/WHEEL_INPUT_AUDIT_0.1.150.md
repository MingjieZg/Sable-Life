## 补齐与保护

- Dashboard底部内部/外部无线频道输入补充±1。
- Hurt设置之前没有数值滚轮，现补充±0.1秒；只在可编辑且对应字段启用时发送。
- 虚拟命令Repeat interval补充±0.1秒，优先判断悬停数值框，再处理命令补全/列表翻页。
- 效果/粒子属性滚轮先夹限，避免越界显示；序列与无线页已有的强度/频道±1、时间±0.1保留。
- 搜索、命令正文、列表分页、布尔/模式选择不当作数值步长处理。
- Core生命从±0.1改为±5；原红石强度±0.1会产生无用小数，现改整数。
- 通用策略集中于NumericWheelSteps；Sound mix保留独立策略，防止修改已明确指定的值。

## 验证

构建及步长规则单测通过，覆盖用户指定值、整数值、精细速度/判定尺寸以及时间字段。运行逻辑/默认值未改；实际鼠标交互列入PLAYTEST_CURRENT.md。

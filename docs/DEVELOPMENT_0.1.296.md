# 0.1.296 新增粒子稳定性与清晰度调整（2026-10-29）

针对新增粒子闪烁、模糊反馈，所有10种自带粒子统一使用已有低透明度截断渲染通道，基础雷电/烟雾/能量光点不再经过原版0.1 alpha硬截断。几何形状与雷电改用短平滑进入、尾段平滑退出，保持中段清楚可见。

基础与分叉雷电仍每两tick生成下一组随机折线，但保存前组并按渲染partial tick插值，固定端点，避免整条瞬间换形。雷电主线略加粗，外围光晕收窄并降低透明度。星芒不再每个新粒子随机旋转，缩小中心柔光；烟雾和柔雾仍保留本来柔和外观。现有ID、RGB/Life/Size设置与网络协议不变。

隔离实际客户端两次运行成功；最终检查覆盖10种provider、20个默认/自定义网络粒子、颜色/寿命/大小/贴图/到期，以及全部低alpha通道、星芒固定角度、雷电换形tick边界实际render顶点连续性。截图已检查。未验证用户原实例的着色器组合与连续发射频率下主观观感，未运行全量服务器测试。

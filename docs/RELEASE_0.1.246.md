# 0.1.246 空间波早期可见性与缩放上限

开发版，稳定版仍为0.1.243；协议14，客户端与服务器同时更新。

波纹保留从0到最终半径的线性扩散进度，取消前半程从零增强的曲线，改为开始即可见、末20%淡出。早期环宽限制在当前半径的一半以内，避免小半径被固定宽度覆盖；环内从多重细纹改为单道折射起伏。扩散时间越长，相同时间内波纹半径越小。重复模式的重复间隔独立于扩散时间，间隔短于扩散时间会产生多道同时扩散的波纹。

镜头缩放范围扩大至-100至100%，输入、网络校验、客户端叠加范围同步。正值拉近、负值拉远，最终FOV仍限制1至179度。双语提示同步。

验证：94控制专项原生GameTests、jar构建、双语手册90通过。真实GPU波纹环内5460像素变化、环外0；半径30、释放后5tick，扩散100tick时164像素变化，最大归一化距离0.03575；扩散20tick时1682像素变化，最大距离0.14843，长时间明确更慢且早期波纹可见。背后/禁用/过期无变化、状态恢复和resize通过。未重跑全套358项、原整合包或JUnit。

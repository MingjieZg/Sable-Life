# 0.1.101 飞剑朝向修复

- 0.1.100 把手持模型与手持姿势一起应用，持握旋转叠加到飞行朝向后，剑尖偏离目标。
- 保留 THIRD_PERSON_RIGHT_HAND 模型选择和自定义渲染上下文，抵消手持的持握旋转／位移／缩放；发射物仍由原飞行渲染器控制朝向。
- 烘焙模型大小与中心按手持模型的原始几何计算，恢复原飞剑姿态与尺寸规则。
- 箭矢／飞剑和追踪弹共用修复；其他自定义弹丸继续使用同一模型处理。
- 追踪强度调整保持 0.1.100 的新曲线。

构建验证通过。视觉待测：普通剑、模组武器，飞剑与追踪弹在水平／上方／下方目标和转向时，剑尖应沿飞行方向；同时确认模型、大小与中心正常。

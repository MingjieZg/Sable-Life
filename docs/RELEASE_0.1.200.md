# 0.1.200 稳定版

用户授权完成本轮修改及检查后立为稳定版。原 0.1.193 稳定导出、备份与 GitHub 历史保留；修改前源码检查点为 backups/source-before-0.1.200.zip。

## 原因和结果

Epic Fight 会根据工具是否适合当前方块判断使用挖掘还是攻击动画。因此 0.1.199 的普通工具攻击正常，但战斗模式仍可能选择挖掘。此次在已核对 21.17.3.1 的客户端原生攻击判定中，让已激活且禁止破坏的生命体使用攻击动画，保留普通地形、允许破坏和原版模式的规则，也使用原生第三人称准星位置。

近战模块原先只有物理伤害类型，没有来源位置和攻击实体。原生防御先检查正面位置，又要求攻击实体非空，所以无法格挡。现在近战提供标记主体的世界位置和原有生命体名称。只为该明确来源接入原生 Guard/Parrying/ImpactGuard 的体力、惩罚、技能动作与招架窗口，原生监听器仍决定持握、防御状态及前后方向；不生成代理攻击者、不重复发布受伤事件。没有实体的攻击者不提供附魔击退，格挡火花使用位置粒子；ImpactGuard 需要攻击实体的额外气爆视觉省略，物理伤害的格挡判定保留。

被格挡的接触消耗一次模块攻击间隔，避免连续触碰每 tick 扣体力；不施加伤害、模块击退或状态效果，也不计入成功命中次数。未防御、后方、普通生物及其他模块保持原伤害链，Arrow/Gun 不改。本轮只承诺已核对版本和技能，第三方防御技能及其他 Epic Fight 版本需要单独验证。

斩击模块的 flightSound 存档字段和播放行为不改，仅面板、手册及说明改名为“释放音效”。其他使用飞行音效的模块不改。

Boss 血条开关右边增加原版七色选择，左键下一种、右键上一种；旧配置默认红色。服务器验证权限、整数及范围，颜色保存/加载、复制与即时血条更新受测，不改变生命值。原版 BossEvent 不提供任意 RGB，因此此次为七色选择。

用户确认大型结构清除中退出再进入会继续清理；这项已记入死亡/区块加载手册。清除算法、残影和奖励路径未改。CBC 附属炮膛仍按之前要求暂不适配。

## 验证和边界

57 项单元测试、282 项无 Epic Fight 完整 GameTest、81 项真实 Epic Fight/Copycats/工具枪/TaCZ/CBC/近战/核心组合回归通过；包含重复覆盖，不能相加为独立用例数量。真实原生普通防御、招架、冲击防御、体力消耗、招架窗口、后方及松开防御；可受伤玩家完整 hurt 链；实际近战模块被挡后遵守 Interval；Boss 七色、非法数值、权限、存档/复制与已创建血条即时更新受测。

真实 Epic 客户端加载 LocalPlayerPatch 工具判定 Mixin，并完成核心界面 GUI 2/3 缩放和血条颜色布局检查。原场景长按工具的动作观感和防御反馈仍需要用户手动观察，不能把客户端启动检查当作已手动实测。

早期实际伤害测试使用的 NeoForge FakePlayer 默认永远无敌，已换成明确可受伤的测试演员。完整套件中的旧地震波测试依赖共享玩家权限，其他测试会留下生存状态；改为独立创造演员并保持原伤害断言后完整通过。地震波生产逻辑未改；失败日志保留。日志：verify200-default-verified.log、verify200-compat1.log、verify200-client.log。手册修订 53、45 章/32 模块和双语言占位符检查通过。

Minecraft 1.21.1，最低 NeoForge 21.1.235，Create 6.0.10 / Sable 2.0.5，协议 6。两端使用同版。备份脚本补入可选 Epic Fight 与清理测试的依赖，确保恢复源码后可重新验证。

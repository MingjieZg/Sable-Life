# 0.1.94 悬浮追踪弹

## 使用

添加红色武器分类的「悬浮追踪弹」，标记发射点及表面方向。可通过 Preview 查看展开位置。

- 数量默认 1，范围 1–32，滚轮 ±1。1 发位于前方中间；5 发在设定角度的扇形弧线上展开，中央第 3 发与单发位置相同。
- 默认向标记方向前方 3 格、再向世界上方偏移 2 格；可设置方向、前方距离 0.5–32、高度 -16–32、扇形角度 0–180°。生成后位置冻结，生物移动不会拖着悬浮阵列一起移动。
- 默认蓄力 2 秒，最长蓄力 60 秒。默认速度 0.3 格/刻，范围 0.05–2；最大飞行时间默认 10 秒，最长 60 秒。
- 单目标时本轮弹丸锁定最近有效目标；多目标时轮流分配给范围内的目标，目标在蓄力结束时确定。锁定后不切换；目标死亡、变创造／旁观或离开原侦测范围则消失。
- 采用类似潜影贝的轴向分段转向并平滑加速，近距离转为向目标中心追踪。检测转向邻格障碍；实际撞墙仍会命中并消失，不穿墙。
- 默认模型为潜影壳，物品槽支持自定义完整物品／武器模型。大小与 hitbox 共用直径 0.05–2 格，与 gun／mortar 一致。
- 粒子使用双栏选择，每种粒子可调时长与大小；未选时显示末地烛粒子。悬停期间也显示粒子，飞行时形成拖尾。
- 蓄力、发射、命中音效均支持 MC／OGG、None、音量和播放半径。发射音效每批播放一次，命中音效每次命中播放。
- 默认伤害 6，可设置多种命中药水效果。通过普通伤害路径接受护甲减伤，保留自身生命体攻击免伤。
- 与其他攻击模块使用同一套 Trigger。已生成的一批可在短脉冲后执行完成，停用／删除／关闭总开关／解除生命化／死亡清理弹丸。场上同模块一批尚未结束时不会重复生成下一批。
- 模块配置持久保存；在途实体的 NBT 包含悬停进度、追踪对象、配置快照、外观、粒子和效果。模块编辑不会改变已生成弹丸。核心卸载会清理当前批次，重新加载后按触发条件生成新批次。

## 验证

构建与单元测试通过，34 项相关 GameTest 通过，新增检查扇形位置与数量限制、短脉冲下蓄力及多目标分配、命中伤害与药水效果、悬停重载及无目标清理。实际追踪手感、模型和声音待人工检查。

3. 物品／武器自定义外观、hitbox 擦边，粒子时长／大小，三种音效及半径。
4. 护甲减伤与多药水、自身免伤；短脉冲触发；停用、删除、总开关、解除与死亡清理。

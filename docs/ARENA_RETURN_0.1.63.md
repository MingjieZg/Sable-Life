# 0.1.63 场地回位规则

替代 0.1.62 的处罚完成回中心规则：

- 边界警告及倒数文字统一为红色。
- 回位开关改名为“附近无人存活时回位”，沿用 `arenaReturn` 存档键及默认关闭；原来已开启的开关保持开启。
- Boss 出界且模块激活时，只检查以 Boss 为中心的 Nearby player range，忽略 Y 轴。警告与回位共用这个范围，不再额外包含整个场地内玩家。
- 当范围内没有存活的非创造/旁观玩家时回位，包括一开始无人、玩家离开范围、死亡或断线。只要仍有合格存活玩家就继续倒数，不回位。
- 回位目的地仍是标记的固定场地中心 X/Z，保留当前高度、朝向及整个机构的部件相对位置，并清零速度。
- 未出界、模块关闭或核心休眠时不执行回位。

编译验证：`scripts/dev.ps1 -Task assemble`。未启动或重启客户端。

待游戏检查：红色倒数；单人死亡后回位；出界时无人直接回位；多人时最后一个死亡/离开才回位；关闭开关不回位。

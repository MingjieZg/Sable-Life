# 从 0.1.320 到当前的更新清单

## 待发布

### 生存生命核心的液体燃料

- 「补充能源」右侧有与容器槽对齐的窄型储槽，容量为 40,000 mB，一次存放一种已注册的液体。储槽每 5,000 mB 有一道刻度，每逢 10,000 mB 加长。将装有液体的容器放入带岩浆桶图标的输入槽，从输出槽取回处理后的容器。也可拿着装有液体的容器右键点击储槽注入。储槽中至少有 1,000 mB 可装桶的液体时，拿着空桶左键点击储槽可取出一桶。悬浮提示将右键和左键操作分行显示。储槽下方的小清空图标与容器槽边框对齐，点击后显示确认勾。储槽状态未变时，再点一次即可清空。
- NeoForge 流体管道接口只接受液体注入。储槽内容随核心保存在世界中，从蓝图放置的核心以空储槽开始。
- 服务端在 `survivalTokens.fluidDepositValues` 中按流体 ID 或带 `#` 的标签设置每 1,000 mB 的能量价格。默认 `minecraft:lava=250`，一桶熔岩可兑换 250 能量。手动补充能源按当前可兑换的液体量报价，点击两次确认后结算，支持不足一桶的用量。
- 自动补充能源每 8 tick 可兑换一整桶已定价的液体，也会处理固体燃料。不足一桶的余量和未定价的液体留在储槽中。登记为第 136 项。

### 目标对准的侦测内半径

- 「侦测内半径」可设为 0–31 格，须小于「半径」。默认 0，表示无最小距离。从标记方块量起，距离小于内半径的目标会被排除，包括自行索敌、关联的目标感应和自定义动作抽选提供的目标。预览显示外球，内半径大于 0 时也显示内球。指挥棒指定目标或目的地时仍可跳过距离限制，继续遵循模块的触发和视线设置。登记为第 137 项，手册修订 265。

## 0.1.458

- **首次放置的蓝图阵营**。待绑定入口显示原阵营名。没有可用的本地阵营时，打开蓝图阵营会先显示已填好原阵营设置的创建页，可确认创建并绑定，也可跳过。手册修订 264。

- **无线红石断电渐降**。渐变模式新增「断电渐降时长」。触发结束时，输出从当前信号强度逐渐降到 0。回落途中再次触发时，输出从当时的强度向结束值继续渐变。全新触发从设置的起始强度开始。默认 0 秒，沿用原有的输出缓冲规则。设为正值时，渐变模式暂停使用缓冲，保存的缓冲数值仍保留。登记为第 135 项，手册修订 263。

## 0.1.457

- **蜂巢护盾**。平面六边形从标记面中心向外逐格显现，形成近圆形的蜂巢。护盾在触发期间保持，触发结束后从外向内收拢。增大尺寸会增加格子数量。常用尺寸下，六边形边长为 0.5 格。尺寸超过 3 时，格子逐渐变大，组成护盾的六边形保持完整。可设置颜色，并选择跟随标记部件或保留释放位置。图案动画速度同时调节展开和收起。预览时长仅用于手动预览。登记为第 134 项，手册修订 262。

- 数据复制器支持复制和粘贴含多层嵌套建模物品的核心配置，例如 Yuushya Modelling 的组合模型。

- 数据复制器的压缩配置上限从 100 万字节提高到 200 万字节，为物品显示等模块存储较大的物品数据。物品悬浮说明显示已用容量和上限，空载时显示为 0。复制失败提示也会显示上限。

- 第三方兼容补丁按最低版本和实际接口检查启用。LittleTiles、武器附属、Walker、领地和 Toolgun 可继续使用符合要求的新版。Epic Fight 和铁魔法进一步核对原生类代码，铁魔法 3.16.4 已加入适配。

## 最终行为与重要调整

### 核心、阵营与能源

- 三类核心分别为 Heart Core、Redstone Core、Survival Heart Core；未发布的生存核心物品 ID 已统一为 `sablelife:survival_heart_core`，按要求不保留旧物品迁移别名。
- 普通核心生存编辑总开关为 `allowEditHeartCoreUnderSurvivalMode`，默认 false；生存生命核心独立开放，不依赖此开关。
- 模块配置统一为 `[modules.heartCore]`、`[modules.redstoneCore]`、`[modules.survivalHeartCore]`。配置注释分组留空行，模块开关列表紧凑排列。
- 玩家白名单只排除自动目标，不提供通用流弹免疫。Owner 和阵营关系不授予编辑、挖掘或交互权限。
- 公开／私人状态、创建者及已加入状态在阵营列表中显示。玩家默认可创建 1 个阵营，管理员豁免；可加入多个阵营，每个生命体只加入一个。结盟须双向接受，不传递。
- Token／Top Up 的界面用词统一为 Energy／Refuel（能量／补充能源）；部分内部配置和存档键保留 Token 命名。
- 生存核心合成采用红石核心配方，中央紫水晶换成红石粉。生存解除工具由剪刀和红石粉无序合成。
- 生存核心隐藏经验、Loot、动态免伤、普通死亡延迟与移除、虚空高度、断肢清理和强制区块加载等不适用设置。生存交互固定开启，来自其他生命体的伤害入口固定开启，但阵营伤害规则仍有效。
- 生命归零播放生命清空特效并解除生命化，保留结构；手动解除保留剩余生命与能量。挖掘核心物品可携带一次性能源凭证，尚不等于完整配置与生命随物品搬运。
- 补充能源修复 Shift 移动物品后无法手动放入、价值悬停缺失和物品余额显示；材料值与实际结算共用服务器配置。铜也统一进入 `depositValues`，旧配置迁移保留自定义设置。
- 充值目录、当前价值与二次确认使用本模组界面样式；顶部余额、预计费用、生命费用有对应颜色和公式提示。

### 攻击计费与生存限制

- 按服务器费率结算，报价与实际扣费共用公式；近战按成功造成伤害的命中，箭矢按成功发射数量，召唤武装结算部署和后续攻击。
- 修正追踪弹伤害／飞行范围费用、Gun 射程、Slash／地震波等速度费用；更快、更远、多发、更多落点会影响相应报价。
- 附带命中爆炸纳入半径 × 伤害；球爆、落地打击、冲击波统一使用半径尺度，避免某些用球体体积、某些用半径造成异常价差。
- Ground Strike 包含延伸段、射线或随机落点，实际按有效安排的落点结算；冲击波包含击退，冻结包含水平范围、高度和持续时间。
- 命中生成的持续伤害区域另计，续时只支付增加的持续时间。无能量不新增付费攻击；已支付并发出的攻击可按原生命周期完成。
- 部位免伤最高 90%，默认每减伤 1 个百分点每秒消耗 1 Energy：50% 为 50/s、90% 为 90/s；不需要受到攻击才扣费。外部总触发有效不代表内部阶段规则已匹配，内部频道条件不成立时既无免伤也不收费。
- 生存生命核心的箭矢、枪、迫击炮和斩击可从发射口瞄准单个或多个目标。保存、导入与激活会保留瞄准设置。球爆、牵引、冻结、冲击波、地震波和落地打击的目标点位释放仍受生存限制。

### 红石核心与移动

- 红石核心开放 17 种受支持能力的默认开关，已有管理员设置保留；不变成无血量的完整战斗核心。
- 红石 Move set 固定忽略目标／血量等条件；优先级、权重、冷却、招式时长、休息和重复仍有效。生命核心可自行勾选忽略条件，并灰化被跳过的条件。
- 安全直线移动支持 Travel、重力和跨步；红石核心不提供瞬移／强制破障等不适用模式。
- 直线移动预览恢复按实际方块外形描线，通畅为绿、阻挡为红，扫描和绘制有上限；大型未完成预览可暂用整体框。
- 移动间隔、蓄力、停止距离、移动距离滚轮按指定整数步长；目标搜索 ±8；新模块触发默认内部无线，跨步冷却默认 0.3 秒。
- Interval 最低可设 0 秒，默认仍为 5 秒；0 不增加冷却，仍按游戏 tick 和动作占用顺序执行，不在同 tick 无限循环。
- Target alignment 六方向使用粗实线，正面黄色增加箭头。
- 修复远处其他 Sable 结构的空包围框误挡旋转／移动：候选框相交后检查附近实际碰撞形状。真实障碍和预算约束保留，自身结构的保守包围框未改成逐块精确碰撞。
- 陀螺仪倾角阈值与扶正速度在 Fully level 也有用途，因此保留显示并修正说明。

- 工作台保护默认水平 64 格，以整张蓝图占地边缘判断，覆盖所有高度；试生成和清障同样遵守。只识别固定世界的原版工作台，Sable 结构内的工作台不携带保护区。

# Iron’s Spells 第一批伤害接口：0.1.202 开发版

稳定记录仍 0.1.200。修改前源码检查点为 backups/source-before-0.1.202.zip。此次实现基础伤害接入，不宣称完整兼容全部铁魔法。

## 第一批支持

已核对 Minecraft1.21.1 / Iron’s Spells 1.21.1-3.16.3；专用 Mixin 仅在此版本启用。魔法飞弹、魔法箭、小火球的真实 BLOCK 命中转交生命核心；火球及火焰箭的范围伤害按原半径、伤害与平方距离衰减执行；Shockwave 原生 onCast 按原等级和施法者法强计算一次范围伤害。

魔法箭保留原生穿透移动，并按生命体 UUID 去重，免伤的第一次接触也消耗该箭的命中窗口。大型生命体不会因为组成多个方块重复扣血。魔法飞弹、小火球的原生消失、普通生物伤害与前方地形/实体命中优先级保留。

Sable 的原生 Clip 返回真实存储方块位置，但命中点可能仍是 plot 坐标。桥接在 Iron 基类截断实体射线之前，以及 impact 回调入口，将点转换到世界空间，保留 BlockPos。解决命中特效跑到存储区及漏掉前方普通目标的问题。

火焰箭对命中生命体施加完整直接伤害，该生命体从半强度旁侧爆炸中排除；其他生命体按半强度及距离衰减。火球按完整强度及衰减。两者构造的附带地形 Explosion 用对象身份标记为 terrain-only，仅禁止通用桥再给核心施加 TNT 公式伤害；不使用覆盖整个调用栈的全局取消，因此无关爆炸仍正常，也不改变原模组普通实体/地形处理。核心现有爆炸破坏保护继续生效。

## 共用接口及附属范围

新增实验性 BodyCombatApi.projectile、BodyCombatApi.sphere 和 BodySphereQuery，说明和最小示例见 COMPATIBILITY_API.md。查询使用已加载核心空间索引、归属体素和实际碰撞形状，不创建代理实体，不把空包围盒当目标。范围查询支持最近碰撞点、遮挡、最多64生命体/每候选32768体素、共享世界碰撞预算、半径256上限和已加载视线路径。预算耗尽或缺失区域失败关闭，极端负载可能漏掉本次攻击；未作真实多人压力测试。

保持已支持直接弹体父类与命中规则的附属子类可以共用；未知 AbstractMagicProjectile 类型不自动当伤害弹，因为其中还有控制、视觉、爆炸及周期范围类型。新直接弹可显式登记其具体类型与伤害函数，或者在自己的服务端真实命中点调用通用 API；已通过自定义子类/显式登记的真实测试。抽象全类型登记禁止，注册表最多128类。

所有伤害继续经过核心 damageAt、部位修正、自适应减伤、受伤触发和死亡清除；红石核心不获得血量。原生 LivingEntity 的 SpellDamageEvent、学派抗性、冻结/减速/点燃状态、吸血、击飞及击杀技能等不会由此自动完整模拟。附带原生地形火焰仍属于原法术环境行为。

## 验证

57单元测试、290无铁魔法默认完整GameTest通过，确认可选API不存在时能启动。44真实铁魔法/审计/防御回归通过；103项铁魔法/Epic Fight/枪炮/Copycats/工具枪/核心/Arena组合通过，均存在重复覆盖，不能相加。12个原生Iron用例涵盖普通三类弹体、原类继承的附属、未知类型不误伤及显式登记、前方普通生物与墙阻挡、世界坐标特效、魔法箭穿透/重复及免伤窗口、多生命体衰减、火焰箭直接/旁侧伤害、破坏配置开关与TNT去重、原生Shockwave含法强倍率。

另有真实球体空洞/包围盒角落/半砖空隙、部位护甲、早先墙遮挡、异常参数与按爆炸对象隔离的检查。实际原生回调不是仅直接调用桥接函数。初次运行缺少新namespace模板已补齐；之后扩展测试暴露plot坐标和普通实体排序问题，修复后通过，失败日志保留。

带真实铁魔法与Epic的隔离客户端启动及核心界面检查通过；没有操作用户游戏实例。原机械、完整法术演出及各种附属仍需用户实际测试。日志：verify202-default.log、verify202-irons-final.log、verify202-all-compat.log、verify202-client.log。手册修订55、45章/32模块与双语言占位符通过。

## 依赖和运行

scripts/setup-iron-spells.ps1 可恢复官方校验固定的 Iron 3.16.3、GeckoLib4.9.2、PlayerAnimator2.0.4、Curios9.5.1、Iron’s Lib2.2.0。均为可选开发依赖，不打入本MOD JAR。测试用 -PironSpellTests=true，常规开发客户端/服务器可用 -PironSpellRuntime=true；实际游戏包已安装铁魔法及其依赖时直接更换Sable Life JAR即可。协议仍7，两端使用同版本。

后续顺序：周期雷球/纯伤害法阵 → 吐息、地面波、射线 → 独立生命体锁定路径。实体状态效果与其他附属独立伤害路径另外验证，未在第一批混入。

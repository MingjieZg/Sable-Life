# 0.1.244 空间冲击波开发版

2026-10-15。稳定版仍为0.1.243；原游戏实例、用户世界和既有稳定备份未修改，没有上传此开发版。

新增 Visual shockwave / 空间冲击波。Mark结构方块作为发射点，信号激活/Move Set动作窗口发出一次波纹；也可选择持续期间按间隔重复。Preview给编辑者本人播放一次。

默认半径18方块、扩散0.45秒、波宽1.5、扭曲0.35、局部模糊0.25、震屏0.15持续0.4秒、拉近4%并在0.5秒内恢复，范围64方块。强度0关闭对应效果，缩放负值拉远。客户端“失真效果”强度缩放全部效果，0关闭。

单次网络事件记录出生世界坐标，客户端每帧从当前相机重新投影；源在身后时不绘制波纹，但范围内仍可震屏/缩放，距离衰减。扩散圆环重采样世界颜色纹理，并仅在环内模糊；不作全屏模糊，不绘制实体，不改变玩家实际朝向或结构大小/碰撞。使用AFTER_LEVEL、手和HUD之前的渲染阶段，HUD保持清晰。

客户端最多保留8事件、同时绘制最近4个可见圆环；相机叠加有上限。固定一张可复用颜色副本，退出世界清理；绘制后恢复framebuffer、深度写入/测试、混合、裁剪、背面剔除和viewport。Shader加载/运行异常时关闭扭曲，保留其他渲染。第三方shader/HDR/额外framebuffer未验收，目标不是主framebuffer时跳过波纹。波纹是屏幕空间投影圆环，不包含球形深度遮挡，墙体不会遮蔽该效果。

验证：94控制专项、358默认原生GameTests通过，覆盖近远玩家、实际世界出生点、单次/重复/重新激活、Move Set每窗口、预览、关闭主开关、保存/预设、codec和异常参数、投影及相机恢复曲线。真实GPU测试5245个环内像素变化、环外0变化，背后/禁用/过期无变化，状态恢复和resize通过。

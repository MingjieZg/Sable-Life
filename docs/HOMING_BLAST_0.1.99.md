# 0.1.99 悬浮追踪弹爆炸

- 与 Arrow launcher 共用 Impact explosion、Blast damage、Blast radius、Destroy blocks。
- 默认爆炸关闭；爆炸伤害默认 20（0–1000）、半径默认 4（0.5–16）、破坏方块默认关闭。
- 本体 Damage 为直接命中伤害，Blast damage 是额外范围伤害；直接命中目标可以同时受到两部分伤害。范围内其他生物也受到爆炸伤害。
- 爆炸音效支持 MC／OGG／None，默认 generic.explode；独立音量 0–4、半径 1–256，默认 1／32。原命中音效仍独立存在。
- 击中生物或方块触发；展开／蓄力、到时消失、失去目标或停用不触发爆炸。
- 已发射弹丸冻结配置，保存重载保持爆炸配置；自身免伤、其他生命体伤害开关和护甲规则继续生效。

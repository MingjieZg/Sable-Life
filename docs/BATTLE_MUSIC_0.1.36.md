# 0.1.36：战斗 BGM

在 Heart 的 Sound 虚拟模块末尾新增 Combat BGM、BGM range、Fade-out (s)、BGM volume。默认曲目 None，不改变旧存档声音行为；默认范围 64 格、淡出 3 秒、音量 1。沿用声音模块的标记点、启用开关与触发方式。

- 生命周期 ALIVE 的核心首次受到有效伤害后开始播放；后续每次有效伤害都重新从曲目开头播放，不应用普通受伤音效冷却。
- 范围内音量不随距离衰减；离开范围后按设置时间逐渐降为零。
- 曾被攻击的生命体仍在战斗状态时，玩家重新进入范围从开头播放。重播也适用于第一次进入已经被攻击过的生命体范围的玩家。
- 死亡、解除生命化、模块停止触发、标记失效或结构卸载时停止会话并淡出；退出服务器或切换维度直接清理客户端播放，避免残留音乐。客户端以周期确认兜底清理丢失的会话。
- 范围内再次攻击或淡出期间重新入场，会停止旧音轨并从头开始。音轨循环；多个战斗音乐模块同时覆盖时只播放最近进入或受伤重播的一首，防止叠音。
- 播放期间让原版随机背景音乐避让。BGM 遵循 Minecraft 的 Music 音量滑块；普通受伤/靠近/脚步音效仍独立播放。
- 曲目库包含自定义 .ogg、末影龙音乐、Pigstep、Otherside；自定义文件放入测试实例 runs/client/config/sablelife/sounds，重启客户端后可选择。多人游戏各客户端需要相同自定义资源。
- 战斗开始状态随核心存档，解除或重新粘贴配置时清零。数据复制器会复制 BGM 属性，不复制已进入战斗的运行状态。

验证：仅 assemble 编译与打包，未运行功能测试。验收：首次攻击起播、再次攻击重播、离圈淡出、返圈重播、死亡/解除清理，及音乐滑块。

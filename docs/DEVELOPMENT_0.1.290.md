# 0.1.290 冻结范围扩展与抓取/束缚（2026-10-29）

## 范围冻结

冻结支持圆形（圆柱）和长方形（竖直旋转盒）。圆形半径0.5–32格，长方形长/宽0.5–64格，两者高度0.5–64格。长方形可设水平角度±180和居中/向前铺设。范围保持竖直；Mark模式以所选标记方向的水平投影定向，竖直方向回退世界南向；On target以世界南向加角度定向。

Mark point新增方向和起始距离0–128格。起点在标记方块面外0.55格，再沿方向偏移；On target隐藏这两个设置，仍锁定最近有效玩家释放时的位置。预警范围的中心、朝向、尺寸在开始时快照，后续不会跟着目标或部件追踪。

ControlVolume统一实际圆柱/OBB相交判定及预览边界。包括高度、长宽、角度和向前布局；不按扩大包围盒替代旋转盒。预览始终用淡蓝色标线画上下边界及侧边，无需选择任何预警粒子。正常运行预警使用自选粒子，清空后只关闭预警视觉。原Mark/On target、时间、声音、Move set及多来源释放规则保留。

圆形从上版球形变为圆柱，以满足与持续范围伤害一致的圆形/长方形设置；增加高度独立控制垂直范围。默认高度16格，默认半径仍8格。没有自动改写已保存的其他参数。

## 抓取/束缚（grab）

独立攻击分类模块，支持Move set和原有触发方式；只需一个所选独立part上的Mark。预警及捕获球跟随当前Mark移动，结束时尝试捕获最近的一名存活生存/冒险玩家，已被其他抓取占用的玩家跳过。创造/旁观/死亡玩家和生物不受影响。

设置：捕获半径0.25–8格，预警0–60秒，保持0.05–60秒，间隔0.05–600秒。间隔从预警+保持后计算。默认半径1.5格、预警0.25秒、保持3秒、间隔5秒。Mark面外0.55格加起始距离0–16格（默认1.5）；另有部件局部左右/高度偏移±16格。默认crit预警，可换粒子及声音组合。

保持点是玩家身体中心；玩家脚底按当前人物高度减半换算。中心随标记方块所在部件的平移/旋转变换，人物保持直立，视角不强制旋转。继续允许攻击和举盾；走路、跳跃、击退不能脱离。不会额外造成伤害或投掷。保持时长/断信号/模块删除、停用/Mark失效或断开、核心卸载/死亡、玩家死亡/退出/换维度时释放。预览橙色捕获球+绿色直立人物位置盒。

PlayerFreeze复用独立来源租约，增加每刻更新的跟随目标。已抓住的玩家不会被第二个抓取抢走；其他范围冻结仍独立计时。抓取释放后若还有冻结，停在释放处，不弹回最初位置。

沿每个移动段按约0.25格间距检查完整玩家体积和已加载区块、世界边界。路径被地形挡住时释放在最后位置，避免穿墙；单刻目标跳变超过8格同样释放。不加载新地形、不改变方块、不把玩家设置为无碰撞。释放后不额外赋予速度。每玩家最多64个硬控来源、每服务端最多256名受控玩家；跟随位置有界且按游戏刻缓存，不按每个网络包重复扫描。

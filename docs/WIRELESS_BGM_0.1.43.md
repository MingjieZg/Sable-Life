# 0.1.43-dev

- 无线序列器底部增加 Delete 按钮。删除当前频道先清理 Create 网络运行状态；后续频道及其模块引用同步前移。被删频道的引用保存为 -1（界面显示 0，未绑定），不会被新添加或前移的频道误触发。重新填写频道号即可绑定。删除最后一行后返回空列表；新加频道仍正常使用。
- 无线时间、信号强度输入框支持悬停滚轮即时修改：时间 0.1 秒，强度 1。上下限继续在客户端与服务器校验，RX 模式及不可编辑状态下不生效。
- Combat BGM 第二页增加 BGM start mode。默认 After first hit 保留现有配置行为；On entering range 在生命化激活、模块触发条件满足时，玩家进入 BGM 范围立即播放。两种方式均保留离开范围渐弱、重新进入重新开始、攻击反馈与 BGM 重叠、死亡或解除停止的行为。

验证：assemble 编译打包通过；尚未在世界内自动操作删除、滚轮和 BGM 开始条件。

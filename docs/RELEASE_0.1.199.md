# 0.1.199 命中充能、工具攻击与死亡特效

开发验证版，稳定记录仍为 0.1.193。修改前 0.1.198 源码检查点：backups/source-before-0.1.199.zip；上一版导出保留。

## 原因与改动

- Epic Fight 桥接已经处理实际动画命中，但未执行命中后武器资源累计。现在对成功扣血的主手命中，按实际健康损失调用原生技能消费/同步 API；复现 21.17.3.1 ServerPlayerPatch 的 DELIVER_DAMAGE_POST 充能条件：攻击允许充能、武器技能匹配、未满且未激活。同段去重保留；减伤减少充能、免伤不充能，致死一击按剩余生命计入，不累计溢出的伤害。
- 不发布携带 null/假生物目标的命中事件，也不生成代理实体。通用事件需要真实 LivingEntity，不能直接假定其他技能监听器支持身体方块。该技术可作为未来逐个适配的边界，但不是通用兼容承诺。目标依赖伤害、副手及附加模组实体技能仍需验证。
- 原先工具在找到生命核心前就跳过攻击处理。现在仅在允许破坏开启时保留工具挖掘；关闭时走正常攻击，服务器保留权限、距离、遮挡与攻击频率验证，Epic 战斗模式仍由原动画负责伤害。客户端同步一个 AllowBreaking 布尔值，禁止持续挖掘裂纹/粒子，初始点击和挥动保留。普通地形不受影响，创造模式核心的原作者删除规则保留。
- 死亡瞬间特效使用连接结构世界空间包围盒中心，包括连接部位；效果半径默认 0 自动取外接球半径（最多 256 格），正数使用指定值，滚轮 ±1。与声音半径独立，存档、复制、恢复默认、菜单快照和预览均保留此值。爆发/云状从球面散布，其他形状保留所选模式；闪光保留为一次中心闪光。
- 延迟结束后的逐方块残影、分批清除与奖励位置保持。CBC 附属炮膛按用户要求暂不修改。

## 验证

57 项单元测试、281 项无 Epic Fight 的完整 GameTest 通过。71 项真实 Epic Fight/Copycats/工具枪/TaCZ/CBC 组合测试通过，与默认回归有重复，不能相加。新增检查涵盖真实剑/斧/三叉戟动画充能、原生 post-hit 事件对照、阶段去重、已满/已激活/非充能攻击、武器不匹配、减伤与免伤；保护工具攻击与允许挖掘开关、客户端状态读写；偏置核心的整身中心/外接球、半径验证与存档/恢复。

隔离客户端确认 Mixin 可加载，核心死亡页在 GUI 缩放 2/3 显示第三个半径输入框且不与恢复/预览重叠。手册修订 52、45 章/32 模块、双语言与占位符一致性检查通过。原场景长按工具的观感、武器 HUD 更新和大型结构外围粒子的视觉效果仍待用户复测。未操作用户的客户端实例或世界。

早期组合失败日志保留：普通战斗用例放入 Epic 默认战斗模式会有预期路径冲突；重跑旧隔离世界会残留先前的测试结构。最终使用全新隔离世界。透明核心测试切换 ACTIVE 保留上轮伪装，已在每轮显式清空测试伪装；生产渲染代码未更改。日志：verify199-default.log、verify199-compat-final.log、verify199-client.log。

Minecraft 1.21.1 / NeoForge 最低 21.1.235，协议 6。建议客户端与服务器使用同一版本，仍不是新稳定版。

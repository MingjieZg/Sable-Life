# 0.1.302 累计／限时伤害检测（2026-10-30）

现有累计伤害触发模块新增“伤害检测模式”：累计伤害保留原阈值行为；限时伤害显示检测时长、要求伤害及单次/循环。默认5秒、200实际扣血、单次；时长0.05–600秒，要求1–1,000,000。保留各模式隐藏配置，切换模式重置运行进度，旧配置默认累计模式。

两个模式共用内部频道、外部Create红蓝物品频率、信号强度、脉冲时长、反转及重置。内外可以同时输出，也可仅输出外部。限时模式开启且存在有效输出时开始完整检测窗口，直到到期才比较实际受到的HP损失；不会提前判定。反转关闭为未达标输出，开启为达标输出，恰好达到要求算达标。累计模式原有反转空闲高/阈值短暂断开行为保留。

单次模式在触发持续有效期间只检测一次，重新触发或重置后开始下一轮。循环模式结算后立即开始下一窗口；边界时刻伤害计入新窗口。触发提前关闭、模块禁用、无线总开关关闭或输出失效取消窗口并清零，不输出失败。模式或限时条件变更重新计时。脉冲长度不短于窗口时，连续匹配可能合并为持续高信号。预设保留配置/频率，不保留临时计数。检测的是实际总扣血：40 DPS、5秒可填200要求伤害。

# 0.1.204 铁魔法接触伤害实验版

稳定版仍为 0.1.200。Minecraft 1.21.1，最低 NeoForge 21.1.235，网络协议仍为 7。可选铁魔法精确版本 1.21.1-3.16.3；没有实体代理。

## 用户新材质

生命核心红菱形与红石核心紫菱形直接替换为用户本次提供的 32×32 RGBA PNG，保留原图颜色与透明通道。六面模型和伪装渲染均继续引用同一菱形资源；外壳模型保持原样。源文件 SHA256：红 9df14ff8db082b81948318cccd0ac53a9fa33783e93b2fce0d3e588c2c9a04ae，紫 d12ed1c1cba13177f7f2dbd35b242afee53dc7aed1e4b75b0e8c6f9cd78a511c。

## 已实现

- 移动伤害弹体命中生命体后一次扣血并清除：魔法飞弹、魔法箭、小火球、Firebolt（铁魔法中文“火焰箭”）、冰锥、雷鸣长枪。穿透弹命中生命体后也停止；普通生物仍保留原生穿透规则。
- 猩红斩击（飞血刃）：独立检测当前原生弹体碰撞箱与实际身体体素；不是仅用整结构外包围盒，也不是每个方块累计。碰到生命体后一次扣血并消失；原生 15% 吸血按实际扣除的生命值计算。块射线先命中身体时也能转接。
- 火球与 Fire arrow：保留已实现的原生爆炸、范围衰减、特效和直接/范围去重，再由原生逻辑清除；不会额外计算 TNT 伤害。
- 火焰吐息、刺骨寒风、毒雾喷射：复用 AbstractConeProjectile 的多个原生攻击部件包围盒，仅在原生 dealDamageActive 打开的窗口查询身体。一次窗口内多个部件/方块触及同一生命体只结算一次，不额外添加每 tick 伤害。地形 LOS 阻挡；原法术仍控制打开下一窗口。
- 血吸光束（Ray of Siphoning）：在原生 onCast 的射线结果处接入实际身体扣血，沿用原生伤害数值与施法脉冲。更近的生物、墙壁仍优先；重复同 tick/同生命体回调被过滤，下一原生施法窗口可再次扣血。按实际生命损失 100% 回血，免疫不回血。
- FireBreath 原生点火射线也转换 Sable 世界坐标，避免给不检查方块的盾牌查询传入远处 plot 终点；保留存储 BlockPos 身份。

## 身体几何与状态

BodySphereQuery.queryVolumes 将最多 16 个 AttackVolume 做候选查询，对已归属、未脱离、存活的真实碰撞体素逐一做 SAT 相交。复用逻辑 pose 的三条世界轴，支持旋转/缩放；不把空洞、台阶上方空气或包围盒空角视为命中。最终仍经过 core.damageAt、部位修正、自适应减伤和死亡清理。

沿用共享 CollisionWorkBudget、每候选 32,768 体素访问、最多 64 命中、有界攻击尺寸及已加载区块 LOS 检查。预算耗尽可漏掉命中，不能无限扫描或强制加载区块。持续回调使用服务端弱源引用和最多 64 个同 tick 目标记录；不保存代理实体、目标对象或永久每 tick 网络广播。

BodyCombatApi.contact 是实验性服务端接口，返回实际扣除血量，一次调用代表一个攻击窗口；调用方必须保持原生形状、时间窗口和权限，不接受客户端伪造命中。不清空普通投射物的一生去重缓存来模拟持续伤害。

## 适配边界

这统一的是已核对路径的身体结算规则，不是给所有 Entity.getDamage 自动猜测语义。未知投射物家族、锁定/连锁、雷球、持续云、地面波还需要接口。原生命中逻辑保持一致的附属继承可以复用支持家族；自定义 tick/范围/伤害公式需单独确认。

身体没有 LivingEntity 药水/燃烧/冻结属性；吐息的毒、火、冰附加状态及 LivingEntity-only 事件没有虚构模拟。此次只转接伤害和明确可表示的实际损血吸血，不承诺原生学校抗性、技能事件或所有附属自动工作。

## 验证与回测

- 65 项含真实铁魔法、Arena、审计、防御的组合 GameTest；最终新增吸血检查后 26 项真实铁魔法再次通过。
- 290 项无铁魔法的完整默认 GameTest。
- 57 项单元测试及最终构建；手册 revision 56，45 章、32 模块、双语与四分页校验。
- 验证直接弹体消失、穿透弹消失、完全免疫接触、猩红斩击边缘命中/空洞拒绝/15% 吸血、三种吐息窗口及墙壁、吸血光束部位减伤实际回血/免疫零回血/下一窗口。

首轮的两个失败属于测试夹具：删除身体中间方块触发结构拆分，空洞改用预先装配的稀疏结构；核心物理运动离开第二次光束瞄准点，第二次测试按当前位置瞄准。没有用放宽伤害断言绕过这些失败。

用户原 Create Aeronautic 2 整合包中的吸血光束崩溃尚需回测；没有新的对应崩溃栈，不能仅凭自动测试断言已经解决所有整合包冲突。原世界没有启动或改动；开发测试采用独立目录。

建议回测：猩红斩击/魔法箭/冰锥命中即消失；三种吐息持续施法时按窗口掉血、停止后停伤；血吸光束应伤害身体并按实际伤害回血，墙壁应阻挡；检查原大型结构与实际整合包是否仍有崩溃。

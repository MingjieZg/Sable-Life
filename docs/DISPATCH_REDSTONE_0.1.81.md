# 招式调度与标记点红石（0.1.81）

## 招式调度

每个招式调度模块代表一个候选招式，可以重命名为「喷火」「落雷」等。多个调度模块共享一个选招池，同一时间只启动一个招式。

满足血量区间、目标类型、距离、前方角度与视线条件，且冷却结束后，按权重随机选招。可设置避免连续重复；只有一个可用招式时允许再次选它。

调度输出的是内部启动脉冲。输出频道必须启用、放入频率样本，并设为 **Sequence / internal**。这是沿用当前频道配置要求。

推荐接法：

1. 调度「喷火」输出频道 1。
2. Pulse sequence 的 Trigger 设为 internal，频道设为 1；使用单次模式，关闭 Stop on low，让短脉冲跑完整轮。
3. 序列步骤输出其他内部频道来启动攻击、声音或标记点红石，也可输出 Sequence / external TX 频道驱动 Create 无线终端与机械动作。
4. 调度等待对应序列结束以及最短占用时间结束，再等待招后休息时间，随后选下一招。

最短占用时间也适用于直接启动攻击模块的接法；调度不会自动判断独立攻击动画是否播放完毕。目标条件只决定是否选招，实际瞄准使用攻击模块自己的设置。前方方向相对于核心所在结构。

## 无线红石

标记生命体上的方块／面，在标记处产生真正的红石信号，不替换标记方块。可以驱动旁边的灯、红石线及红石设备。

可设置强度 0–15、所有面／仅标记面，以及跟随输入持续输出或上升沿触发完整短脉冲。默认使用 internal trigger，也可使用核心红石或 external RX 等原有触发方式。短脉冲不会因输入提前消失而截断。

同一位置多个输出采用最高强度；与导航、传感器的输出合并。停用、删除、关闭无线总开关或生命体死亡后清理输出。

## 自动验证

构建与单元测试通过；游戏引擎测试验证调度启动序列、序列驱动标记点与原版灯、运行时互斥、信号合并和死亡清理，以及目标条件、频道模式、配置保存与频道删除解绑。

## 本轮待玩家检查

1. 添加两个不同招式的调度：权重、各自冷却、血量／距离／前方角度限制，确认等待完整序列后才选下一招。
2. 标记点红石分别驱动灯、红石线和实际机械设备；测试六面／单面、持续／短脉冲，以及 external RX 触发。
3. 招式运行中停用／删除模块、关闭总开关、解除生命化，检查没有残留输出。
4. 保存重载、数据复制器与 Photomancy 复制两个新模块，重新激活后检查配置及标记继承。
5. 界面翻页、滚轮调整、右键反向切换及运行状态提示。

运行中的冷却、选招与脉冲状态不保存；重新激活或加载后从空闲状态重新调度。

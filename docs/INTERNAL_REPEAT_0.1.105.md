# 0.1.105 内部循环免频率物品

- Internal repeat（模式 0）已启用时，即使红／蓝都为空也按延迟、开启／关闭时长、强度和循环设置输出内部信号。
- 仅此模式免除频率物品要求；接收、普通外部输出、序列内部／外部模式保持原规则。
- 内部循环不注册 Create 外部无线发射器；不同核心不会因空频率串联。
- 频道停用、总开关关闭、核心解除生命化或死亡仍停止内部输出。
- 频道模式提示增加空频率说明；保存重载保留空频率内部循环。
- 包含 0.1.104 Common／Advanced（同时生效）文字提示。

## 待人工检查

1. Internal repeat 清空红／蓝，启用后驱动同核心攻击模块；延迟及开关周期符合设置。
2. 停用频道／总开关／解除生命化停止信号；保存重载仍正常。
3. 外部无线模式清空物品仍不发射／接收；放频率物品后保持正常。

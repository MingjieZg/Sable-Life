# 0.1.21-dev 一次性实机测试

测试实例：Minecraft 1.21.1 / NeoForge，Create + Sable + Aeronautics + Sable Life + Jade。测试前确认模组列表中的 Sable Life 为 **0.1.21-dev**。

1. **Jade 信息提示**：准星分别指向普通方块和牛。应显示方块名称、牛的名称与血量。
2. **生命核心名称与 Boss 血条**：创造模式空手右键核心；把铁砧改名的命名牌拿在光标上点击名称图标（命名牌应保留），打开 Boss 血条。潜行空手右键激活后，附近可见自定义名称及满血条；攻击相连身体后血条减少，血量归零后消失。核心仍存活时在菜单内关闭血条应立即隐藏。
3. **箭矢发射模块**：先在未激活结构上配置朝向和伤害，再组装、激活并通电。应按设定间隔射箭，断电停射；箭矢不能拾取。拆下带模块的部位后，即使残骸仍通电也应停射。
4. **范围脉冲模块**：在目标附近通电，检查每隔设定时间出现冲击粒子并造成伤害/击退。普通石墙挡在模块与目标之间应阻止伤害；断电、核心死亡或部位拆下后不再产生脉冲。
5. **目标感应模块**：创造模式在未激活时把目标类型设成“其他生物”，与箭矢或喷火模块相邻组装，尽量与生命核心隔开，避免核心自己的心跳红石直接供电。激活后让牛进入感应范围：感应模块应输出红石并启动相邻攻击模块；移走牛后约 5 游戏刻内停攻。默认视线模式下石墙应挡住感应；需要验证隔墙感应时，先解除生命化再关闭“视线遮挡”并重新激活。核心死亡或感应模块断肢应立即停止输出。

如需对比，在创造模式可使用 `/give @s sablelife:arrow_module`、`/give @s sablelife:pulse_module`、`/give @s sablelife:target_sensor`。配置界面仅创造模式可打开；模块激活后只读。

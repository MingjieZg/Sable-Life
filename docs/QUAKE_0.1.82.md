# 地震波模块（0.1.82）

## 行为与设置

- 直线波浪：从起点沿设定方向推进，直线宽度限制左右命中范围。
- 环形震波：从起点向外扩散；宽度是波峰的厚度。
- 起点可选 Mark 点投影到地面，或最近符合目标类型的生物／玩家脚下。起招时固定起点和方向，后续不追踪位置。
- 预警阶段在预计路径内目标的脚下画圈，同时显示直线边缘／环形外沿；目标移开后预警圈留在原地。
- 波峰经过才造成普通物理伤害，并施加可调击飞高度与水平推力。每个目标每一波最多命中一次，快速波浪也检查两刻之间扫过的位置。
- 默认只命中接地目标：跳过波峰可躲避。关闭后可以命中离地目标，仍受「离地命中高度」限制。
- 击飞高度 0–20 格按原版重力估算；地形、天花板、装备及其他模组运动效果可能改变实际高度。
- 地面隆起高度 0–4 格独立于击飞高度。临时模型复制普通地面方块外观，不移动原方块、不制造掉落物；液体、容器等有方块实体的表面不生成隆起模型。
- 波数 1–8，每波间隔可调，距离最多 64 格；可自选颜色、粒子及预警／震波音效与播放半径。
- 一次短脉冲可完成整次预警与多波攻击。持续输入在最后一波落回并完成冷却后再次起招。停用、删除、总开关关闭、解除生命化、死亡或卸载会清理临时模型及音效。
- 模块保存设置、音效、粒子和标记，运行中的波浪不保存。临时模型本身禁止写入存档，且有短暂寿命。

## 视觉与地形限制

地震沿世界地面采样，Mark 点下方 64 格内需要有地面；一般台阶及坡地会使用各采样点的地面高度。每个采样点搜索基准高度上方 4 格至下方 64 格。大型悬崖、洞穴、复杂屋顶与 Sable 移动平台需实测。

隆起是无碰撞的视觉模型，真实击飞由命中判定施加。一个核心同时最多保留 192 个隆起模型，较远的环形波采样较稀疏；视觉限制不会缩小攻击范围。

## 自动验证

构建、几何／高速波峰／击飞高度单元测试，以及游戏引擎的直线、环形、接地／空中躲避、固定脚下预警、短输入完成、配置保存、地形不变及临时模型清理测试。

## 本轮待玩家检查

1. 直线／环形与 Mark 点／目标脚下四种组合：预警圈留在原地，移动和跳跃能够躲避。
2. 击飞高度 0／1／3／10，水平推力 0／默认／高值；地面隆起视觉与人物运动协调。
3. 多波、每波间隔、波速、宽度与伤害；每个目标每波只受一次伤害，护甲减伤正常。
4. 草地、石头、台阶、斜坡、悬崖与容器附近：没有真实方块改变或掉落；同时观察远距离环形的视觉密度。
5. 自定义粒子、预警／震波音效、音量与半径；最少粒子设置下仍能看到预警。
6. internal／external RX／核心红石触发，以及招式调度 → 序列 → 地震波联动；短脉冲能跑完整招。
7. 预警／波浪期间停用、删除、关闭总开关、解除、死亡；重新进世界后没有遗留模型。
8. 保存重载、数据复制器和 Photomancy 复制配置、标记及粒子；UI 滚轮、右键反向、50% 缩放与预览。

本轮未启动客户端，视觉效果与玩家实际击飞手感仍待以上检查。

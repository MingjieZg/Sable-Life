# 0.1.58 UI 与落地雷扩展

用户已反馈之前清单测试完毕，场地边界警告仍需复查。本轮仅编译与代码检查，没有游戏内验证。

## 界面
- 密度增加 50%，100 / 85 / 75 / 50 循环；右键反向切换，设置保存在本地。
- 减伤滚轮每步 5%，限制仍为 0–100%。
- 所有模块枚举/开关、触发模式、无线模式/开关、核心设置开关支持右键回退。打开子界面、文件夹、删除等操作按钮不属于循环选择。

## 场地边界诊断
- 保留机械核心越界规则：以固定中心与核心世界坐标的水平距离判断，玩家自己越界不触发。
- 预览可在休眠时显示，但处罚仅在 ALIVE、模块启用且触发供电满足时执行。
- 创造/旁观玩家不参加处罚；附近需要生存/冒险玩家。
- 面板区分休眠、等待触发、监控、越界无合格玩家、正在倒数，不把预览当成启动。
- 截图中的 DORMANT 可解释当时预览有圈却未处罚；未据此宣称已证实或修复其他运行问题。

## 落地雷
- 起始距离 0–128 格：直线/向外射线从该距离开始落地；目标模式只选择该距离以外的目标。延伸距离是距标记点的最远距离；起始距离大于延伸距离时不生成落点。
- 向外射线 4–32 条，默认 8；均匀覆盖整圈。每轮最多 128 落点，自动扩大层间距以覆盖完整距离，不截断一侧。
- 发射物使用原一格物品样本界面，保留物品组件；下落外观尺寸 0.05–2 格。
- 下落物仅是视觉载体，伤害仍在预警点落地时按攻击半径结算，不额外产生碰撞伤害或破坏地形。
- 下落/落地音效独立选择 Minecraft 或自定义 OGG；默认下落静音、落地爆炸。每个落点播放各自音效，长音效可重叠。
- 拖尾使用与药水相同的双列表流程选择最多 16 种简单粒子；未选择时使用原颜色拖尾，多选时交错采样避免粒子数量随种类成倍增长。
- 每轮捕获发射物、大小、拖尾、音效配置；关闭触发/禁用/删除/解除会取消该模块待落点、下落实体和对应音效。

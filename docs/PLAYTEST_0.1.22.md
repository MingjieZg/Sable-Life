# 0.1.22-dev 实机测试

测试实例：Minecraft 1.21.1 / NeoForge 21.1.251。按本轮约定，不自动启动客户端；下次进入游戏前确认模组列表的 Sable Life 为 **0.1.22-dev**。Jade 生物血量暂不列入本轮检查，Boss 血条保留现状。

1. **箱子背景**：在创造模式右键核心、战利品或模块设置，应显示铜色机械边框、铆钉与紫晶装饰背景。格子位置、图标、左右键和 Shift 调整方式保持原样。激活生命体后仍按原规则锁定编辑；生存模式不能查看配置。
2. **箭矢散射**：设置每轮 5 支、8 格处散射半径 2；激活后通电，应每轮发射 5 支，从发射口向外散开，单支模式仍保持直射。断电停射。箭矢连击同一生物时应按每支实际命中扣血。
3. **无敌帧**：把近战模块设置为低伤害并持续通电，让生物站在范围内，生命值应随模块每次判定继续下降。喷火、脉冲和箭矢也不应因其他近期命中而被原版红色受伤闪烁吞掉伤害；脉冲/喷火自身设置的间隔仍须有效。
4. **脉冲预览与音效**：选声音模块相同的内置或 `config/sablelife/sounds` 中 OGG，通电脉冲时应播放选定声音。点击“预览脉冲范围”后应在自己画面看到约 3 秒球形粒子边框。
5. **环形感应**：设外半径 6、内半径 3、目标为其他生物。牛在内圈应不触发，在 3–6 格环带内应触发。点击预览应看到内外圈范围；石墙视线开关仍有效。
6. **前方感应与斜角供电**：切前方模式，设射程和末端半径并指定朝向。牛进入前方锥形范围应触发，背后或横向超出范围不触发。把攻击模块装在感应方块的斜角相邻位置，并用玻璃或其他不传红石的方块连接主体；目标进入范围时模块应启动，离开/死亡/断肢后停止。普通六面红石线也应输出 15 级信号。

若界面按钮、数值同步或 Sable 运动方向出现异常，请记下对应模块、设置值和触发步骤。

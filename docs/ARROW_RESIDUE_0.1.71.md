# 箭矢落地残留 — 0.1.71-dev

箭矢模块新增「落地残留时长（秒）」：0–600 秒，默认 10 秒。滚轮每次增减 0.1 秒；0 表示撞到方块后立即消失。

普通箭矢与自定义飞剑／工具均适用。计时不计飞行时间；非爆炸发射物停在方块上后计时。爆炸开启时仍按原设定碰撞爆炸并立即消失。实体命中仍使用原版箭矢行为，不会额外生成残留武器物品。

修正宽 hitbox 擦到方块时立即删除发射物的行为：现在也会停留并按该属性计时。移除支撑方块后可继续掉落；已累计的落地时间保留。计时及发射时快照的残留时长会存档，重载不重新开始；后续修改模块属性只影响新发射物。

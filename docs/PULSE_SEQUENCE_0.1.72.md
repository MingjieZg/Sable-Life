# 内置可编程脉冲序列 — 0.1.72-dev

本轮加入独立虚拟「可编程脉冲序列」模块，无需 mark，也无需安装 Create Connected。控制的是玩家自定义频道信号，机械如何转向、移动、停顿仍由玩家接线决定。

## 使用

1. 在 Wireless 添加用于机械动作的频道，设置频率物品、启用频道。
2. 将这些输出频道设为新增的「序列控制／内部」或「序列控制／外部发射」。内部频道可驱动同一核心的模块；外部发射可驱动 Create 无线终端。两种模式都由序列控制输出，忽略旧的启动延迟、On／Off 时长和循环波形。
3. 添加脉冲序列模块，进入「编辑序列」。每个模块最多 128 步，可添加、删除、上下移动与分页。
4. 每一步选择「输出信号」或「等待」。输出设置频道号、1–15 强度和持续时长；等待期间该序列不输出。每步持续 0.05–600 秒，滚轮每次 ±0.1 秒；频道与强度每次 ±1。切换按钮支持右键回退。
5. 在主界面选择触发：Always、核心处红石、内部频道或外部接收频道。红石触发使用核心，序列无需标记。

示例：频道 1 输出 15、0.5 秒 → 等待 0.25 秒 → 频道 2 输出 15、0.5 秒 → 等待 1 秒。用频道 1 和 2 控制不同的动作机构，机械动作由其实际接线执行。

## 执行与复位

- 单次：输入由无信号变为有信号时开始，完整执行后等待下一次输入脉冲。输入持续为高不会不断重跑。Always 在激活／恢复运行时执行一次。
- 循环：输入有信号时重复；输入断电后默认完成当前一轮再停止。
- 「触发断电时停止」开启后，输入一旦归零就立即停止并清空本序列输出。
- 复位频道 0 表示不用；非零可选择外部接收或内部输出信号。复位信号优先于启动，保持复位信号会禁止运行。
- 编辑器的「立即复位」停止当前序列。单次模式需先断电再通电；循环模式若仍通电，下一 tick 可重新开始，需要持续停止时切断触发或保持复位信号。
- 一步只输出一个频道；进入下一步或等待步骤后上一步输出归零。若需要循环边界出现断电脉冲，加入一个等待步骤。
- 同一频道收到多个序列输出时取最高强度；复位一个序列不会清掉其他序列的输出。
- 关闭模块、关闭 Wireless 总开关、解除生命化、死亡或卸载会清空运行状态及输出。修改步骤会取消正在运行的序列。
- 删掉频道后，后续频道号自动前移；被删除的步骤输出变为未绑定，需手动重选频道。编辑器频道输入会提示未启用、未配置频率或未选序列模式的频道。

步骤、频道引用和模块属性使用现有配置存储，可随存档、数据复制器及 Photomancy 蓝图复制。执行进度不复制／保存；恢复后按触发条件从第一步执行。

# Move set 招式完整性规则（用户确定，2026-10-06）

决定：保留当前整招失效规则。一个引用动作模块失效，就让整个Move停用；不改为跳过坏动作继续执行，不追加宽松/严格模式开关。

## 判定与表现

- Move自身没有独立Mark；检查的是它引用的各个动作模块。
- 任一引用模块缺少必需Mark、标记被毁、肢体脱离、被禁用/删除，或Trigger不再为Move set，该Move不参与Weighted/ Priority候选选择。
- 如果失效发生在运行中，取消当前Move的剩余调度。普通持续运行方式经过该招式Rest后，继续选择其他可用且满足条件/冷却的Move。
- 其他完整Move不受这个失效Move牵连；但若它们都引用同一个损坏部位，可能一起失效。
- 所有Move均不可用或不满足条件时，调度器等待；不是生命体被关闭或死亡，但可能表现为没有招式可用。
- When hurt / Once中途失效时结束本次反击，等待下一次受伤触发。
- 取消剩余调度不等同于撤销已经产生的所有效果，已发射物及编排音效各自遵守其运行/取消规则。

## 必须在说明书解释的实例

有三个Move，其中“喷火招式”按时间线引用：Wireless redstone、声音、喷火、机械动作。若机械动作的Mark被打掉，整条“喷火招式”退出候选；无线红石、声音和喷火也不再以该招式继续调度。剩下两个完整Move继续参与选择。

设计理由：一个完整招式需要所有动作配合；断肢后应失去整招，避免只剩音效、喷火或移动的一部分产生不完整表现。可以使用不同部位的独立Move，让机器失去一招后仍保留其他招式。

## Mark例外

依据模块本身的有效性规则检查，不能笼统要求所有动作都有Mark。Wireless redstone的Mark为可选输出位置，外部红蓝频率模式无需Mark；虚拟命令模块也无需Mark。没有Mark但仍合法的模块不导致整招失效。

# 0.1.280 持续区域合并与离开后燃烧（开发版，2026-10-28）

Mortar、Flamethrower 只保留“命中后持续区域”选择，移除独立的“命中后留下火焰”及其半径/时长/伤害设置。火池、毒雾等统一由 surface_field 模板描述。

持续区域新增 **接触后燃烧** 勾选，默认关闭。开启后显示 **离开后燃烧时间（秒）**，默认3秒，0–30秒。粒子独立选择：火焰粒子只是视觉，是否点燃由勾选控制；毒雾也可以按需要同时点燃。

区域直接伤害仍按命中间隔独立结算，通过既有 ModuleDamage 入口暂时绕过普通受击无敌帧，保持原有护甲和伤害修正规则。刚受到原版燃烧伤害，不会吞掉应到的区域伤害。原版残留燃烧伤害另行运行，不改变区域伤害时钟。

开启燃烧的区域每刻检查接触，并在伤害冷却检查前刷新燃烧时间；即使伤害间隔100刻，也不会让燃烧倒计时在区域内提前耗尽。目标离开区域后不再刷新，继续燃烧剩余的设定时间。关闭燃烧时隐藏时长并忽略保留的时长值。不开启燃烧的区域保留原有最多5刻一次的接触扫描。

示例：创建持续区域，长8宽2、角度90度，设置区域伤害和间隔，选择 flame 粒子，勾选接触后燃烧并设3秒。然后在迫击炮或喷火的命中后持续区域中选择它。旧0.1.279的独立残留火焰选项被移除，若原先仅使用该选项，需要改为选择区域模板并在模板内开启燃烧。

范围贴合、UUID引用、重叠伤害间隔、刷新区域时长、清理及数量限制沿用0.1.279。没有实际火方块或地形改动。

验证：58项持续区域/攻击原生GameTests通过，包含新增的燃烧刷新独立于伤害冷却、离开后停止刷新和到期熄灭、已有无敌帧及刚受到燃烧伤害仍按时扣除区域伤害。16组GUI缩放/密度检查通过，覆盖燃烧勾选、时长显隐及移除重复设置。双语手册117及Jar内容验证通过。

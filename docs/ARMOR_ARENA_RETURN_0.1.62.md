# 0.1.62：护甲伤害与场地回中心

## 变更

- 修正落地雷的 `magic`、近战/力场/子弹/爆炸的 `generic` 伤害源：这些原版伤害类型绕过护甲。
- 近战、力场、落雷改为普通物理伤害；子弹使用投射物伤害；爆炸使用爆炸伤害，适用对应保护附魔。原生箭矢及喷火保留正常原版规则。
- 攻击模块仍使用自己的命中间隔；场地处罚仍使用原版 `genericKill`，保留秒杀。
- 场地新增“处罚完成后传回中心”，默认关闭，旧存档行为不变。
- 开启时，场地圆柱内所有非创造/旁观的存活玩家，以及原有 Boss 警告范围内玩家，都获得完整倒数。所有当前警告结束且确实发生击杀后才传回；没有玩家时不会直接传回，仍存活的免死玩家会阻止传回。
- 传送整个连接机构，保留各部件相对位置、朝向及当前高度，仅将核心 X/Z 移到固定场地中心；同时清零机构速度。

## 验证

`scripts/dev.ps1 -Task assemble` 编译通过；未启动客户端或进行游戏测试。

待游戏检查：

1. 只安排一次 20 伤害落雷：比较裸装与未附魔全下界合金，后者应受到明显更低伤害。避免多个落雷范围同时覆盖玩家。
2. 检查近战、力场、子弹对护甲减伤，以及弹丸爆炸对爆炸保护的响应。
3. 回中心关闭：越界后继续原有警告及秒杀，不传送。
4. 回中心开启：两个场内玩家分别收到完整倒数；最后一个被击杀之前 Boss 不回中心。
5. 检查在倒数中途进入场地的玩家获得完整倒数，并延后回中心。
6. 检查整台机构回到中心后，各连接部件未重叠或断开，保持高度；无人时不传回。

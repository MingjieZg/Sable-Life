# Sable Life 最终需求清单

本文件保存 2026-09-27 与用户确定的设计。这里描述目标，不表示功能已经实现。

## Heart 生命核心方块

- 可放置在预先制作的机械身体内部；激活后整个机械成为生命体。
- 每只生物首版限定一个 Heart。
- 管理 UUID、统一生命值、身体归属、阵营、目标、行为状态、断肢与奖励记录。
- 右键配置生命值、感知/攻击距离、行为红石信号和死亡战利品。
- 输出待机、移动、左转、右转、攻击、受伤、低血量和死亡信号。
- 机械动作由作者搭建的机械与红石线路实现；Heart 不直接操纵关节或旋转身体。
- Heart 被直接破坏默认触发生物死亡；允许配置成存活期间不可挖毁。

## 创造解除工具

- 仅创造模式可用，右键身体任意方块解除相连结构的生命属性。
- 保留所有建筑方块和机械连接，恢复普通 Sable 行为，允许继续拆改。
- 可处理存活、死亡中和死亡的核心；核心恢复默认未激活状态，清除生命身份、绑定、倒计时和信号，可重新激活。
- 不触发死亡战利品，不影响未连接的其他结构；生存玩家即使持有工具也不能重置。

## 身体与受伤

- 所有已绑定的身体方块都是攻击目标：箭射中脚上的铁块也扣同一条血。
- 身体可能由多个通过关节相连的物理结构组成，正常关节不应被误判为断肢。
- 身体可被挖掘、爆炸和破坏，但不掉普通组成材料。
- 攻击伤害与破坏方块造成的伤害可配置。
- 核心提供“允许破坏身体方块”总开关，默认开启；关闭后身体与所属残骸保持不可拆块，攻击扣血与死亡清理仍生效。
- 同一次攻击合理去重，避免多个方块重复结算意外多倍伤害。

## 攻击模块

首版：近战攻击核心、喷射模块、投射物发射器、范围脉冲模块。

后续：射线、传播冲击波、危险区域、抓取/释放/投掷、攻击前摇预警。

统一参数：伤害、伤害类型、击退力度/方向、减益/时长/概率、范围、持续时间、命中间隔、目标/阵营过滤、友伤、红石触发、命中反馈。

近战：区域与部件绑定、可视化覆盖范围、红石控制攻击窗口、默认每次挥击每个目标仅受伤一次、高速挥动扫掠检测。

喷射/射线应跟随模块朝向，并具有地形遮挡检测；是否点燃/破坏地形独立配置。

可选速度伤害应有上限，固定伤害为默认。

## Part Marker 部位战利品模块

- 支持手、尾巴、角、翅膀等作者自定义部位 ID。
- 指定战利品表及解体延迟。
- 与 Heart 真正失去身体连接时触发，不要求击碎 Marker。
- 部位丢失状态反馈给 Heart，允许作者换动作或攻击模式。
- 一个部位可以同时安装攻击模块和战利品模块。
- 奖励仅结算一次，再次碎裂、存档重载与死亡掉落均不得重复产出。

## 断肢规则

连接断裂 → 攻击立即失效 → 物理掉落 → 延迟解体 → 指定素材。

- 脱离部位不再向主体传递伤害。
- 停止近战、喷射、发射；抓取立即释放；旧红石信号不能重新启用。
- 所有残骸保留原 Creature UUID 及禁止材料掉落标志。
- 残骸仍可继续破坏，但不掉原本建筑材料。
- 再次碎裂不重复奖励，重新连接不自动恢复生命或重置奖励。
- 首版残骸不主动造成攻击伤害；砸落伤害以后作为独立选项。
- 已发射弹体和已生成危险区域在断肢后的处理策略，实施相应模块前单独明确。

## 死亡

- HP 归零或核心被破坏进入统一死亡流程。
- 立即关闭常规行为及攻击，发出死亡信号。
- 等待可配置死亡动作时间，随后清理主体与所属残骸。
- 禁止普通方块掉落；执行指定死亡战利品表与经验结算。
- 已结算的断肢奖励不能再结算。

## 配置与可靠性

- 可视化身体归属、部位绑定与攻击范围；查看状态和信号。
- 生命、身体归属、断肢和奖励状态持久化。
- 存档重载、区块卸载、结构移动、拆装、再分裂、重新拼接都不能制造材料或奖励重复。
- 服务端负责攻击、生命、状态迁移和掉落；客户端只负责显示及请求。

## 开发顺序

1. 固定环境，验证结构、关节、断裂、坐标变换、命中和红石接口。
2. Heart → 整体受伤 → 禁止材料掉落 → 死亡清理与指定战利品。
3. 机械手红石挥击 → 近战伤害 → 断手 → 攻击失效 → 部位战利品。
4. 喷射、投射物、范围脉冲。
5. AI、配置界面、调试工具和更多攻击形式。

首个完整验收：机械怪兽能挥手伤人；玩家能攻击身体并打断手；断手立即停攻，延迟解体掉手部素材；本体归零或核心破坏后正常死亡与掉落。

## 后续：部位掉落权重

已实现独立概率（每格 0–100%，默认 100%，整叠判定）与加权抽选（每格权重 0–100，1–27 次有放回抽取）。每格的概率与权重分别保存，切换模式不清除另一组数值。断肢时保存规则快照，只结算一次。

## 后续：声音模块（用户指定，待设计）

- 玩家靠近时播放音效。
- 生命体受伤时播放音效。
- 从自定义音频文件夹选择音效。
- 本阶段仅记录需求，声音模块的触发、播放及文件接入方式留待后续设计。

### 喷火模块（0.1.16）

定位：红石持续触发的定向火焰攻击。距离、每次伤害、燃烧时长、伤害间隔、末端半径、六向朝向在创造配置菜单中调整。只在活着的已绑定主体上通电工作，断肢和死亡后停攻；受方块遮挡，无地形燃烧。目标已附带的燃烧继续按原版计时。

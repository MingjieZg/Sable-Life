# Changelog

This changelog highlights major Sable Life development milestones.

> **History note:** Sable Life was developed through many private development commits before its public release. The public Git history was intentionally reset at **0.1.313** during repository cleanup, so earlier entries below are curated milestones rather than a complete commit-by-commit history.

## 0.1.313 — 2026-11-01

- Established the source snapshot used for the public release.
- Improved bundled particle compatibility with Iris/shader environments.
- Improved respawn-label rendering compatibility.
- Added Summoned Weapon support to Move Sets.
- Finalized the project branding/icon used for the public repository.

## 0.1.308 — 2026-10-31

- Consolidated the development build and tested source changes accumulated after 0.1.284.
- Continued compatibility and stability work ahead of the public-source milestone.

## 0.1.284 — 2026-10-28

- Added impact-area improvements.
- Added optional Slash blocking behavior.
- Fixed schematic reference handling.

## 0.1.278 — 2026-10-19

- Reached the final acceptance milestone for the physical-body damage API.
- Preserved a tested development snapshot around the completed damage integration work.

## 0.1.243 — 2026-10-14

- Promoted a stable checkpoint.
- Added configurable hover behavior.
- Added hit-counter mechanics.
- Added self-health adjustment behavior.

## 0.1.206 — 2026-10-10

- Added optional Arena blueprint respawn support.
- Expanded Iron's Spells 'n Spellbooks compatibility with additional physical-body damage paths.

## 0.1.200 — 2026-10-09

- Promoted a stable checkpoint.
- Expanded Epic Fight compatibility for guard/parry and protected-body combat.
- Preserved native attack behavior without relying on proxy entities.
- Added persistent configurable boss-bar colors.

## 0.1.195 — 2026-10-09

- Hardened authoring permissions and runtime safety.
- Added ownership, core, and signal indexing.
- Added bounded cleanup, visual, projectile, and collision workloads.
- Improved synchronization while preserving authoring behavior.

## 0.1.194 — 2026-10-09

- Established the audited source baseline used for the later development cycle.
